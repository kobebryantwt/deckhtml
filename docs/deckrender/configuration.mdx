DeckRender can submit cloud renders without credentials in rate-limited guest mode. Log in or set an API key for authenticated use.

```bash
deckrender auth login
deckrender auth status
deckrender config list
```

`auth status` validates the effective credential. `config list` shows masked values and the source that won for each field.

## Credential precedence

Each field resolves independently in this order:

1. Explicit SDK renderer option.
2. Environment variable.
3. `~/.deckflow/credentials`.
4. `~/.deckops/config.json`, read only.
5. Built-in default.

| Field | Environment variables, in order |
| --- | --- |
| API key | `DECKRENDER_API_KEY`, `DECKFLOW_API_KEY`, `DECKHTML_API_KEY` |
| Token | `DECKRENDER_TOKEN`, `DECKFLOW_TOKEN` |
| Space | `DECKRENDER_SPACE_ID`, `DECKFLOW_SPACE_ID` |
| API base | `DECKRENDER_API_BASE`, `DECKFLOW_API_BASE` |

The default API root is `https://app.deckflow.com/v1`. Shared credentials are stored in `~/.deckflow/credentials`; DeckRender preserves unknown keys written by other Deckflow tools.

## Persistent CLI defaults

Render defaults live separately in `~/.deckrender/config.json`:

```bash
deckrender config set profile web
deckrender config set image-format webp
deckrender config set width 2560
deckrender config unset width
deckrender config path
```

Supported keys are `profile`, `format`, `image-format`, `quality`, `width`, `scale`, and `timeout`. Precedence is:

```text
profile defaults < ~/.deckrender/config.json < explicit CLI options
```

If a profile or stored default cannot apply to the selected route, it is dropped with a warning. An incompatible option typed explicitly remains an error.

## CI and isolated environments

```bash
export DECKFLOW_API_KEY='...'
export DECKFLOW_CONFIG_DIR=/tmp/deckflow-ci
export DECKRENDER_CONFIG_DIR=/tmp/deckrender-ci
deckrender deck.pptx --json --quiet
```

Non-interactive and JSON invocations do not open the browser login flow after an authentication failure.
