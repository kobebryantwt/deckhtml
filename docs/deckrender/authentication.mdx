You can try DeckRender cloud routes without configuring credentials. Guest mode is rate-limited and is suitable for evaluation. For sustained workloads, CI, production quotas, or a private workspace, use an API key or sign in through the browser. Browser login stores a session token for interactive development; API keys are better suited to unattended services.

## Browser login

```bash
deckrender auth login
deckrender auth status
```

Login opens the DeckFlow authorization page and stores the returned token in `~/.deckflow/credentials`. When credentials exist, `auth status` validates them against the backend and shows their source; without credentials it reports that guest mode is active without making a validation request.

## API key

Get an API key before configuring the CLI:

<Steps>
  <Step title="Open DeckFlow Settings">
    Sign in to DeckFlow and open [API Key Settings](https://app.deckflow.com/start#settings).
  </Step>
  <Step title="Create and store the key">
    Configure an API key in Settings, copy it once, and save it in the secret store used by your development or production environment.
  </Step>
</Steps>

Configure the key on a developer workstation:

```bash
deckrender config set api-key YOUR_API_KEY
deckrender auth status
```

For CI or containers, use an environment variable instead of writing a credential file:

```bash
export DECKFLOW_API_KEY='YOUR_API_KEY'
deckrender hello.html -o hello.png --json --quiet
```

`DECKRENDER_API_KEY` has higher priority than `DECKFLOW_API_KEY`; `DECKHTML_API_KEY` is also recognized for compatibility.

<Warning>
  Treat the API key as a server-side secret. Do not place it in browser code, commit it to a repository, or print it in logs.
</Warning>

## Credential resolution

Each field resolves independently:

1. Explicit Node.js renderer option.
2. DeckRender or DeckFlow environment variable.
3. `~/.deckflow/credentials`.
4. `~/.deckops/config.json`, read only.
5. Built-in API base default.

Run `deckrender config list` to see masked effective values and their sources.

## Logout and fallback credentials

```bash
deckrender auth logout
deckrender config list
```

Logout removes credentials stored in the shared DeckFlow file. An environment variable or token in the DeckOps config can still authenticate subsequent calls; confirm the effective source with `config list`.

<Warning>
  JSON, CI, and other non-interactive calls do not open a browser after `401`. Configure an API key or token before starting the job.
</Warning>

Render defaults such as format, profile, width, and timeout are covered separately in [Configuration](/deckrender/configuration).
