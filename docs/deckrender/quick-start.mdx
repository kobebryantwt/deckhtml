This walkthrough renders a self-contained HTML file locally. It does not require an account or upload the source to DeckFlow.

<Steps>
  <Step title="Check prerequisites">
    DeckRender requires Node.js 18 or later. Local rendering also needs Chrome, Chromium, or Edge installed on the execution machine.

    ```bash
    node --version
    ```
  </Step>
  <Step title="Install and verify the CLI">
    A normal installation includes the optional JavaScript dependencies and the matching `office2html` platform package.

    ```bash
    npm install -g @deckflow/deckrender
    deckrender --version
    deckrender formats --engine local
    ```
  </Step>
  <Step title="Create a known input">
    Save this as `hello.html`:

    ```html
    <!doctype html>
    <html>
      <head>
        <meta charset="utf-8" />
        <style>
          body { margin: 0; font: 48px system-ui; }
          main { padding: 64px; background: #f4f7ff; }
        </style>
      </head>
      <body><main>Hello DeckRender</main></body>
    </html>
    ```
  </Step>
  <Step title="Render one PNG locally">
    ```bash
    deckrender hello.html --engine local -o hello.png --json --quiet
    ```
  </Step>
  <Step title="Verify the artifact and route">
    A successful command exits `0`, writes `hello.png`, and prints a result shaped like:

    ```json
    {
      "ok": true,
      "input": "hello.html",
      "format": "image",
      "engine": "local",
      "route": ["local.capture"],
      "pages": 1,
      "outputs": [{ "page": 1, "file": "hello.png", "width": 1280, "height": 720, "bytes": 18432 }],
      "durationMs": 1200
    }
    ```

    Dimensions, byte count, and duration depend on the page and browser. Verify the file separately in automation:

    ```bash
    test -s hello.png
    ```

    ```powershell
    if (!(Test-Path hello.png) -or (Get-Item hello.png).Length -eq 0) { exit 1 }
    ```
  </Step>
</Steps>

If DeckRender cannot find a browser, install Chrome/Chromium/Edge or set `DECKRENDER_CHROMIUM_EXECUTABLE_PATH`. See [Local and Cloud Engines](/deckrender/engines) for dependency lookup and PPTX/PDF local routes.

## Try a cloud route

Cloud is still the default engine and provides broader format coverage. This command uploads `hello.html` and runs without credentials in rate-limited guest mode:

```bash
deckrender hello.html --engine cloud -o hello-cloud.png --json --quiet
```

Use `--engine auto` for local-first selection. It warns before choosing cloud, so an upload is never silent. For sustained workloads or private workspaces, configure [Authentication](/deckrender/authentication).
