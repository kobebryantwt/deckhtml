description: "Install DeckRender, create an HTML input, render a PNG in guest mode, and verify the artifact and JSON result."
---

This example creates its own input and runs through a DeckFlow cloud render in guest mode. The HTML source is uploaded for processing; no account is required for the first request.

<Steps>
  <Step title="Check Node.js">
    DeckRender requires Node.js 18 or later.

    ```bash
    node --version
    ```
  </Step>
  <Step title="Install and verify the CLI">
    ```bash
    npm install -g @deckflow/deckrender
    deckrender --version
    deckrender formats
    deckrender config list
    ```

    Check the credential source shown by `config list`. DeckRender can inherit a token from DeckOps; an expired fallback token will cause `auth_error` instead of guest execution.
  </Step>
  <Step title="Create a known input">
    Save this as `hello.html`:

    ```html
    <!doctype html>
    <html>
      <head>
        <meta charset="utf-8" />
        <style>
          body { margin: 0; font: 48px system-ui; }
          main { padding: 64px; background: #f4f7ff; }
        </style>
      </head>
      <body><main>Hello DeckRender</main></body>
    </html>
    ```
  </Step>
  <Step title="Render one PNG">
    ```bash
    deckrender hello.html -o hello.png --json --quiet
    ```
  </Step>
  <Step title="Verify the artifact and result">
    A successful command exits `0`, writes `hello.png`, and prints a result shaped like:

    ```json
    {
      "ok": true,
      "input": "hello.html",
      "format": "image",
      "engine": "cloud",
      "route": ["convertor.html2png"],
      "pages": 1,
      "outputs": [
        {
          "page": 1,
          "file": "hello.png",
          "bytes": 18432
        }
      ],
      "durationMs": 3200
    }
    ```

    `--quiet` keeps stderr empty unless the command fails. Byte count and duration vary. Verify the file separately in automation:

    ```bash
    test -s hello.png
    ```

    In PowerShell, use `if (!(Test-Path hello.png) -or (Get-Item hello.png).Length -eq 0) { exit 1 }`.
  </Step>
</Steps>

Guest rendering is quota-limited. If the command returns `auth_error`, run `deckrender auth status` to inspect the selected credential. Sign in or configure an API key and retry; an expired environment variable or DeckOps fallback credential can override guest mode. See [Authentication](/deckrender/authentication).
