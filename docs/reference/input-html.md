# Input HTML Reference

This page defines the role of HTML inputs in the DeckHTML workflow.

## Supported sources

- Local file paths
- Standard input streams
- Hosted URLs

## Authoring guidance

- Keep each input page presentation-oriented.
- For multi-slide decks, provide files in the intended order.
- Ensure referenced assets are reachable in the execution mode you selected.

## Validation goals

Before conversion, verify:

- The HTML is complete and readable
- Assets resolve correctly
- The selected output format matches the intended downstream workflow
