This section documents the Default Module API exposed by DeckHTML.

<Note>
  The API reference pages below are generated from your OpenAPI definition, so request parameters, response schemas, code examples, and the interactive playground stay aligned with the spec.
</Note>

## Authentication

All endpoints in this module use:

```text
Authorization: Bearer <APIKEY>
```

The interactive playground uses the production base URL:

```text
https://app.deckflow.com/v1
```
