title: Update Approved Content in a PPTX

---

This example changes `Presentation Title Text` to `DeckUse Updated Title` in a known presentation. The source and output remain local, and the original PPTX is never overwritten.

## Prerequisites

- Node.js 18 or later
- No DeckFlow account or API key

## Run the example

<Steps>
  <Step title="Install the CLI">
    ```bash
    npm install -g @deckflow/deckuse
    deckuse --version
    deckuse --help
    ```
  </Step>
  <Step title="Download the public test presentation">
    ```bash
    curl -fL https://docs.deckflow.com/images/deckuse-sample.pptx \
      -o input.pptx
    ```

    This documentation fixture contains one editable text box with `Presentation Title Text`.
  </Step>
  <Step title="Initialize and review the match">
    ```bash
    deckuse init input.pptx ./workspace --json
    deckuse query ./workspace 'text=Presentation Title' --limit 10 --json
    ```

    Continue only when the query returns the expected text box. A reviewed query prevents an accidental global change against an unknown file.
  </Step>
  <Step title="Create the approved operation">
    Save as `replace.json`:

    ```json
    {
      "type": "replaceText",
      "find": "Presentation Title Text",
      "replace": "DeckUse Updated Title",
      "selector": "kind=textbox",
      "limit": 1
    }
    ```
  </Step>
  <Step title="Apply, validate, and export">
    ```bash
    deckuse apply ./workspace --input replace.json --json
    deckuse validate ./workspace --json
    deckuse commit ./workspace -o updated.pptx --json
    ```

    Check that the apply result has `ok: true`, `matched: 1`, and a new revision. Validation must also return `ok: true` before commit.
  </Step>
  <Step title="Verify the output as a new input">
    ```bash
    deckuse init updated.pptx ./verification --json
    deckuse query ./verification 'text=DeckUse Updated Title' --limit 10 --json
    test -s updated.pptx
    ```

    The verification query should return `DeckUse Updated Title` and no `Presentation Title Text`. In PowerShell, verify the file with:

    ```powershell
    if (!(Test-Path updated.pptx) -or (Get-Item updated.pptx).Length -eq 0) { exit 1 }
    ```
  </Step>
</Steps>

## What this verifies

- DeckUse indexed the expected source object before changing it.
- The JSON command matched exactly one text box.
- The workspace passed structural validation.
- Commit produced a non-empty, independently readable PPTX.

<Warning>
  Structural validation is not visual validation. Open or render `updated.pptx` before using it in a delivery workflow.
</Warning>
