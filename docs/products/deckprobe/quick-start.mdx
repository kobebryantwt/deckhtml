## Try the Playground

Open the [Deck Playground](https://deckflow.github.io/playground/) to see how document-level profile information, page previews, and downstream actions can be presented before integrating the CLI or browser SDK.

## Install

DeckProbe requires Rust 1.88 or newer when installing from source:

```bash
cargo install --git https://github.com/deckflow/deckprobe --locked deckprobe
```

Prebuilt installers are also published with DeckProbe releases. See the [installation guide](https://github.com/deckflow/deckprobe/blob/main/docs/INSTALLATION.md) for platform-specific commands and verification details.

## Inspect a document

Run a default metadata probe:

```bash
deckprobe --pretty report.pdf
```

Ask for only the targets your workflow needs:

```bash
deckprobe --pretty -t format,slide_count deck.pptx
```

The result is structured JSON. Each requested target reports its resolution status, value, confidence, and selected probe path.
