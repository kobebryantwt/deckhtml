# DeckOps

DeckOps is the one-way document operations layer. It parses source files, exposes an intermediate representation (IR), and can reconstruct or export supported downstream file formats.

## Use DeckOps when

- A pipeline needs structured document data rather than a visual rendering.
- Consumers need a stable IR between input parsing and output generation.
- A conversion or reconstruction does not need to preserve an editable connection to the original source.

## Product boundary

DeckOps is intentionally one-way. Use [DeckUse](/products/deckuse/overview) when changes must be applied back to a supported source file, or [DeckRender](/products/deckrender/overview) when only visual output is needed.
