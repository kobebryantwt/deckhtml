# DeckRender

DeckRender is the focused rendering component of the Deckflow document runtime. Developers integrate through its SDK, while rendering executes in the cloud.

## Use DeckRender when

- A workflow needs page or slide previews rather than structured document content.
- Visual fidelity must be checked without manipulating the source file.
- Thumbnails, review images, or other rendered assets are required downstream.
- The application needs rendering without the broader Parse, Extract, and Convert surface of DeckOps.

## Product boundary

Use [DeckProbe](/products/deckprobe/overview) for local or browser inspection without rendering. Use [DeckOps](/products/deckops/overview) when rendering belongs to a larger cloud workflow that also needs Probe, Parse into Document IR, Extract, or Convert.

Use [DeckUse](/products/deckuse/overview) when the source Office file must be manipulated rather than rendered.
