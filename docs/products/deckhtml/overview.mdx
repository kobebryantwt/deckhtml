# DeckHTML

DeckHTML generates PPTX presentations from HTML. It is the authoring product in the Deckflow family for workflows where HTML is the source of slide structure and visual design.

## Product boundary

DeckHTML starts from HTML and produces PPTX. For existing document files, use [DeckProbe](/products/deckprobe/overview) to inspect, [DeckRender](/products/deckrender/overview) to render, [DeckOps](/products/deckops/overview) for one-way document operations, or [DeckUse](/products/deckuse/overview) for source-file editing.
