# DeckHTML

DeckHTML is the HTML-native deck engine in the Deckflow family. It is a specialized capability for the growing workflow in which HTML is the source of slide structure and visual design, and presentation artifacts are generated through local or cloud execution paths.

## Product boundary

DeckHTML starts from HTML and produces presentation artifacts. For existing document files, use [DeckProbe](/products/deckprobe/overview) to inspect, [DeckRender](/products/deckrender/overview) to render, [DeckOps](/products/deckops/overview) to Parse into IR, Extract, or Convert, and [DeckUse](/products/deckuse/overview) to Manipulate a supported Office source file.
