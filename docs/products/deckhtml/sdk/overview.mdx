The SDK section is for teams integrating DeckHTML into services, internal tools, and automation code.

<Note>
  The npm package already exposes a Node programmatic API. For now, that is the concrete SDK surface we can document reliably.
</Note>

## When to use the SDK

Choose the SDK layer when:

- conversion is part of backend application logic
- you want to call DeckHTML from JavaScript or TypeScript directly
- you want typed options instead of shell flags
- you need the conversion result as an in-memory `Buffer`

## Suggested adoption path

<Steps>
  <Step title="Prototype with the CLI first">
    Validate your HTML input and expected output behavior at the terminal.
  </Step>
  <Step title="Move to the Node SDK for code-level integration">
    Use the published `convertHtmlToPptx()` function in services, workers, or internal tools.
  </Step>
  <Step title="Add your own file writing or storage layer">
    The programmatic API returns conversion output in memory, so your application decides how to persist or upload it.
  </Step>
</Steps>
