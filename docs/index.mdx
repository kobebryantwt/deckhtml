# Build Presentation Workflows With DeckHTML

DeckHTML turns HTML into presentation-ready outputs for developer workflows. Start from the CLI, integrate with SDKs, or expose conversion flows to agent tools through MCP.

<Note>
  This documentation set is organized for developers first: get a page rendering end to end, choose an integration surface, then deepen into formats, configuration, and agent workflows.
</Note>
