title: Convert IR to Markdown
sidebarTitle: Convert to Markdown

---

`convert` derives a view from DeckIR. The current target is Markdown. When the input is an artifact directory, DeckOps reads `ir.json` and never reopens or reparses the original document.

## Convert an existing artifact

```bash
deckops convert report/
```

The default output is `report/views/markdown/index.md`, and `manifest.json` records the renderer, options, files, and creation time.

To write elsewhere:

```bash
deckops convert report/ -o output/report.md
```

Use `-` to write Markdown to standard output:

```bash
deckops convert report/ -o -
```

## One-shot conversion

You can pass a document instead of an artifact:

```bash
deckops convert report.pdf -o report.md
```

This is shorthand for parsing the document and then converting the resulting IR. Use the two-step form when your application will inspect `ir.json`, generate multiple views, or reuse the parse later.

## Preserve source context

For PDF, add per-element provenance comments containing stable node IDs:

```bash
deckops convert report/ --anchors -o report.md
```

For PPTX and Keynote, write one Markdown file per page or slide:

```bash
deckops convert slides/ --split-pages
```

If cloud conversion returns expiring image links, the default behavior protects portability by rejecting an incomplete localization. `--keep-remote-images` accepts those temporary links explicitly:

```bash
deckops convert cloud-artifact/ --keep-remote-images
```

<Warning>
  Signed cloud image URLs are temporary preview references. Download and store required assets in your own system before their links expire.
</Warning>

## Verify reuse in automation

```bash
deckops convert report/ --json
```

Check that the response has `"ok": true`, `"op": "convert"`, and `"reusedParse": true`. The `outputs` array contains each written file and its byte size.
