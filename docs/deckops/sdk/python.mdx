PyPI does not provide the DeckOps Python package. To use this interface, install it from a reviewed source revision:

```bash
pip install "git+https://github.com/deckflow/deckops.git@<commit>#subdirectory=sdks/python"
```

Replace `<commit>` with the exact revision your application has tested.

```python
import os
from deckops import create_deck

with create_deck(api_key=os.getenv("DECKOPS_API_KEY")) as deck:
    task = deck.convert_ppt_to_pdf(files=["./slides.pptx"], name="slides")
    done = deck.tasks.wait(task["id"])
    result = deck.tasks.down(done["id"])
```

The Python client is synchronous and owns its HTTP connection pool. Use it as a context manager or call `close()` for short-lived clients.

<Warning>
  Configure an API key or user token for task execution. The current Python SDK does not expose the `tasks.start()` method required to start a guest-created task.
</Warning>

## Parse to Markdown

```python
with create_deck(api_key=os.getenv("DECKOPS_API_KEY")) as deck:
    markdown = deck.parse("./slides.pptx")
    detailed = deck.parse_detailed({
        "file_id": "uploaded-file-id",
        "name": "slides.pptx",
    })
```

The SDK also exposes low-level upload and task clients, typed shortcut methods, SSE-based waiting, polling fallback, and converters for structured parse results.
