This path creates a known HTML input, uploads it to Deckflow cloud, explicitly starts a guest task, and verifies the returned PNG metadata. It works with the currently published `@deckops/sdk@0.7.3` and requires Node.js 18 or later.

<Steps>
  <Step title="Prepare the project">
    ```bash
    mkdir deckops-quickstart && cd deckops-quickstart
    npm init -y
    npm install @deckops/sdk
    ```
  </Step>
  <Step title="Create an input">
    Save this as `sample.html`:

    ```html
    <!doctype html>
    <html><body><h1>Hello DeckOps</h1></body></html>
    ```
  </Step>
  <Step title="Create the script">
    Save this as `run.mjs`:

    ```js
    import { createDeck } from '@deckops/sdk';

    const deck = createDeck();
    const task = await deck.convertHtmlToPng({ files: ['./sample.html'] });

    // Guest tasks remain pending until explicitly started.
    await deck.tasks.start(task.id);
    const completed = await deck.tasks.wait(task.id, {
      timeout: 120,
      onProgress: (next) => console.error(next.status),
    });
    const result = await deck.tasks.down(completed.id);

    console.log(JSON.stringify({
      taskId: completed.id,
      type: completed.type,
      status: completed.status,
      result,
    }, null, 2));
    ```
  </Step>
  <Step title="Run and verify">
    ```bash
    node run.mjs
    ```

    A successful response has a non-empty task ID, `convertor.html2png`, `completed`, and a result tuple containing the PNG download URL, byte size, and hash:

    ```json
    {
      "taskId": "<task-id>",
      "type": "convertor.html2png",
      "status": "completed",
      "result": ["<download-url>", 8063, "<hash>"]
    }
    ```
  </Step>
</Steps>

Guest execution is rate-limited. Configure an API key or user token for production; authenticated tasks start automatically. See [Authentication](/deckops/authentication).

<Warning>
  The repository contains a newer Parse facade and typed Parse tasks, but the currently published `@deckops/sdk@0.7.3` artifact does not expose them. The Parse pages describe the source implementation and must not be treated as an installable npm contract until a corrected package is published.
</Warning>
