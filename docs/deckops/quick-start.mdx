---

This quickstart uses the CLI because it exposes the complete local workflow with no account or API key. DeckOps requires Node.js 22.18 or newer.

<Steps>
  <Step title="Install and verify the CLI">
    ```bash
    npm install -g @deckflow/deckops
    deckops --version
    deckops --help
    ```

    If global installation is not appropriate, replace `deckops` with `npx -y @deckflow/deckops@latest` in the following commands.
  </Step>
  <Step title="Download the sample document">
    ```bash
    curl -fL https://docs.deckflow.com/images/deckuse-sample.pptx -o sample.pptx
    ```

    The sample contains editable presentation text and is served with this documentation. You can replace it with your own PDF, PPTX, or DOCX after completing the workflow once.

    ```bash
    test -s sample.pptx
    ```

    Verify the download. On PowerShell, use the second form:

    ```powershell
    if (!(Test-Path sample.pptx) -or (Get-Item sample.pptx).Length -eq 0) { exit 1 }
    ```
  </Step>
  <Step title="Parse the source into an artifact">
    ```bash
    deckops parse sample.pptx --json
    ```

    A successful run reports `"op": "parse"`, `"engine": "local"`, `"irSchemaVersion": "deckir.v1"`, and an artifact path. The default path is `sample/`:

    ```text
    sample/
    ├── ir.json
    ├── manifest.json
    ├── probe.json
    └── assets/
    ```

    The sample can also produce an advisory preflight warning about embedded objects. Use `ok` and `quality` to determine parse success; keep `warnings` visible to the application separately.
  </Step>
  <Step title="Generate Markdown from the artifact">
    ```bash
    deckops convert sample/ --json
    ```

    The result reports `"reusedParse": true` and writes `sample/views/markdown/index.md`. The source PPTX is not parsed again.

    ```bash
    test -s sample/views/markdown/index.md
    ```
  </Step>
</Steps>

For a portable Markdown file outside the artifact, use the one-shot form:

```bash
deckops convert sample.pptx -o sample.md
```

This parses the document when needed and localizes referenced assets next to the output. Continue with [Parse documents](/deckops/parse) for format-specific options or [CLI](/deckops/cli) for automation and error handling.
