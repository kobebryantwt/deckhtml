The TypeScript SDK is the shortest path to DeckOps from either Node.js or a browser application.

<Steps>
  <Step title="Install the SDK">
    ```bash
    npm install @deckops/sdk
    ```
  </Step>
  <Step title="Create a client">
    An API key is recommended for production. Omit it to use rate-limited guest mode.

    ```ts
    import { createDeck } from '@deckops/sdk';

    const deck = createDeck({
      apiKey: process.env.DECKOPS_API_KEY,
    });
    ```
  </Step>
  <Step title="Parse a document">
    `parseDetailed()` uploads the file, selects a parser from its extension, waits for completion, downloads the structured result, and converts it to Markdown.

    ```ts
    const result = await deck.parseDetailed('./slides.pptx');

    console.log(result.markdown);
    console.log(result.taskId, result.type);
    ```
  </Step>
  <Step title="Run a typed conversion task">
    ```ts
    const task = await deck.convertPptToPdf({
      files: ['./slides.pptx'],
      name: 'slides',
    });

    const completed = await deck.tasks.wait(task.id, {
      onProgress: (next) => console.log(next.status),
    });
    const files = await deck.tasks.down<'convertor.ppt2pdf'>(completed.id);
    ```
  </Step>
</Steps>
