DeckOps is DeckFlow's cloud document-processing runtime. Upload a supported file or provide a URL, create an asynchronous task, then receive Markdown, a format-specific structured result, or a converted artifact.

| | DeckOps |
| --- | --- |
| Best for | Server-side parsing, extraction, conversion, and document workflows |
| Inputs | PDF, PPTX, DOCX, Keynote, supported conversion inputs, or an HTML URL |
| Results | Markdown, format-specific JSON, or files such as PDF, images, video, HTML, and PPTX |
| Runs | DeckFlow cloud |
| Interfaces | Published TypeScript task SDK and CLIs; Python and Go implementations currently require source checkout |
| Authentication | API key or user token; limited guest execution is available for low-level tasks |

```mermaid
flowchart LR
  I["File or URL"] --> U["Upload or materialize input"]
  U --> C["Create task"]
  C --> S["Start guest task when required"]
  S --> W["Wait by SSE or polling"]
  W --> R["Download result"]
```

## When to use DeckOps

- Parse PDF, PPTX, DOCX, or Keynote into Markdown for search, review, or AI pipelines.
- Retain format-specific structure such as slide geometry, notes, document elements, or PDF semantic roles.
- Convert supported documents into visual or editable artifacts.
- Run OCR, presentation inspection, compression, splitting, joining, font, image, or content tasks in the cloud.

DeckOps does not currently expose one cross-format public Document IR. The high-level `parse()` facade normalizes supported parse results to Markdown; low-level parse tasks preserve a different structured contract for each format. Read [Structured results](/deckops/structured-results) before storing or transforming those responses.

## A first cloud task

```ts
import { createDeck } from '@deckops/sdk';

const deck = createDeck();
const task = await deck.convertHtmlToPng({ files: ['./sample.html'] });
await deck.tasks.start(task.id); // required for a guest task
const completed = await deck.tasks.wait(task.id);
const result = await deck.tasks.down(completed.id);

console.log(completed.id, completed.type, completed.status);
console.log(result);
```

This published-package path uploads the file, explicitly starts a guest task, waits for completion, and downloads the result. Follow the [Quickstart](/deckops/quick-start) for a complete runnable example.

<Warning>
  The repository source implements `parse()`, `parseDetailed()`, and typed Parse tasks, but the current `@deckops/sdk@0.7.3` npm artifact does not expose them. Parse documentation is source-contract documentation until a corrected artifact is published. Python is not currently published to PyPI, and the Go module is not fetchable from its repository URL.
</Warning>

## Execution and data boundary

Files processed by DeckOps are uploaded to DeckFlow cloud. Authenticated tasks start automatically. A guest-created low-level task must be started explicitly before waiting; the high-level parse facade does not perform that guest start for you.

<Warning>
  Use an API key or user token with `parse()` and `parseDetailed()`. If you need guest mode, use the low-level task API and call `tasks.start(task.id)` after creation. The Python SDK does not currently expose this guest-start method.
</Warning>
