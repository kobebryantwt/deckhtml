The `@deckflow/deckuse` package exports two high-level entry points:

- `createDefaultExecutor()` creates an executor with the PPTX adapter and reserved adapters registered.
- `runCommand(input)` creates an executor and executes one complete command.

<Warning>
  The source API is implemented and tested, but the current `@deckflow/deckuse@1.0.0` registry package cannot resolve four private placeholder adapters in its dependency list. Develop against the cloned workspace until the published dependency set is corrected.
</Warning>

## Result contract

Commands resolve to a result envelope rather than throwing for expected command, format, workspace, validation, or transaction errors:

```ts
type Result<T> =
  | { ok: true; value: T; diagnostics: Diagnostic[] }
  | { ok: false; error: DeckuseError; diagnostics: Diagnostic[] };
```

Stable error codes include `INVALID_COMMAND`, `WORKSPACE_NOT_FOUND`, `ELEMENT_NOT_FOUND`, `FORMAT_NOT_IMPLEMENTED`, `VALIDATION_FAILED`, `TRANSACTION_CONFLICT`, and `IO_ERROR`.

## Initialize and inspect

```ts
import { runCommand } from '@deckflow/deckuse';

const workspaceId = '/absolute/path/customer-deck';

const initialized = await runCommand({
  version: '1.0',
  type: 'init',
  workspaceId,
  format: 'pptx',
  source: '/absolute/path/input.pptx',
});

if (!initialized.ok) throw new Error(initialized.error.message);

const inspected = await runCommand({
  version: '1.0',
  type: 'inspect',
  workspaceId,
  depth: 2,
});

if (!inspected.ok) throw new Error(inspected.error.message);
console.log(inspected.value);
```

## Query, mutate, and commit

Read the current revision from `inspect`, select a returned reference, and use both in the mutation:

```ts
const query = await runCommand({
  version: '1.0',
  type: 'query',
  workspaceId,
  selector: { kind: 'textbox', text: 'Revenue 2025' },
  limit: 10,
});

if (!query.ok || !Array.isArray(query.value) || query.value.length !== 1) {
  throw new Error('Expected one approved text box');
}

const target = query.value[0] as { ref: Record<string, unknown> };
const revision = (inspected.value as { document: { revision: string } }).document.revision;

const changed = await runCommand({
  version: '1.0',
  type: 'setText',
  workspaceId,
  transactionId: revision,
  ref: target.ref,
  text: 'Revenue 2026',
});

if (!changed.ok) throw new Error(changed.error.message);

const committed = await runCommand({
  version: '1.0',
  type: 'commit',
  workspaceId,
  transactionId: (changed.value as { revision: string }).revision,
  destination: '/absolute/path/updated.pptx',
});

if (!committed.ok) throw new Error(committed.error.message);
```

`runCommand()` can reopen an existing workspace by reading `.deckuse/manifest.json`, so these calls do not have to share one executor instance. Reuse `createDefaultExecutor()` when an application wants one explicit registry and execution context.

## Lower-level packages

The source workspace also exposes `@deckflow/deckuse-core`, `@deckflow/deckuse-opc`, and `@deckflow/deckuse-pptx`. They provide the command schema, `Executor`, adapter registry, OPC archive primitives, PPTX capabilities, index builder, and format adapter. Prefer the aggregate API unless you are implementing an adapter or integrating the protocol at a lower level.

Use [Command Reference](/deckuse/commands) for every command shape and [Selectors](/deckuse/selectors) for query behavior.
