title: DeckUse Quickstart
sidebarTitle: Quickstart
description: "Install DeckUse from source, inspect and replace text in a known PPTX, validate the workspace, and export the result."
---

This path runs entirely on your machine and requires no DeckFlow account or API key. It uses the source installation because the current public package has an incomplete published dependency set.

<Steps>
  <Step title="Check the runtime">
    Install Node.js 24 or later, pnpm 10, and Git.

    ```bash
    node --version
    pnpm --version
    git --version
    ```
  </Step>
  <Step title="Build and link the CLI">
    ```bash
    git clone https://github.com/deckflow/deckuse.git
    cd deckuse
    pnpm install
    pnpm install:global
    deckuse --help
    ```

    `pnpm install:global` builds every workspace package, deploys a self-contained production tree, and links the `deckuse` executable. The current `--version` output is an internal placeholder, so verify this build with `deckuse --help` rather than using the displayed version for dependency checks.
  </Step>
  <Step title="Download a known PPTX">
    ```bash
    curl -fL https://docs.deckflow.com/images/deckuse-sample.pptx \
      -o input.pptx
    ```

    The sample contains the text `Revenue 2025`, so the following query and replacement have a known match. You can substitute your own PPTX after completing this path once.
  </Step>
  <Step title="Create a workspace">
    ```bash
    deckuse init input.pptx ./workspace --json
    ```

    Success returns `{ "ok": true, ... }` and creates `workspace/package.pptx` plus the `.deckuse` manifest, index, media cache, and operation log.
  </Step>
  <Step title="Inspect the matching element">
    ```bash
    deckuse query ./workspace 'text=Revenue' --limit 10 --json
    ```

    Confirm that the result contains a text box whose `text` is `Revenue 2025`. Keep the returned `ref` when a later command must change one exact object.
  </Step>
  <Step title="Apply a reviewed replacement">
    Save this command as `replace.json`:

    ```json
    {
      "type": "replaceText",
      "find": "2025",
      "replace": "2026",
      "selector": "kind=textbox"
    }
    ```

    Apply it to the workspace:

    ```bash
    deckuse apply ./workspace --input replace.json --json
    ```

    The CLI supplies the protocol version, workspace ID, and current transaction revision for this top-level command. Check that `ok` is `true` and `value.matched` is greater than zero.
  </Step>
  <Step title="Validate and export">
    ```bash
    deckuse validate ./workspace --json
    deckuse commit ./workspace -o updated.pptx --json
    ```

    `commit` refuses to replace an existing destination unless `--force` is present.
  </Step>
  <Step title="Verify the exported file">
    ```bash
    deckuse init updated.pptx ./verification --json
    deckuse query ./verification 'text=2026' --limit 10 --json
    test -s updated.pptx
    ```

    In PowerShell, replace the final line with:

    ```powershell
    if (!(Test-Path updated.pptx) -or (Get-Item updated.pptx).Length -eq 0) { exit 1 }
    ```

    Package validation does not check visual layout. Open or render `updated.pptx` before shipping it.
  </Step>
</Steps>
