DeckUse performs focused, file-native changes to an existing PowerPoint presentation. It opens a PPTX as a temporary or persistent workspace, resolves selectors against slides and shapes, updates supported properties, and packages the workspace as another editable PPTX.

| Item | Current contract |
| --- | --- |
| Input | One `.pptx` file or initialized DeckUse workspace |
| Output | Updated `.pptx` file; read commands print structural information |
| Execution | Local Node.js process; no file upload and no authentication |
| Interfaces | Verified `deckuse` CLI; Node.js API source exists but the `0.2.0` ESM build has a runtime import issue |
| Runtime | Node.js 18 or later; `zip` and `unzip` commands for workspace packaging |

## Use DeckUse for

- Listing slides and inspecting slide structure.
- Reading text through slide, shape, text, or canonical ID-path selectors.
- Setting paragraph text or replacing text globally or on one slide.
- Moving selected slide shapes using normalized `left` and `top` positions.
- Keeping a workspace for several changes before committing one output file.

```text
input.pptx → open or initialize workspace → select existing content → change → commit → updated.pptx
```

<Warning>
  The current release is PPTX-only. It does not expose commands to add or delete slides or elements, and it does not edit DOCX, XLSX, or Keynote files. Preserve the original file and verify the output in PowerPoint or another compatible application.
</Warning>
