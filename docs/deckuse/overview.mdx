DeckUse is the Manipulate layer of the Deckflow stack. It operates on supported Office source files when the document must remain editable in its original format.

## Current focus

The current implementation focus is Office PPTX. It supports element-level operations such as modifying and deleting existing presentation objects.

## Use DeckUse when

- The Office file remains the system of record and final editable artifact.
- A workflow must update or remove existing elements rather than generate a derived representation.
- Changes need to respect source-format structures and relationships.

## Product boundary

Use [DeckOps](/deckops/overview) to Parse heterogeneous formats into Document IR, Extract semantic structure, Convert formats, or Render through the combined runtime. Use DeckUse when the operation is explicitly a source-aware Office manipulation.

DeckUse does not replace [DeckHTML](/deckhtml/overview), which starts from HTML as the native authoring source for a deck.
