The CLI exposes six workflow commands. Mutations such as `replaceText`, `setProperties`, `add`, and `remove` are JSON commands passed through `apply` rather than separate shell subcommands.

```text
deckuse <command> [arguments] [options]
```

Follow the [Quickstart](/deckuse/quick-start) for the currently verified source installation.

## Commands

| Command | Purpose |
| --- | --- |
| `init <input> <workspace>` | Import a document into a persistent workspace |
| `inspect <workspace>` | Return document capabilities and the indexed elements |
| `query <workspace> [selector]` | Filter indexed elements; defaults to `*` |
| `apply <workspace>` | Apply one JSON object, a JSON array, or JSON Lines |
| `validate <workspace>` | Check internal package relationships |
| `commit <workspace>` | Export the current package to a PPTX |

The help is available without a subcommand and per command:

```bash
deckuse --help
deckuse query --help
deckuse help apply
```

<Note>
  `deckuse --version` currently prints the CLI's `0.0.0` placeholder rather than the package release. Do not use it to enforce a minimum version until that value is wired to package metadata.
</Note>

## `init`

```bash
deckuse init input.pptx ./workspace --json
```

The positional arguments are the source file and destination workspace. The command parser recognizes `.pptx`, `.docx`, `.xlsx`, `.key`, and `.numbers`, but only PPTX has an implemented adapter; the other formats return `FORMAT_NOT_IMPLEMENTED`.

## `inspect`

```bash
deckuse inspect ./workspace --depth 2 --json
```

The result includes `document.revision`, current PPTX capabilities, and indexed elements with `ref`, `kind`, slide ID, text, geometry, location, and format-specific payload where available. `--depth` accepts `0` through `100`; the current PPTX adapter returns its complete flat index rather than pruning that list by depth.

## `query`

```bash
deckuse query ./workspace 'kind=textbox hasText=true' --limit 200 --json
deckuse query ./workspace 'text~=FY20[0-9]{2}' --limit 1000 --json
```

`--limit` defaults to `100` and accepts up to `10000`. See [Selectors](/deckuse/selectors) for the exact syntax and reference lifecycle.

## `apply`

Read one command from a file:

```bash
deckuse apply ./workspace --input change.json --json
```

Read from standard input, which is the default:

```bash
printf '%s\n' '{"type":"replaceText","find":"FY2025","replace":"FY2026"}' \
  | deckuse apply ./workspace --json
```

The input may be:

- One JSON command object.
- A JSON array of command objects, applied in order.
- JSON Lines, with one command object per non-empty line.

For each top-level input object, the CLI reads the workspace's latest revision and supplies `version`, `workspaceId`, and `transactionId`. It stops at the first failed command. Nested commands inside a `batch` still require their complete protocol fields; use the template in [Command Reference](/deckuse/commands#batch-and-dry-run).

## `validate`

```bash
deckuse validate ./workspace --level full --json
```

`--level` accepts `fast` or `full` and defaults to `full`. The current PPTX validator checks that internal relationships resolve to existing parts. It is not a renderer, visual check, or complete OOXML conformance validator.

## `commit`

```bash
deckuse commit ./workspace -o updated.pptx --json
deckuse commit ./workspace -o updated.pptx --force --json
```

Without `-o`, the output defaults to `<source-name>.deckuse.pptx` beside the original source. Existing destinations fail unless `--force` is supplied.

## Output and exit status

Every successful or failed DeckUse operation uses a result envelope:

```json
{
  "ok": true,
  "value": {},
  "diagnostics": []
}
```

| Exit status | Meaning |
| ---: | --- |
| `0` | The command completed with `ok: true` |
| `1` | A valid DeckUse command returned `ok: false` |
| `2` | CLI usage, file reading, or JSON parsing failed before execution |

By default JSON is indented. `--json` selects compact one-line JSON, which is more convenient for automation. Command-usage errors are written to standard error.
