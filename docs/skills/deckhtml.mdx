The DeckHTML skill is the agent-friendly packaging of the product's conversion workflow.

## Primary goal

Help an agent decide when to use DeckHTML and what output to request.

## A good skill page should answer

- What problem DeckHTML solves
- What inputs the agent needs before conversion
- Which outputs are supported
- How to recover when a conversion fails
