Deckflow MCP is now split into three hosted servers. Each server maps to a narrower product surface, so you can register only the tools you actually need in your MCP client.

<Note>
  File inputs use one shared convention. In the hosted MCP setup, use `http(s)` URLs or `fileId:<uploaded-file-id>` references because the remote server cannot read your local filesystem directly.
</Note>

## Server map

| Server | Endpoint | Best for |
| --- | --- | --- |
| `deckflow_html2pptx` | `https://mcp.deckflow.com/v1/html2pptx` | HTML slide rendering, PPTX export, preview images, and player packaging |
| `deckflow_pptx` | `https://mcp.deckflow.com/v1/pptx` | PPTX splitting, merging, font embedding, and inspection |
| `deckflow_tools` | `https://mcp.deckflow.com/v1/tools` | Cross-format conversion, OCR, image transforms, and compression |

## HTML-to-PPTX pipeline

| Tool | Purpose | Common inputs |
| --- | --- | --- |
| `html_to_pptx` | Convert HTML slide content into an editable PPTX deck. | `html`, `file`, `width`, `height`, `platform`, `needEmbedFonts` |
| `html_to_image` | Render HTML content or a page into image output. | `html`, `file`, `width`, `height`, `scale`, `fullPage` |
| `markdown_to_image` | Render Markdown content or a Markdown file to an image. | `markdown`, `file`, `theme`, `scale`, `pageWidth` |
| `build_html_player` | Package multiple HTML pages into a player experience. | `contents`, `pageWidth`, `pageHeight`, `title`, `description`, `brandMarkPosition` |

## PPTX file utilities

| Tool | Purpose | Common inputs |
| --- | --- | --- |
| `split_pptx` | Split a PPTX into individual or selected slide ranges. | `file`, `indexes`, `allowSize` |
| `merge_pptx` | Merge multiple PPTX files in order. | `files`, `hiddens`, `autoResize` |
| `embed_pptx_fonts` | Embed selected fonts into a PPTX. | `file`, `usedFonts` |
| `inspect_pptx` | Extract font or text-shape information from a PPTX. | `file`, `aspect`, `pickPages`, `includeLayout`, `includeMaster`, `includeNotes`, `onlyBrief` |

## General file tools

| Tool | Purpose | Common inputs |
| --- | --- | --- |
| `convert_file` | Convert supported files across PPT, PDF, Keynote, DOC, and related delivery formats. | `file`, `targetFormat`, `resolution`, `imageFormat` |
| `ocr_image` | Recognize text in an image. | `file`, `language` |
| `transform_image` | Resize an image or convert it to WebP. | `file`, `action`, `maxWidth`, `maxHeight` |
| `compress_file` | Compress videos and general files. | `file` |

## Recommended setup patterns

- Add only `deckflow_html2pptx` when your client mainly generates PPTX decks or preview images from HTML.
- Add `deckflow_html2pptx` and `deckflow_pptx` together when you also need to split, merge, inspect, or embed fonts after generation.
- Add all three servers when your workflow includes OCR, format conversion, image processing, or compression.
