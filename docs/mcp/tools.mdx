Deckflow MCP currently provides three hosted servers. Each server exposes four capability tools, and each endpoint also includes the same two support tools: `get_task` and `download_task_result`.

<Note>
  File inputs use one shared convention. In the hosted MCP setup, use `http(s)` URLs or `fileId:<uploaded-file-id>` references because the remote server cannot read your local filesystem directly.
</Note>

## Server map

| Server | Endpoint | Tool count | Best for |
| --- | --- | --- | --- |
| `deckflow-html2pptx` | `https://mcp.deckflow.com/v1/html2pptx` | 4 capability tools + 2 support tools | HTML slide rendering, PPTX export, preview images, and player packaging |
| `deckflow-pptx` | `https://mcp.deckflow.com/v1/pptx` | 4 capability tools + 2 support tools | PPTX splitting, merging, font embedding, and inspection |
| `deckflow-tools` | `https://mcp.deckflow.com/v1/tools` | 4 capability tools + 2 support tools | Cross-format conversion, OCR, image transforms, and compression |

## Shared support tools

These two tools appear in all three endpoint groups. MCP clients usually namespace them by server name, for example `deckflow-tools_get_task` or `deckflow-pptx_download_task_result`.

In normal usage, you usually do **not** need to fill every schema field. Start with the required inputs only, then add optional fields only when you need to control layout, language, output shape, or waiting behavior.

### `get_task`

Use this when a tool call times out or when you want to poll an existing task.

| Parameter | Type | Meaning |
| --- | --- | --- |
| `taskId` | `string` | Required task identifier |
| `wait` | `boolean` | Optional; when `true`, block until terminal state or timeout |
| `timeoutSeconds` | `number` | Optional; default `120`, max `600` |

### `download_task_result`

Use this to refresh or retrieve the final artifact for a completed task.

| Parameter | Type | Meaning |
| --- | --- | --- |
| `taskId` | `string` | Required task identifier |
| `resultType` | `html \| pptx \| image` | Optional output type hint |
| `savePath` | `string` | Optional; only meaningful in stdio mode for single-file outputs |

<Tip>
  Capability tools accept `waitSeconds`. For small jobs, they usually wait up to 120 seconds and return the artifact directly. If the task does not finish in time, continue with `get_task`, then use `download_task_result` when the task is complete.
</Tip>

## `deckflow-html2pptx`

Endpoint: `https://mcp.deckflow.com/v1/html2pptx`

| Tool | Purpose | Key parameters |
| --- | --- | --- |
| `html_to_pptx` | Convert HTML into an editable PPTX deck | `html` or `file`, `needEmbedFonts`, `platform`, `lang`, `width`, `height`, `waitSeconds` |
| `html_to_image` | Render HTML into a PNG screenshot | `html` or `file`, `scale`, `fullPage`, `width`, `height`, `waitSeconds` |
| `markdown_to_image` | Render Markdown into a PNG image | `markdown` or `file`, `theme`, `scale`, `pageWidth`, `waitSeconds` |
| `build_html_player` | Package multi-page inline HTML into a player | `contents`, `pageWidth`, `pageHeight`, `title`, `description`, `brandMarkPosition`, `waitSeconds` |

### Parameter usage

| Category | Applies to | What to do |
| --- | --- | --- |
| Minimum required | `html_to_pptx` | Provide exactly one of `html` or `file` |
| Minimum required | `html_to_image` | Provide exactly one of `html` or `file` |
| Minimum required | `markdown_to_image` | Provide exactly one of `markdown` or `file` |
| Minimum required | `build_html_player` | Provide `contents` |
| Input model | `html_to_pptx`, `html_to_image`, `markdown_to_image` | “Inline content” means pasting raw HTML or Markdown directly into the tool input instead of passing a file path or URL |
| Common optional | Rendering tools | Use `width`, `height`, `scale`, or `pageWidth` when you need to control canvas size or screenshot density |
| Common optional | All tools in this group | Use `waitSeconds` when you want the tool to wait longer before returning a task ID |
| Only when needed | `html_to_pptx` | Use `needEmbedFonts` when the exported PPTX must carry embedded fonts |
| Only when needed | `html_to_pptx` | `platform` is `mac` or `win` |
| Only when needed | `html_to_pptx` | `lang` supports `latin`, `sc`, `tc`, `jp`, `kr`, `ar`, `he` |
| Only when needed | `build_html_player` | `contents` must be inline HTML page content |

### Example prompts

| Tool | Example prompt |
| --- | --- |
| `html_to_pptx` | “Use Deckflow to convert this HTML page into an editable PPTX deck and keep the original slide layout.” |
| `html_to_image` | “Render this HTML page as a PNG preview image for review.” |
| `markdown_to_image` | “Turn this Markdown release note into a clean PNG image for sharing in chat.” |
| `build_html_player` | “Package these HTML slide sections into a browser-based player I can open and review.” |

## `deckflow-pptx`

Endpoint: `https://mcp.deckflow.com/v1/pptx`

| Tool | Purpose | Key parameters |
| --- | --- | --- |
| `split_pptx` | Split one PPTX into individual or selected slide outputs | `file`, `indexes`, `allowSize`, `waitSeconds` |
| `merge_pptx` | Merge multiple PPTX files in order | `files`, `hiddens`, `autoResize`, `waitSeconds` |
| `embed_pptx_fonts` | Embed selected fonts into a PPTX | `file`, `usedFonts`, `waitSeconds` |
| `inspect_pptx` | Extract font info or text-shape structure | `file`, `aspect`, `pickPages`, `includeLayout`, `includeMaster`, `includeNotes`, `ignoreEmptyText`, `onlyBrief`, `imageFilter`, `hasChildren`, `waitSeconds` |

### Parameter usage

| Category | Applies to | What to do |
| --- | --- | --- |
| Minimum required | `split_pptx` | Provide `file` |
| Minimum required | `merge_pptx` | Provide `files`, with at least 2 PPTX files |
| Minimum required | `embed_pptx_fonts` | Provide `file` |
| Minimum required | `inspect_pptx` | Provide `file` and `aspect` |
| Common optional | `split_pptx` | Use `indexes` only when you want selected slides; indexes are 0-based |
| Common optional | `embed_pptx_fonts` | Use `usedFonts` only when you want to embed a specific font set |
| Common optional | All tools in this group | Use `waitSeconds` when the file is large and you want the tool to wait longer |
| Only when needed | `inspect_pptx` | `aspect` is `fonts` or `texts` |
| Only when needed | `inspect_pptx` | Most optional inspection fields apply only when `aspect=texts` |

### Example prompts

| Tool | Example prompt |
| --- | --- |
| `split_pptx` | “Split this PPTX into separate slide files so I can review each page individually.” |
| `merge_pptx` | “Merge these two PPTX decks into one file and preserve their original order.” |
| `embed_pptx_fonts` | “Embed the fonts used in this PPTX so the deck displays consistently on other machines.” |
| `inspect_pptx` | “Inspect this PPTX and tell me which fonts it uses.” |

## `deckflow-tools`

Endpoint: `https://mcp.deckflow.com/v1/tools`

| Tool | Purpose | Key parameters |
| --- | --- | --- |
| `convert_file` | Convert supported files across Deckflow delivery formats | `file`, `targetFormat`, `resolution`, `imageFormat`, `waitSeconds` |
| `ocr_image` | Recognize text in an image | `file`, `language`, `waitSeconds` |
| `transform_image` | Resize an image or convert it to WebP | `file`, `action`, `maxWidth`, `maxHeight`, `waitSeconds` |
| `compress_file` | Compress a file or video | `file`, `waitSeconds` |

### Parameter usage

| Category | Applies to | What to do |
| --- | --- | --- |
| Minimum required | `convert_file` | Provide `file` and `targetFormat` |
| Minimum required | `ocr_image` | Provide `file` and `language` |
| Minimum required | `transform_image` | Provide `file` and `action` |
| Minimum required | `compress_file` | Provide `file` |
| Common optional | `convert_file` | Use `resolution` and `imageFormat` only when you need to control output quality or image format |
| Common optional | `transform_image` | Use `maxWidth` or `maxHeight` only when `action=resize` |
| Common optional | All tools in this group | Use `waitSeconds` for larger conversions |
| Only when needed | `convert_file` | `targetFormat` is `image`, `pdf`, `pptx`, `html`, or `video` |
| Only when needed | `convert_file` | `resolution` supports `1080`, `1920`, or `2560` |
| Only when needed | `convert_file` | `imageFormat` supports `png` or `jpg` |
| Only when needed | `ocr_image` | `language` supports: `ar`, `bg`, `cs`, `da`, `de`, `el`, `en`, `es`, `et`, `fi`, `fr`, `hu`, `id`, `it`, `ja`, `ko`, `lt`, `lv`, `nb`, `nl`, `pl`, `pt`, `ro`, `ru`, `sk`, `sl`, `sv`, `tr`, `uk`, `zh-hans`, `zh-hant` |
| Only when needed | `transform_image` | `action` is `resize` or `to_webp` |
| Only when needed | `transform_image` | `resize` requires at least one of `maxWidth` or `maxHeight` |

### Example prompts

| Tool | Example prompt |
| --- | --- |
| `convert_file` | “Convert this PDF into images so I can use each page as a visual asset.” |
| `ocr_image` | “Read the text from this screenshot and return the extracted content in English.” |
| `transform_image` | “Resize this image to a smaller width for web delivery.” |
| `compress_file` | “Compress this large file so it is easier to upload and share.” |

## Recommended setup patterns

- Register only `deckflow-html2pptx` when your client mainly generates PPTX decks or preview images from HTML.
- Register `deckflow-html2pptx` together with `deckflow-pptx` when you also need to split, merge, inspect, or embed fonts in PPTX files.
- Register all three servers when your workflow also includes OCR, format conversion, image processing, or compression.
