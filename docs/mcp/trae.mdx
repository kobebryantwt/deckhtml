Use this page to add Deckflow MCP in TRAE through the hosted Streamable HTTP endpoint and complete browser-based authorization.

<Note>
  Use the hosted HTTP endpoint in TRAE. It is the standard setup path and the easiest one to verify.
</Note>

## Open the MCP configuration entry

<Steps>
  <Step title="Open TRAE settings">
    In TRAE, click the settings icon in the top-right corner, then switch to the `MCP` tab.
  </Step>
  <Step title="Add a custom MCP server">
    In `MCP Servers`, click `Add`, then choose the manual configuration option. TRAE opens an editable `mcp.json` tab for the new server entry.
  </Step>
</Steps>

![TRAE MCP settings entry](/images/mcp/trae-mcp-entry.png)

## Add the hosted configuration

Paste this config into TRAE's `mcp.json` editor:

```json
{
  "mcpServers": {
    "deckflow": {
      "url": "https://mcp.deckflow.com/mcp/v1/"
    }
  }
}
```

## Hosted Streamable HTTP flow

<Steps>
  <Step title="Paste the hosted config">
    Use the hosted config shown above:

    ```json
    {
      "mcpServers": {
        "deckflow": {
          "url": "https://mcp.deckflow.com/mcp/v1/"
        }
      }
    }
    ```
  </Step>
  <Step title="Wait for the verification prompt">
    After saving the entry, TRAE shows the `deckflow` server in the MCP list. If authorization is still required, TRAE marks the server as needing verification and shows a link to continue the verification flow.
  </Step>
  <Step title="Complete authorization">
    Click the verification link, finish the browser authorization flow, then return to TRAE.
  </Step>
  <Step title="Confirm the server is ready">
    Once authorization succeeds, TRAE reports that verification completed successfully. You can then close the browser page and return to the MCP panel.
  </Step>
</Steps>

![TRAE verification required state](/images/mcp/trae-mcp-verify.png)

## What to try after setup

- Convert an HTML slide page into an editable PPTX deck.
- Convert a PPTX file into PDF or image outputs for sharing.
- Translate a PPTX, PDF, or DOCX file, including text inside images, while preserving layout where possible.
- Generate a first-draft presentation from a short brief plus reference files or URLs.

## Example prompts

```text
Use Deckflow MCP to convert this HTML page into an editable PPTX deck and return the download link.
```

```text
Convert this PPTX to PDF, then compress the result if it is still too large to share.
```

```text
Create a presentation for a live meeting from this brief and the attached PDF and Markdown references.
```

## Validation checklist

- TRAE shows the `deckflow` server as enabled in the MCP list.
- Hosted HTTP mode completes the verification step successfully.
- Deckflow tools are discoverable in the MCP tool list.
- A small utility call succeeds directly, or a long-running call returns a valid `taskId`.
- Completed tasks can be checked with `get_task` and downloaded with `download_task_result`.
