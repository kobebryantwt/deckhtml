Use this page to add Deckflow MCP in TRAE through the hosted Streamable HTTP endpoints and complete browser-based authorization.

<Note>
  Add one MCP server per endpoint in TRAE. Use `deckflow_html2pptx` for HTML rendering workflows, `deckflow_pptx` for PPTX post-processing, and `deckflow_tools` for general file utilities.
</Note>

## Set up Deckflow MCP in TRAE

<Steps>
  <Step title="Open the MCP settings">
    In TRAE, click the settings icon in the top-right corner, switch to the `MCP` tab, then choose `Add` and the manual configuration option. TRAE opens an editable `mcp.json` tab for the new server entry.
  </Step>
  <Step title="Paste the Deckflow server config">
    Add the hosted MCP configuration you need. A full setup looks like this:

    ```json
    {
      "mcpServers": {
        "deckflow_html2pptx": {
          "url": "https://mcp.deckflow.com/v1/html2pptx"
        },
        "deckflow_pptx": {
          "url": "https://mcp.deckflow.com/v1/pptx"
        },
        "deckflow_tools": {
          "url": "https://mcp.deckflow.com/v1/tools"
        }
      }
    }
    ```
  </Step>
  <Step title="Save and wait for the verification prompt">
    After saving the entry, TRAE shows the new Deckflow servers in the MCP list. If authorization is still required, TRAE marks each server as needing verification and shows a link to continue the verification flow.
  </Step>
  <Step title="Complete authorization">
    Click the verification link, finish the browser authorization flow, then return to TRAE.
  </Step>
  <Step title="Confirm the servers are ready">
    Once authorization succeeds, TRAE reports that verification completed successfully. You can then close the browser page and return to the MCP panel.
  </Step>
</Steps>

## What to try after setup

- Convert an HTML slide page into an editable PPTX deck.
- Render an HTML page or Markdown snippet into preview images.
- Split, merge, inspect, or embed fonts in PPTX files.
- Convert files, run OCR, resize images, or compress large outputs.

## Example prompts

```text
Use deckflow_html2pptx to convert this HTML page into an editable PPTX deck.
```

```text
Use deckflow_pptx to split this deck into single-slide PPTX files.
```

```text
Use deckflow_tools to convert this PDF into images and then compress them for sharing.
```

## Validation checklist

- TRAE shows the Deckflow servers you added as enabled in the MCP list.
- Hosted HTTP mode completes the verification step successfully.
- Deckflow tools are discoverable in the MCP tool list.
- HTML-to-PPTX, PPTX utilities, and general file tools are exposed under the expected server names.
