WorkBuddy can connect to Deckflow MCP so agent workflows can handle HTML-to-PPTX, format conversion, and presentation-processing tasks without dropping into separate scripts. WorkBuddy does not use a CLI-style `add mcp` command. Instead, you add Deckflow from the Connectors UI, paste the MCP config into WorkBuddy's config editor, then complete the authorization flow in the MCP manager.

<Note>
  The hosted MCP endpoint is the easiest WorkBuddy setup path. After authorization succeeds, WorkBuddy shows the Deckflow tool list directly inside the MCP manager.
</Note>

## Open the WorkBuddy MCP configuration entry

<Steps>
  <Step title="Open the Connectors area">
    In WorkBuddy, open the `Connectors` area from the top navigation. Then click `Custom Connector` to create a new MCP entry.
  </Step>
  <Step title="Open the MCP config editor">
    In the MCP manager, click `Configure MCP`. WorkBuddy opens the config file editor where you can paste the Deckflow MCP definition and save it.
  </Step>
</Steps>

![WorkBuddy MCP config entry](/images/mcp/workbuddy-mcp-entry.png)

## Add the Deckflow MCP config

Paste this config into WorkBuddy's MCP config editor:

```json
{
  "mcpServers": {
    "deckflow": {
      "url": "https://mcp.deckflow.com/mcp/v1/"
    }
  }
}
```

Save the file after the new server entry is added.

## Complete authorization

<Steps>
  <Step title="Return to the MCP manager">
    After the config is saved, WorkBuddy lists `deckflow` under `My MCP`.
  </Step>
  <Step title="Connect the server">
    If WorkBuddy marks the server as needing authentication, click `Connect` to start the authorization flow.
  </Step>
  <Step title="Finish verification">
    Complete the authorization flow in the browser, then return to WorkBuddy.
  </Step>
</Steps>

![WorkBuddy verification required state](/images/mcp/workbuddy-mcp-verify.png)

## Verify the Deckflow tools

After authorization succeeds, WorkBuddy expands the `deckflow` entry and shows the available MCP tools directly in the MCP manager.

![WorkBuddy Deckflow tools list](/images/mcp/workbuddy-mcp-tools.png)

## Prompt examples

```text
Use Deckflow MCP to convert this HTML page into an editable PPTX deck and return the download link.
```

```text
Convert this PPTX to PDF, then compress the result if it is still too large to share.
```

```text
Create a presentation for a live meeting from this brief and the attached PDF and Markdown references.
```

## Validation checklist

- WorkBuddy recognizes `deckflow` as an available MCP server.
- WorkBuddy no longer shows the `needs authentication` state after the connection is completed.
- Tool discovery shows the full Deckflow tool list in the MCP manager.
- The tool list includes generation, rendering, file utility, and task lifecycle tools.
- A completed task can be downloaded successfully from `download_task_result`.
