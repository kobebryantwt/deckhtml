Use this page to add Deckflow MCP in WorkBuddy. The normal path is to create a custom connector, paste the hosted MCP config, complete the authorization flow, and then confirm that WorkBuddy can see the Deckflow tools.

<Note>
  Hosted HTTP is the recommended WorkBuddy setup path. Add one MCP server per endpoint, then verify the tool lists directly in the MCP manager.
</Note>

## Open the WorkBuddy MCP configuration entry

<Steps>
  <Step title="Open the Connectors area">
    In WorkBuddy, open the `Connectors` area from the top navigation. Then click `Custom Connector` to create a new MCP entry.
  </Step>
  <Step title="Open the MCP config editor">
    In the MCP manager, click `Configure MCP`. WorkBuddy opens the config file editor where you can paste the Deckflow MCP definitions and save them.
  </Step>
</Steps>

![WorkBuddy MCP config entry](/images/mcp/workbuddy-mcp-entry.png)

## Add the Deckflow MCP config

Paste this config into WorkBuddy's MCP config editor:

```json
{
  "mcpServers": {
    "deckflow_html2pptx": {
      "url": "https://mcp.deckflow.com/v1/html2pptx"
    },
    "deckflow_pptx": {
      "url": "https://mcp.deckflow.com/v1/pptx"
    },
    "deckflow_tools": {
      "url": "https://mcp.deckflow.com/v1/tools"
    }
  }
}
```

Save the file after the new server entries are added.

## Complete authorization

<Steps>
  <Step title="Return to the MCP manager">
    After the config is saved, WorkBuddy lists the new Deckflow servers under `My MCP`.
  </Step>
  <Step title="Connect the servers">
    If WorkBuddy marks a server as needing authentication, click `Connect` to start the authorization flow.
  </Step>
  <Step title="Finish verification">
    Complete the authorization flow in the browser, then return to WorkBuddy.
  </Step>
</Steps>

![WorkBuddy verification required state](/images/mcp/workbuddy-mcp-verify.png)

## Verify the Deckflow tools

After authorization succeeds, WorkBuddy expands each Deckflow entry and shows the available MCP tools directly in the MCP manager.

![WorkBuddy Deckflow tools list](/images/mcp/workbuddy-mcp-tools.png)

## What to try after setup

- Convert an HTML slide page into an editable PPTX deck.
- Render HTML or Markdown into preview images.
- Split, merge, inspect, or embed fonts in PPTX files.
- Convert files, run OCR, resize images, or compress large outputs.

## Example prompts

```text
Use deckflow_html2pptx to convert this HTML page into an editable PPTX deck.
```

```text
Use deckflow_pptx to inspect this presentation and list the fonts it uses.
```

```text
Use deckflow_tools to run OCR on this image and return the extracted text.
```

## Validation checklist

- WorkBuddy recognizes the Deckflow servers you added as available MCP servers.
- WorkBuddy no longer shows the `needs authentication` state after the connection is completed.
- Tool discovery shows the expected tool list under each Deckflow server entry.
- The tool list matches the HTML-to-PPTX, PPTX utility, and general file-tool groupings.
