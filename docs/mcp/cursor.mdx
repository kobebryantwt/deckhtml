Use this page to connect Deckflow MCP in Cursor. The focus here is setup: add the server, authenticate if required, confirm Cursor can see the tools, and then start using Deckflow from your editor workflow.

<Note>
  Cursor MCP setup can vary slightly by release, but the two common paths are the same: add the server from the UI, or edit the MCP config file directly.
</Note>

## Add the MCP server from Cursor settings

<Steps>
  <Step title="Open Cursor MCP settings">
    In Cursor, open Settings and go to the MCP or Tools & Integrations section.
  </Step>
  <Step title="Create a new MCP server entry">
    Add a custom MCP server named `deckflow`.
  </Step>
  <Step title="Use the Deckflow endpoint">
    Paste the hosted MCP URL:

    ```text
    https://mcp.deckflow.com/mcp/v1/
    ```
  </Step>
  <Step title="Complete authentication if required">
    If Cursor asks you to authorize the server in the browser, finish that step and return to the MCP panel.
  </Step>
</Steps>

## Alternative: edit Cursor MCP config directly

If Cursor opens or manages MCP entries through a JSON config file, add Deckflow like this:

```json
{
  "mcpServers": {
    "deckflow": {
      "url": "https://mcp.deckflow.com/mcp/v1/"
    }
  }
}
```

Use the Cursor-managed MCP config location for your environment, or the project-level MCP file when you want the setup to live with the repository.

## Verify the connection

After setup, check that:

- `deckflow` appears in Cursor's MCP list
- the server is enabled and authenticated
- Deckflow tools are available in chat or agent mode
