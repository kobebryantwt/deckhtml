Cursor can call Deckflow MCP tools from inside an editing workflow. This is useful when an agent is writing slide HTML, preparing source files, or coordinating document operations alongside code changes.

<Note>
  Cursor MCP configuration may vary by version. Use the hosted HTTP endpoint when your Cursor build supports remote MCP servers. Use local stdio when you need local file path access.
</Note>

## Hosted HTTP endpoint

```text
https://mcp.deckflow.com/mcp/v1/
```

Use one of these authentication paths:

| Method | When to use it |
|---|---|
| OAuth | Cursor supports remote MCP authorization in your environment. |
| `Authorization: Bearer <API key>` | Cursor or a proxy can send custom headers. |
| `?API_KEY=<key>` | Custom headers are not available. |

## Local stdio configuration

```json
{
  "mcpServers": {
    "deckflow": {
      "command": "node",
      "args": ["/absolute/path/deckflow-mcp/dist/entry/stdio.js"],
      "env": {
        "DECKFLOW_API_KEY": "<your-api-key>"
      }
    }
  }
}
```

Add `DECKFLOW_SPACE_ID` if you want Cursor to operate inside a fixed Deckflow space.

## Troubleshooting

| Symptom | Check |
|---|---|
| Cursor cannot read a local file | Use stdio mode, or upload the file and pass `fileId:<id>`. |
| Authorization fails | Prefer OAuth, or verify the API key header/query value. |
| Task does not finish before client timeout | Ask Cursor to call `get_task` later, or use a shorter `waitSeconds` and poll. |
