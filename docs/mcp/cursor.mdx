Use this page to connect Deckflow MCP in Cursor. The focus here is setup: add the servers you need, authenticate if required, confirm Cursor can see the tools, and then start using Deckflow from your editor workflow.

<Note>
  Cursor MCP setup can vary slightly by release, but the two common paths are the same: add the server from the UI, or edit the MCP config file directly.
</Note>

## Add the MCP servers from Cursor settings

<Steps>
  <Step title="Open Cursor MCP settings">
    In Cursor, open Settings and go to the MCP or Tools & Integrations section.
  </Step>
  <Step title="Create one or more MCP server entries">
    Add custom MCP servers such as `deckflow_html2pptx`, `deckflow_pptx`, and `deckflow_tools`.
  </Step>
  <Step title="Use the matching Deckflow endpoints">
    Paste the hosted MCP URLs you need:

    ```text
    https://mcp.deckflow.com/v1/html2pptx
    https://mcp.deckflow.com/v1/pptx
    https://mcp.deckflow.com/v1/tools
    ```
  </Step>
  <Step title="Complete authentication if required">
    If Cursor asks you to authorize the server in the browser, finish that step and return to the MCP panel.
  </Step>
</Steps>

## Alternative: edit Cursor MCP config directly

If Cursor opens or manages MCP entries through a JSON config file, add Deckflow like this:

```json
{
  "mcpServers": {
    "deckflow_html2pptx": {
      "url": "https://mcp.deckflow.com/v1/html2pptx"
    },
    "deckflow_pptx": {
      "url": "https://mcp.deckflow.com/v1/pptx"
    },
    "deckflow_tools": {
      "url": "https://mcp.deckflow.com/v1/tools"
    }
  }
}
```

Use the Cursor-managed MCP config location for your environment, or the project-level MCP file when you want the setup to live with the repository.

## Verify the connection

After setup, check that:

- the Deckflow servers you added appear in Cursor's MCP list
- each server is enabled and authenticated
- Deckflow tools are available in chat or agent mode

## Try a first task

```text
Use deckflow_html2pptx to turn this HTML page into an editable PPTX deck.
```

```text
Use deckflow_pptx to inspect this deck and show me the fonts used on each page.
```

```text
Use deckflow_tools to run OCR on this image and return the extracted text.
```
