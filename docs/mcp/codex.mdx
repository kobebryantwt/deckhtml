Use this page to connect Deckflow MCP in Codex. The goal here is simple: register one or more Deckflow MCP servers, confirm Codex can see them, and then start calling Deckflow tools from your normal coding workflow.

<Note>
  Codex configuration is stored in `~/.codex/config.toml` at user scope, and can also be overridden per project with `.codex/config.toml`.
</Note>

## Recommended setup

For most users, start from Codex settings and add the Deckflow servers there. If you prefer managing MCP entries in source-controlled config, add the same definitions directly to a Codex config file.

## Add the MCP servers from the Codex UI

<Steps>
  <Step title="Open MCP server settings">
    In Codex, open settings and go to the MCP Servers section.
  </Step>
  <Step title="Add one or more custom servers">
    Create MCP server entries such as `deckflow_html2pptx`, `deckflow_pptx`, and `deckflow_tools`.
  </Step>
  <Step title="Use the matching Deckflow endpoints">
    Register the hosted MCP servers you need:

    ```text
    https://mcp.deckflow.com/v1/html2pptx
    https://mcp.deckflow.com/v1/pptx
    https://mcp.deckflow.com/v1/tools
    ```
  </Step>
  <Step title="Complete authentication if prompted">
    If Codex opens a browser sign-in flow or asks for credentials, complete that step before returning to the MCP list.
  </Step>
</Steps>

## Alternative: edit `config.toml` directly

You can also define the Deckflow servers in your Codex config file:

```toml
[mcp_servers.deckflow_html2pptx]
url = "https://mcp.deckflow.com/v1/html2pptx"
enabled = true

[mcp_servers.deckflow_pptx]
url = "https://mcp.deckflow.com/v1/pptx"
enabled = true

[mcp_servers.deckflow_tools]
url = "https://mcp.deckflow.com/v1/tools"
enabled = true
```

Use `~/.codex/config.toml` for your personal setup, or `.codex/config.toml` inside a trusted project when you want project-scoped configuration.

## Verify the connection

After setup, confirm:

- the Deckflow servers you added appear in Codex MCP settings
- each server is enabled and connected
- Deckflow tools are available in a new Codex session

## Try a first task

```text
Use deckflow_html2pptx to convert this HTML slide page into an editable PPTX deck.
```

```text
Use deckflow_pptx to split this presentation into separate section files.
```

```text
Use deckflow_tools to convert this PDF into images for review.
```
