Use this page to connect Deckflow MCP in Codex. The goal here is simple: register the Deckflow server, confirm Codex can see it, and then start calling Deckflow tools from your normal coding workflow.

<Note>
  Codex configuration is stored in `~/.codex/config.toml` at user scope, and can also be overridden per project with `.codex/config.toml`.
</Note>

## Recommended setup

For most users, start from Codex settings and add the Deckflow server there. If you prefer managing MCP entries in source-controlled config, add the same server definition directly to a Codex config file.

## Add the MCP server from the Codex UI

<Steps>
  <Step title="Open MCP server settings">
    In Codex, open settings and go to the MCP Servers section.
  </Step>
  <Step title="Add a custom server">
    Create a new MCP server entry named `deckflow`.
  </Step>
  <Step title="Use the Deckflow endpoint">
    Register the hosted MCP server:

    ```text
    https://mcp.deckflow.com/mcp/v1/
    ```
  </Step>
  <Step title="Complete authentication if prompted">
    If Codex opens a browser sign-in flow or asks for credentials, complete that step before returning to the MCP list.
  </Step>
</Steps>

## Alternative: edit `config.toml` directly

You can also define Deckflow in your Codex config file:

```toml
[mcp_servers.deckflow]
url = "https://mcp.deckflow.com/mcp/v1/"
enabled = true
```

Use `~/.codex/config.toml` for your personal setup, or `.codex/config.toml` inside a trusted project when you want project-scoped configuration.

## Verify the connection

After setup, confirm:

- the `deckflow` server appears in Codex MCP settings
- the server is enabled and connected
- Deckflow tools are available in a new Codex session

## Try a first task

After the server is available, try one of these prompts:

```text
Use Deckflow MCP to convert this HTML slide page into an editable PPTX deck and return the download link.
```

```text
Use Deckflow MCP to convert this PPTX into PDF and tell me when the result is ready.
```

```text
Use Deckflow MCP to generate a presentation draft from this brief and the attached reference files.
```
