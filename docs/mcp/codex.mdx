Codex can use Deckflow MCP when a documentation, code, or automation task needs a generated presentation artifact. The MCP server gives the agent a structured tool surface instead of relying on ad hoc shell commands.

<Note>
  In hosted HTTP mode, pass URLs or `fileId:<uploaded-file-id>` values for files. Use local stdio mode when the MCP server must read local absolute file paths.
</Note>

## Connection options

<Tabs>
  <Tab title="Hosted HTTP">
    Add Deckflow as a remote MCP server:

    ```text
    https://mcp.deckflow.com/mcp/v1/
    ```

    Use OAuth if the Codex environment supports remote MCP authorization. Otherwise provide `Authorization: Bearer <API key>`, `X-Auth-Token: <user_... token>`, or `?API_KEY=<key>`.
  </Tab>
  <Tab title="Local stdio">
    Use this shape when configuring a local MCP server:

    ```json
    {
      "mcpServers": {
        "deckflow": {
          "command": "node",
          "args": ["/absolute/path/deckflow-mcp/dist/entry/stdio.js"],
          "env": {
            "DECKFLOW_API_KEY": "<your-api-key>"
          }
        }
      }
    }
    ```
  </Tab>
</Tabs>

## Good fits for Codex

<CardGroup cols={2}>
  <Card title="Render generated HTML" icon="code">
    Ask Codex to create or edit HTML slide content, then call `render_html` for PNG or PPTX output.
  </Card>
  <Card title="Turn specs into decks" icon="sparkles">
    Feed product notes, PRDs, or release notes into `generate_presentation`.
  </Card>
  <Card title="Translate generated documents" icon="languages">
    Use `translate_document` after a deck or document is created.
  </Card>
  <Card title="Inspect and repair files" icon="search">
    Use `inspect_pptx`, `embed_pptx_fonts`, `compress_file`, and format conversion tools during delivery checks.
  </Card>
</CardGroup>

## Agent workflow pattern

<Steps>
  <Step title="Create or identify an input">
    Codex can generate HTML, select a project document, or reference a URL or uploaded file ID.
  </Step>
  <Step title="Call the right Deckflow tool">
    Use `render_html` for HTML, `generate_presentation` for prompt-to-deck work, or `convert_file` for format conversion.
  </Step>
  <Step title="Track progress">
    If the tool returns `taskId`, call `get_task` until the status reaches a terminal state.
  </Step>
  <Step title="Return the artifact">
    Call `download_task_result`, then report the download URL and any relevant task metadata.
  </Step>
</Steps>

Use Deckflow MCP to render this HTML slide into a PPTX and give me the download link.
