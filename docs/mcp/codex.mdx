Use this page to connect Deckflow MCP in Codex-style environments. Hosted HTTP is the best default when the runtime supports remote MCP authorization; switch to local stdio only when the server must read local absolute file paths.

<Note>
  In hosted HTTP mode, pass URLs or `fileId:<uploaded-file-id>` values for files. Use local stdio only when local file path access is required.
</Note>

## Connection options

<Tabs>
  <Tab title="Hosted HTTP">
    Add Deckflow as a remote MCP server:

    ```text
    https://mcp.deckflow.com/mcp/v1/
    ```

    Use OAuth if the Codex environment supports remote MCP authorization. Otherwise provide `Authorization: Bearer <API key>`, `X-Auth-Token: <user_... token>`, or `?API_KEY=<key>`.
  </Tab>
  <Tab title="Local stdio">
    Use this shape when configuring a local MCP server:

    ```json
    {
      "mcpServers": {
        "deckflow": {
          "command": "node",
          "args": ["/absolute/path/deckflow-mcp/dist/entry/stdio.js"],
          "env": {
            "DECKFLOW_API_KEY": "<your-api-key>"
          }
        }
      }
    }
    ```
  </Tab>
</Tabs>

## Agent workflow pattern

<Steps>
  <Step title="Create or identify an input">
    Codex can generate HTML, select a project document, or reference a URL or uploaded file ID.
  </Step>
  <Step title="Call the right Deckflow tool">
    Use `render_html` for HTML, `generate_presentation` for prompt-to-deck work, or `convert_file` for format conversion.
  </Step>
  <Step title="Track progress">
    If the tool returns `taskId`, call `get_task` until the status reaches a terminal state.
  </Step>
  <Step title="Return the artifact">
    Call `download_task_result`, then report the download URL and any relevant task metadata.
  </Step>
</Steps>

## What to try after setup

- Convert an HTML slide page into an editable PPTX deck.
- Convert a PPTX file into PDF or image outputs for sharing.
- Translate a PPTX, PDF, or DOCX file, including text inside images, while preserving layout where possible.
- Generate a first-draft presentation from a short brief plus reference files or URLs.
