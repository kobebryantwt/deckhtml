Use this page to connect Deckflow MCP in Claude Code. This is primarily a setup guide: add the Deckflow servers you need, authenticate them, confirm the connection, and then start using Deckflow tools inside Claude Code.

<Note>
  Claude Code supports the cleanest CLI-based setup path of the current agent guides, so it is usually the fastest place to get Deckflow MCP running.
</Note>

## Prerequisites

- Claude Code installed
- A Deckflow account or API key, depending on the connection mode you choose

## Add the MCP servers with the CLI

Run these in your terminal:

```bash
claude mcp add --transport http deckflow_html2pptx https://mcp.deckflow.com/v1/html2pptx
claude mcp add --transport http deckflow_pptx https://mcp.deckflow.com/v1/pptx
claude mcp add --transport http deckflow_tools https://mcp.deckflow.com/v1/tools
```

To make the servers available across all projects, use user scope:

```bash
claude mcp add --scope user --transport http deckflow_html2pptx https://mcp.deckflow.com/v1/html2pptx
claude mcp add --scope user --transport http deckflow_pptx https://mcp.deckflow.com/v1/pptx
claude mcp add --scope user --transport http deckflow_tools https://mcp.deckflow.com/v1/tools
```

To share the servers with the current project through `.mcp.json`, use project scope:

```bash
claude mcp add --scope project --transport http deckflow_html2pptx https://mcp.deckflow.com/v1/html2pptx
claude mcp add --scope project --transport http deckflow_pptx https://mcp.deckflow.com/v1/pptx
claude mcp add --scope project --transport http deckflow_tools https://mcp.deckflow.com/v1/tools
```

## Alternative: edit config directly

You can also add the hosted servers by editing Claude Code config yourself.

User-scoped example in `~/.claude.json`:

```json
{
  "mcpServers": {
    "deckflow_html2pptx": {
      "type": "http",
      "url": "https://mcp.deckflow.com/v1/html2pptx"
    },
    "deckflow_pptx": {
      "type": "http",
      "url": "https://mcp.deckflow.com/v1/pptx"
    },
    "deckflow_tools": {
      "type": "http",
      "url": "https://mcp.deckflow.com/v1/tools"
    }
  }
}
```

Project-scoped example in `.mcp.json`:

```json
{
  "mcpServers": {
    "deckflow_html2pptx": {
      "type": "http",
      "url": "https://mcp.deckflow.com/v1/html2pptx"
    },
    "deckflow_pptx": {
      "type": "http",
      "url": "https://mcp.deckflow.com/v1/pptx"
    },
    "deckflow_tools": {
      "type": "http",
      "url": "https://mcp.deckflow.com/v1/tools"
    }
  }
}
```

## Authentication

After adding the hosted servers, open Claude Code and run:

```text
/mcp
```

If a server requires sign-in, Claude Code will prompt you to finish the browser-based authorization flow.

## Verify the connection

You can verify from either side:

```bash
claude mcp list
```

Or inside Claude Code:

```text
/mcp
```

You should see the Deckflow servers you added listed and connected.
