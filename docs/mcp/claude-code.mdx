Use this page to connect Deckflow MCP in Claude Code. This is primarily a setup guide: add the Deckflow server, authenticate it, confirm the connection, and then start using Deckflow tools inside Claude Code.

<Note>
  Claude Code supports the cleanest CLI-based setup path of the current agent guides, so it is usually the fastest place to get Deckflow MCP running.
</Note>

## Prerequisites

- Claude Code installed
- A Deckflow account or API key, depending on the connection mode you choose

## Add the MCP server with the CLI

Run this in your terminal:

```bash
claude mcp add --transport http deckflow https://mcp.deckflow.com/mcp/v1/
```

To make the server available across all projects, use user scope:

```bash
claude mcp add --scope user --transport http deckflow https://mcp.deckflow.com/mcp/v1/
```

To share the server with the current project through `.mcp.json`, use project scope:

```bash
claude mcp add --scope project --transport http deckflow https://mcp.deckflow.com/mcp/v1/
```

## Alternative: edit config directly

You can also add the hosted server by editing Claude Code config yourself.

User-scoped example in `~/.claude.json`:

```json
{
  "mcpServers": {
    "deckflow": {
      "type": "http",
      "url": "https://mcp.deckflow.com/mcp/v1/"
    }
  }
}
```

Project-scoped example in `.mcp.json`:

```json
{
  "mcpServers": {
    "deckflow": {
      "type": "http",
      "url": "https://mcp.deckflow.com/mcp/v1/"
    }
  }
}
```

## Authentication

After adding the hosted server, open Claude Code and run:

```text
/mcp
```

If the server requires sign-in, Claude Code will prompt you to finish the browser-based authorization flow.

## Verify the connection

You can verify from either side:

```bash
claude mcp list
```

Or inside Claude Code:

```text
/mcp
```

You should see `deckflow` listed and connected.
