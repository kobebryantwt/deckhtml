---
title: 将 IR 转换为 Markdown
sidebarTitle: 转换为 Markdown
description: "从已有 DeckOps 产物生成 Markdown，不重复解析源文档。"
---

`convert` 从 DeckIR 派生视图，当前支持的目标是 Markdown。输入为产物目录时，DeckOps 读取 `ir.json`，不会再次打开或解析原文档。

## 转换已有产物

```bash
deckops convert report/
```

默认写入 `report/views/markdown/index.md`，并在 `manifest.json` 中记录渲染器、参数、输出文件和创建时间。

指定其他输出位置：

```bash
deckops convert report/ -o output/report.md
```

写入标准输出：

```bash
deckops convert report/ -o -
```

## 一次性转换

也可以直接传入文档：

```bash
deckops convert report.pdf -o report.md
```

这相当于先解析文档，再转换得到的 IR。如果应用还要检查 `ir.json`、生成多个视图或以后复用解析结果，应使用分成两步的流程。

## 保留来源上下文

PDF 可以为每个元素增加包含稳定节点 ID 的来源注释：

```bash
deckops convert report/ --anchors -o report.md
```

PPTX 和 Keynote 可以按页或幻灯片拆分 Markdown：

```bash
deckops convert slides/ --split-pages
```

云端转换返回短期图片链接时，DeckOps 默认拒绝无法完整本地化的结果。`--keep-remote-images` 表示应用明确接受这些临时链接：

```bash
deckops convert cloud-artifact/ --keep-remote-images
```

<Warning>
  云端签名图片 URL 只适合临时预览。链接过期前，请把需要长期使用的资源保存到应用自己的存储中。
</Warning>

## 在自动化中确认复用

```bash
deckops convert report/ --json
```

确认响应包含 `"ok": true`、`"op": "convert"` 和 `"reusedParse": true`。`outputs` 数组会列出每个写入文件及其字节数。
