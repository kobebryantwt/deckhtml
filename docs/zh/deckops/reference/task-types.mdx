以下标识可以用于通用任务 API 或 `deckops run`。

| 分类 | 任务类型 |
| --- | --- |
| 文件与图片 | `file.compress`、`video.compress`、`image.ocr`、`image.convertWebp`、`image.resize` |
| PPTX | `pptx.split`、`pptx.join`、`pptx.getFontInfo`、`pptx.getTextShapes`、`pptx.embedFonts` |
| 演示文稿转换 | `convertor.ppt2image`、`convertor.ppt2pptx`、`convertor.ppt2pdf`、`convertor.ppt2video` |
| 文档转换 | `convertor.doc2pdf`、`convertor.pdf2image` |
| Keynote 转换 | `convertor.keynote2image`、`convertor.keynote2html`、`convertor.keynote2pdf` |
| HTML 与 Markdown | `convertor.html2png`、`convertor.markdown2png`、`convertor.html2pptx`、`html.buildPlayer` |
| Parse | `pdf.parse`、`pptx.parse`、`docx.parseTextAndImage`、`keynote.parseTextAndImage`、`html.getByURL` |
| 内容工作流 | `generation`、`translation`、`revamp` |

## 结果行为

- 生成文件的任务通常返回单个文件元组或文件元组列表，包括路径、字节数、Hash，部分转换还带页面 Bounds。
- `convertor.html2pptx` 返回目标文件和转换期间使用的字体。
- Parse 任务返回格式专属结构化对象。
- Generation 和 Revamp 下载时可以选择 `html`、`pptx` 或 `image`。

<Warning>
  每个任务类型的参数和结果结构不同。使用 SDK 的 `DeckTaskTypeParams` 和 `DeckTaskTypeResult` 类型，不要向所有任务发送相同参数对象。
</Warning>
