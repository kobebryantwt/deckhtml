这条路径会创建一个已知 HTML 输入，上传到 DeckFlow 云端，显式启动游客任务，并验证返回的 PNG 元数据。它适用于当前已发布的 `@deckops/sdk@0.7.3`，需要 Node.js 18 或更高版本。

<Steps>
  <Step title="准备项目">
    ```bash
    mkdir deckops-quickstart && cd deckops-quickstart
    npm init -y
    npm install @deckops/sdk
    ```
  </Step>
  <Step title="创建输入">
    保存为 `sample.html`：

    ```html
    <!doctype html>
    <html><body><h1>Hello DeckOps</h1></body></html>
    ```
  </Step>
  <Step title="创建脚本">
    保存为 `run.mjs`：

    ```js
    import { createDeck } from '@deckops/sdk';

    const deck = createDeck();
    const task = await deck.convertHtmlToPng({ files: ['./sample.html'] });

    // 游客任务会保持 pending，必须显式启动。
    await deck.tasks.start(task.id);
    const completed = await deck.tasks.wait(task.id, {
      timeout: 120,
      onProgress: (next) => console.error(next.status),
    });
    const result = await deck.tasks.down(completed.id);

    console.log(JSON.stringify({
      taskId: completed.id,
      type: completed.type,
      status: completed.status,
      result,
    }, null, 2));
    ```
  </Step>
  <Step title="运行并验证">
    ```bash
    node run.mjs
    ```

    成功响应包含非空任务 ID、`convertor.html2png`、`completed`，以及由 PNG 下载地址、字节数和哈希组成的结果元组：

    ```json
    {
      "taskId": "<task-id>",
      "type": "convertor.html2png",
      "status": "completed",
      "result": ["<download-url>", 8063, "<hash>"]
    }
    ```
  </Step>
</Steps>

游客执行存在限频。生产环境请配置 API Key 或用户 Token；已认证任务会自动启动。详见[认证](/zh/deckops/authentication)。

<Warning>
  仓库源码包含更新的 Parse Facade 和类型化 Parse 任务，但当前已发布的 `@deckops/sdk@0.7.3` 产物没有暴露这些接口。在修正后的软件包发布前，Parse 页面描述的是源码实现，不能视为可安装的 npm 契约。
</Warning>
