## 安装

```bash
npm install -g @deckflow/deckops
deckops --version
deckops --help
```

DeckOps 需要 Node.js 22.18 或更高版本。只运行一次时，可用 `npx -y @deckflow/deckops@latest` 代替全局安装。

## 命令

| 命令 | 用途 |
| --- | --- |
| `deckops <input>` | `deckops parse <input>` 的简写 |
| `deckops parse <input>` | 把文档解析成 IR 产物 |
| `deckops convert <input>` | 把产物转换为 Markdown，或一次性解析并转换文档 |
| `deckops formats` | 输出当前安装版本已经实现的路径 |
| `deckops auth login\|status\|logout` | 管理 DeckFlow 共享云端凭证 |
| `deckops config list\|set\|migrate` | 查看默认值、设置产品参数或迁移旧配置 |

`extract`、`modify` 和 `export` 是预留的 API 方向，不是当前可用的 CLI 命令。

## 输入与输出

```bash
# 文件写入默认产物目录
deckops parse report.pdf

# 文件写入指定产物目录
deckops parse slides.pptx -o build/slides-ir

# 标准输入必须声明源格式
deckops parse - --from pdf -o build/report-ir < report.pdf

# URL 源码
deckops parse https://example.com/article --mode source -o build/article-ir

# 产物转换到标准输出
deckops convert build/report-ir -o -
```

## 解析与转换参数

<AccordionGroup>
  <Accordion title="PDF">
    `--profile fast|balanced|quality`、`--password`、`--no-images`、`--page-furniture off|drop|extract` 和 `--overlaid-text auto|keep|drop`。转换时使用 `--anchors`，可以在 Markdown 中加入节点来源注释。
  </Accordion>
  <Accordion title="DOCX">
    `--tracked-changes final|original|all` 用于选择修订内容视图。
  </Accordion>
  <Accordion title="PPTX 与 Keynote">
    `--split-pages` 按页生成 Markdown。Keynote 使用云端引擎，还接受 `--stay-image-area-rate 0..1`。
  </Accordion>
  <Accordion title="URL">
    `--mode source|runtime` 用于选择获取 HTML 源码，或在云端读取运行时 HTML。
  </Accordion>
</AccordionGroup>

使用 `deckops parse --help` 和 `deckops convert --help` 查看当前安装版本支持的准确参数。

## 引擎与上传许可

```bash
deckops parse report.pdf --engine local
deckops parse report.pdf --engine cloud
deckops parse report.pdf --engine auto
deckops parse report.pdf --engine auto --allow-upload
```

`auto` 本身不授予上传权限。没有 `--allow-upload` 时，DeckOps 会把文档留在本地，仅在质量降级时建议使用云端。

## 机器可读自动化

```bash
deckops parse report.pdf --json > parse-result.json
deckops convert report/ --json > convert-result.json
```

成功结果包含 `ok`、`op`、`engine`、`format`、产物或输出路径、警告和耗时。错误结果包含稳定的 `error.code`、说明以及通常可直接执行的修复提示。详情见 [CLI 结果与错误](/zh/deckops/reference/results-and-errors)。

只希望输出错误时使用 `--quiet`；需要跳过兼容产物复用时使用 `--force`。CLI 还提供源文件大小、OOXML 展开大小、ZIP 条目、单个/全部资源、URL 响应和 Worker 堆内存限制；只有在应用已经接受该输入后才应调高限制。
