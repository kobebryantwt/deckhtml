```bash
npm install @deckflow/deckops
```

Node.js 入口需要 Node.js 22.18 或更高版本。它默认本地执行，只有实际选择云端路径时才会初始化云端 Client。

## 解析与转换

```ts
import { parse, type DeckIR } from '@deckflow/deckops';

const document = await parse('slides.pptx');
const ir = await document.ir() as DeckIR;
const result = await document.convert({ splitPages: true });

console.log(document.dir);
console.log(ir.schemaVersion);
console.log(result.outputs);
```

`parse()` 返回 `ParsedDocument`，而不是 Markdown 字符串。该对象包含产物目录、manifest、可选云端 `irKey`、预检摘要、完整预检报告、IR 和转换方法。

## 不重新解析，直接打开产物

```ts
import { openArtifact } from '@deckflow/deckops';

const document = await openArtifact('slides/');
await document.convert();
```

## 使用配置后的 Client

```ts
import { createClient } from '@deckflow/deckops';

const client = createClient({
  apiKey: process.env.DECKOPS_API_KEY,
  spaceId: process.env.DECKOPS_SPACE_ID,
});

const local = await client.parse('report.pdf', {
  engine: 'local',
  profile: 'balanced',
  preflight: 'validate',
  out: 'artifacts/report',
});

const envelope = await client.convert('artifacts/report', {
  anchors: true,
  out: 'output/report.md',
});
```

调用方只需要完整机器结果而不需要文档对象时，使用 `parseEnvelope()`：

```ts
const result = await client.parseEnvelope('contract.docx', {
  trackedChanges: 'final',
});

console.log(result.artifact, result.quality, result.inspection);
```

## 处理类型化错误

```ts
import { DeckOpsError, parse } from '@deckflow/deckops';

try {
  await parse('report.pdf', { failOnDegraded: true });
} catch (error) {
  if (error instanceof DeckOpsError) {
    console.error(error.code, error.message, error.hint, error.taskId);
  }
}
```

稳定错误代码可区分参数错误、不支持的格式、认证、调用方可修复的 IR/输入问题、云端失败、尚不可用的操作和额度不足。
