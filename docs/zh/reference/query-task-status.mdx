无论是生成、翻译、焕新还是工具类任务，最终都使用这个接口查询执行状态。

## 这个接口会返回什么

- 当前 `status`
- 原始任务元数据
- 可用时返回的 `result`
- 任务完成后的 `result.url`

## 标准轮询流程

<Steps>
  <Step title="保存任务 ID">
    从 `POST /tools/tasks` 的返回结果中读取 `id`。
  </Step>
  <Step title="持续查询直到任务结束">
    使用 `GET /tools/tasks/{id}` 重复查询，直到任务进入 `completed` 或 `failed`。
  </Step>
  <Step title="读取结果链接">
    任务完成后，从返回结果中的 `result.url` 读取最终下载地址。
  </Step>
</Steps>

## 轮询示例

```bash
curl --location 'https://app.deckflow.com/api/tools/tasks/task-uuid-string' \
  --header 'Authorization: Bearer <YOUR_API_KEY>'
```

```js
const response = await fetch('https://app.deckflow.com/api/tools/tasks/task-uuid-string', {
  method: 'GET',
  headers: {
    Authorization: 'Bearer <YOUR_API_KEY>'
  }
});

const task = await response.json();
console.log(task.status, task.result?.url);
```

```python
import requests

response = requests.get(
    "https://app.deckflow.com/api/tools/tasks/task-uuid-string",
    headers={"Authorization": "Bearer <YOUR_API_KEY>"},
)

task = response.json()
print(task["status"])
print(task.get("result", {}).get("url"))
```

## Server-Sent Events (SSE)

官方文档说明，这个接口还支持基于同一路径的 SSE 实时流模式。只需要额外增加请求头：

```text
response-event-stream: yes
```

启用后，接口会返回 `text/event-stream`，服务端会以 `data: { ...taskJSON }` 的形式持续推送状态更新；当任务进入 `completed` 或 `failed` 时，连接会自动关闭。

## SSE 示例

```bash
curl --location 'https://app.deckflow.com/api/tools/tasks/task-uuid-string' \
  --header 'Authorization: Bearer <YOUR_API_KEY>' \
  --header 'response-event-stream: yes'
```

```js
const response = await fetch('https://app.deckflow.com/api/tools/tasks/task-uuid-string', {
  method: 'GET',
  headers: {
    Authorization: 'Bearer <YOUR_API_KEY>',
    'response-event-stream': 'yes'
  }
});

const reader = response.body.getReader();
const decoder = new TextDecoder();

while (true) {
  const { value, done } = await reader.read();
  if (done) break;
  console.log(decoder.decode(value, { stream: true }));
}
```

```python
import requests

with requests.get(
    "https://app.deckflow.com/api/tools/tasks/task-uuid-string",
    headers={
        "Authorization": "Bearer <YOUR_API_KEY>",
        "response-event-stream": "yes",
    },
    stream=True,
) as response:
    for line in response.iter_lines():
        if line:
            print(line.decode("utf-8"))
```

<Tip>
  默认优先使用普通 JSON 轮询即可。只有当你的客户端确实需要实时接收状态更新时，再切到 SSE。
</Tip>
