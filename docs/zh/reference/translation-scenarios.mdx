文档翻译也复用统一的异步任务接口，区别在于翻译场景会使用专门的任务类型和语言参数。

## 场景映射

| 字段 | 值 |
|---|---|
| 接口 | `POST /tools/tasks` |
| `type` | `translation` |
| 文件 | PPTX、Keynote、PDF、Word、Excel 等 |
| 查询接口 | `GET /tools/tasks/{id}` |

## 常见翻译参数

源站文档明确展示了以下字段：

- `from`
- `to`

这两个字段分别表示源语言和目标语言代码。

## `params` 示例

```json
{
  "from": "zh",
  "to": "en"
}
```

## 使用建议

- 原始文件通过 `files` 上传
- 即使源语言看起来很明显，也建议显式填写 `from`
- 完成后的结果文件链接会出现在任务详情结果中

<Tip>
  产品文档强调翻译类任务会尽量保留原有版式与视觉结构，适合用于演示文稿和排版较强的文档场景。
</Tip>
