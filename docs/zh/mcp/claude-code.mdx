本页重点说明如何在 Claude Code 中配置 Deckflow MCP。它主要是一份接入指南：添加所需的 Deckflow Server、完成授权、确认连接成功，然后开始在 Claude Code 中调用 Deckflow 工具。

<Note>
  在目前这些客户端里，Claude Code 的 CLI 接入路径最清晰，通常也是最快能把 Deckflow MCP 跑起来的方式。
</Note>

## 前置条件

- 已安装 Claude Code
- 你已经拥有 Deckflow 账号或可用的 API key

## 通过 CLI 添加 MCP Server

在终端中执行：

```bash
claude mcp add --transport http deckflow-html2pptx https://mcp.deckflow.com/v1/html2pptx
claude mcp add --transport http deckflow-pptx https://mcp.deckflow.com/v1/pptx
claude mcp add --transport http deckflow-tools https://mcp.deckflow.com/v1/tools
```

如果希望所有项目都可用，使用用户级作用域：

```bash
claude mcp add --scope user --transport http deckflow-html2pptx https://mcp.deckflow.com/v1/html2pptx
claude mcp add --scope user --transport http deckflow-pptx https://mcp.deckflow.com/v1/pptx
claude mcp add --scope user --transport http deckflow-tools https://mcp.deckflow.com/v1/tools
```

如果希望把配置落到当前项目的 `.mcp.json` 中并共享给团队，使用项目级作用域：

```bash
claude mcp add --scope project --transport http deckflow-html2pptx https://mcp.deckflow.com/v1/html2pptx
claude mcp add --scope project --transport http deckflow-pptx https://mcp.deckflow.com/v1/pptx
claude mcp add --scope project --transport http deckflow-tools https://mcp.deckflow.com/v1/tools
```

## 备选方式：直接编辑配置

你也可以不走 CLI，直接手动写入配置。

用户级 `~/.claude.json` 示例：

```json
{
  "mcpServers": {
    "deckflow-html2pptx": {
      "type": "http",
      "url": "https://mcp.deckflow.com/v1/html2pptx"
    },
    "deckflow-pptx": {
      "type": "http",
      "url": "https://mcp.deckflow.com/v1/pptx"
    },
    "deckflow-tools": {
      "type": "http",
      "url": "https://mcp.deckflow.com/v1/tools"
    }
  }
}
```

项目级 `.mcp.json` 示例：

```json
{
  "mcpServers": {
    "deckflow-html2pptx": {
      "type": "http",
      "url": "https://mcp.deckflow.com/v1/html2pptx"
    },
    "deckflow-pptx": {
      "type": "http",
      "url": "https://mcp.deckflow.com/v1/pptx"
    },
    "deckflow-tools": {
      "type": "http",
      "url": "https://mcp.deckflow.com/v1/tools"
    }
  }
}
```

## 完成授权

添加托管服务后，在 Claude Code 中运行：

```text
/mcp
```

如果服务需要浏览器授权，Claude Code 会在这里提示你继续完成认证。

## 验证连接

可以用命令行检查：

```bash
claude mcp list
```

也可以在 Claude Code 内查看：

```text
/mcp
```

理想状态下，你会看到你添加的 Deckflow Server 都已出现在列表中并处于已连接状态。
