Deckflow MCP 适合接入到常见智能体客户端中，重点解决 HTML 转 PPTX 演示文稿、格式转换，以及文件与 PPTX 处理这几类工作流。当前中文文档优先覆盖更常见的国内客户端接入方式。

<Note>
  生产环境托管端点为 `https://mcp.deckflow.com/mcp/v1/`。菜单名称会因客户端不同而略有差异，但整体流程通常都是：添加 MCP 配置、完成授权、再开始调用工具。
</Note>

## 你可以做什么

<CardGroup cols={2}>
  <Card title="HTML 转 PPTX 演示文稿" icon="code">
    将 HTML 页面、模板或组件内容直接转换成 PPTX，更适合 html2pptx 的自动化生成与交付场景。
  </Card>
  <Card title="格式转换" icon="repeat">
    在 PPTX、PDF、图片等格式之间转换，适合交付、预览、归档和分享流程。
  </Card>
  <Card title="文件和 PPTX 工具链" icon="file-cog">
    在同一个工作流里完成压缩、OCR、拆分、合并、嵌入字体和内容检查等处理。
  </Card>
  <Card title="生成、翻译和改写演示文稿" icon="sparkles">
    通过提示词和参考材料生成演示文稿，翻译包含图片内容的文档，并尽量保留和还原原始版式。
  </Card>
</CardGroup>
