本页重点说明如何在 Cursor 中配置 Deckflow MCP。重点不是介绍工作流模式，而是帮助你完成接入：添加所需服务器、完成授权、确认工具可见，然后开始使用 Deckflow。

<Note>
  Cursor 的 MCP 入口会因版本略有差异，但常见方式基本一致：要么通过设置页添加，要么直接编辑 MCP 配置文件。
</Note>

## 通过 Cursor 设置页添加

<Steps>
  <Step title="打开 Cursor 的 MCP 设置">
    在 Cursor 中进入 Settings，然后打开 MCP 或 Tools & Integrations 相关区域。
  </Step>
  <Step title="新增一个或多个自定义 MCP Server">
    创建类似 `deckflow_html2pptx`、`deckflow_pptx`、`deckflow_tools` 这样的服务器条目。
  </Step>
  <Step title="填写对应的 Deckflow 端点">
    按需使用这些托管地址：

    ```text
    https://mcp.deckflow.com/v1/html2pptx
    https://mcp.deckflow.com/v1/pptx
    https://mcp.deckflow.com/v1/tools
    ```
  </Step>
  <Step title="如有需要则完成授权">
    如果 Cursor 要求在浏览器中完成授权，先完成该流程，再返回 MCP 面板。
  </Step>
</Steps>

## 备选方式：直接编辑 MCP 配置

如果你的 Cursor 版本通过 JSON 文件管理 MCP 配置，可以直接写入：

```json
{
  "mcpServers": {
    "deckflow_html2pptx": {
      "url": "https://mcp.deckflow.com/v1/html2pptx"
    },
    "deckflow_pptx": {
      "url": "https://mcp.deckflow.com/v1/pptx"
    },
    "deckflow_tools": {
      "url": "https://mcp.deckflow.com/v1/tools"
    }
  }
}
```

把这段配置写入当前环境对应的 Cursor MCP 配置位置，或者写入项目级 MCP 文件中。

## 验证连接

配置完成后，确认：

- Cursor 的 MCP 列表中已经出现你添加的 Deckflow Server
- 每个服务状态都正常，且已完成授权
- 在 chat 或 agent 模式下可以发现 Deckflow 工具

## 先试一个任务

```text
使用 deckflow_html2pptx 把这个 HTML 页面转换成可编辑的 PPTX 演示文稿。
```

```text
使用 deckflow_pptx 检查这个演示文稿，并列出每页使用到的字体。
```

```text
使用 deckflow_tools 对这张图片执行 OCR，并返回识别出的文字。
```
