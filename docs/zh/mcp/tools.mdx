Deckflow MCP 当前分别提供 3 个托管 Server。每个 Server 对应一条更清晰的产品线，你可以只接入自己真正需要的工具。

<Note>
  文件输入遵循统一约定。在托管 MCP 接入方式下，应使用 `http(s)` URL 或 `fileId:<uploaded-file-id>`，因为远端服务无法直接读取你本机文件系统。
</Note>

## Server 对照表

| Server | 端点 | 适合的场景 |
| --- | --- | --- |
| `deckflow_html2pptx` | `https://mcp.deckflow.com/v1/html2pptx` | HTML 幻灯片渲染、PPTX 导出、预览图生成、播放器打包 |
| `deckflow_pptx` | `https://mcp.deckflow.com/v1/pptx` | PPTX 拆分、合并、检查、嵌入字体 |
| `deckflow_tools` | `https://mcp.deckflow.com/v1/tools` | 跨格式转换、OCR、图片处理、压缩 |

## HTML→PPTX 生产线

| 工具 | 作用 | 常见输入 |
| --- | --- | --- |
| `html_to_pptx` | 把 HTML 幻灯片内容转换成可编辑 PPTX。 | `html`, `file`, `width`, `height`, `platform`, `needEmbedFonts` |
| `html_to_image` | 把 HTML 内容或页面渲染成图片。 | `html`, `file`, `width`, `height`, `scale`, `fullPage` |
| `markdown_to_image` | 将 Markdown 内容或文件渲染成图片。 | `markdown`, `file`, `theme`, `scale`, `pageWidth` |
| `build_html_player` | 将多个 HTML 页面打包为播放器式体验。 | `contents`, `pageWidth`, `pageHeight`, `title`, `description`, `brandMarkPosition` |

## PPTX 文件处理

| 工具 | 作用 | 常见输入 |
| --- | --- | --- |
| `split_pptx` | 按页或指定范围拆分 PPTX。 | `file`, `indexes`, `allowSize` |
| `merge_pptx` | 按顺序合并多个 PPTX。 | `files`, `hiddens`, `autoResize` |
| `embed_pptx_fonts` | 把指定字体嵌入到 PPTX。 | `file`, `usedFonts` |
| `inspect_pptx` | 提取 PPTX 的字体、文本框或结构信息。 | `file`, `aspect`, `pickPages`, `includeLayout`, `includeMaster`, `includeNotes`, `onlyBrief` |

## 通用文件小工具

| 工具 | 作用 | 常见输入 |
| --- | --- | --- |
| `convert_file` | 在 PPT、PDF、Keynote、DOC 等交付格式之间转换文件。 | `file`, `targetFormat`, `resolution`, `imageFormat` |
| `ocr_image` | 识别图片中的文本。 | `file`, `language` |
| `transform_image` | 调整图片尺寸或转成 WebP。 | `file`, `action`, `maxWidth`, `maxHeight` |
| `compress_file` | 压缩视频或通用文件。 | `file` |

## 推荐接入组合

- 只需要 HTML 转 PPTX 或预览图时，只接入 `deckflow_html2pptx`
- 如果还需要额外做 PPTX 拆分、合并、检查或嵌入字体，就接入 `deckflow_pptx`
- 如果流程里还涉及 OCR、格式转换、图片处理或压缩，就接入 `deckflow_tools`
