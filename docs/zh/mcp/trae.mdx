本页重点说明如何在 TRAE 中通过托管的 Streamable HTTP 方式接入 Deckflow MCP，并完成浏览器授权。

<Note>
  在 TRAE 中，每个端点都应作为独立的 MCP Server 添加。`deckflow-html2pptx` 负责 HTML 渲染相关能力，`deckflow-pptx` 负责 PPTX 文件处理，`deckflow-tools` 负责通用文件小工具。
</Note>

## 在 TRAE 中完成 Deckflow MCP 配置

<Steps>
  <Step title="打开 MCP 设置">
    在 TRAE 右上角点击设置图标，切换到 `MCP` 标签页，然后点击 `Add` 并选择手动配置。TRAE 会打开一个可编辑的 `mcp.json` 标签页。
  </Step>
  <Step title="粘贴 Deckflow 配置">
    按需粘贴下面这组托管配置。完整接入方式如下：

    ```json
    {
      "mcpServers": {
        "deckflow-html2pptx": {
          "url": "https://mcp.deckflow.com/v1/html2pptx"
        },
        "deckflow-pptx": {
          "url": "https://mcp.deckflow.com/v1/pptx"
        },
        "deckflow-tools": {
          "url": "https://mcp.deckflow.com/v1/tools"
        }
      }
    }
    ```
  </Step>
  <Step title="保存并等待验证提示">
    保存后，TRAE 会在 MCP 列表中显示新加的 Deckflow Server。如果还没有完成授权，界面会提示当前服务需要验证，并提供继续验证的入口。
  </Step>
  <Step title="完成授权">
    点击验证入口，在浏览器中完成授权流程，然后回到 TRAE。
  </Step>
  <Step title="确认服务可用">
    授权成功后，TRAE 会提示验证已完成。此时可以关闭浏览器页面并回到 MCP 面板继续使用。
  </Step>
</Steps>

## 配置完成后先试这些

- 把一份 HTML 幻灯片页面转换成可编辑的 PPTX 演示文稿。
- 把 HTML 页面或 Markdown 内容渲染成预览图片。
- 对 PPTX 做拆分、合并、检查或嵌入字体。
- 做 OCR、格式转换、图片处理或压缩文件。

## 示例提示词

```text
使用 deckflow-html2pptx 把这份 HTML 页面转换成一份可编辑的 PPTX 演示文稿。
```

```text
使用 deckflow-pptx 把这个演示文稿按单页拆分成多个 PPTX 文件。
```

```text
使用 deckflow-tools 把这个 PDF 转成图片，并进一步压缩结果文件。
```

## 验证清单

- TRAE 在 MCP 列表中显示你添加的 Deckflow Server，且状态为已启用。
- 托管模式可以顺利完成验证流程。
- Deckflow 的工具能够在 MCP 工具列表中被发现。
- HTML→PPTX、PPTX 文件处理、通用文件工具这 3 组能力与配置的服务名一一对应。
