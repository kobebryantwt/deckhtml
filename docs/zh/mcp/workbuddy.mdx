本页重点说明如何在 WorkBuddy 中完成 Deckflow MCP 的接入。标准流程是创建自定义连接器、粘贴托管 MCP 配置、完成授权，然后确认 WorkBuddy 已经能看到 Deckflow 暴露的工具列表。

<Note>
  在 WorkBuddy 里，优先使用托管模式。每个端点都作为独立的 MCP Server 添加，授权完成后就能在 MCP 管理界面里看到对应工具列表。
</Note>

## 打开 WorkBuddy 的 MCP 配置入口

<Steps>
  <Step title="进入连接器区域">
    在 WorkBuddy 顶部导航中打开 `连接器`，然后点击 `自定义连接器`，创建新的 MCP 条目。
  </Step>
  <Step title="打开 MCP 配置编辑器">
    在 MCP 管理窗口中点击 `配置 MCP`。WorkBuddy 会打开配置文件编辑器，供你粘贴 Deckflow MCP 的配置内容并保存。
  </Step>
</Steps>

![WorkBuddy MCP config entry](/images/mcp/workbuddy-mcp-entry.png)

## 添加 Deckflow MCP 配置

将下面这段配置粘贴到 WorkBuddy 的 MCP 配置编辑器中：

```json
{
  "mcpServers": {
    "deckflow_html2pptx": {
      "url": "https://mcp.deckflow.com/v1/html2pptx"
    },
    "deckflow_pptx": {
      "url": "https://mcp.deckflow.com/v1/pptx"
    },
    "deckflow_tools": {
      "url": "https://mcp.deckflow.com/v1/tools"
    }
  }
}
```

粘贴后保存配置文件。

## 完成授权

<Steps>
  <Step title="返回 MCP 管理窗口">
    保存完成后，WorkBuddy 会在 `我的 MCP` 区域显示新加的 Deckflow Server。
  </Step>
  <Step title="连接服务">
    如果 WorkBuddy 提示某个服务还需要认证，点击 `连接` 按钮启动授权流程。
  </Step>
  <Step title="完成验证">
    在浏览器中完成授权，然后返回 WorkBuddy。
  </Step>
</Steps>

![WorkBuddy verification required state](/images/mcp/workbuddy-mcp-verify.png)

## 查看 Deckflow 工具列表

授权完成后，WorkBuddy 会展开每个 Deckflow 条目，并在 MCP 管理窗口中显示当前可用的工具列表。

![WorkBuddy Deckflow tools list](/images/mcp/workbuddy-mcp-tools.png)

## 配置完成后先试这些

- 把一份 HTML 幻灯片页面转换成可编辑的 PPTX 演示文稿。
- 把 HTML 或 Markdown 内容渲染成预览图片。
- 对 PPTX 做拆分、合并、检查或嵌入字体。
- 做 OCR、格式转换、图片处理或压缩文件。

## 示例提示词

```text
使用 deckflow_html2pptx 把这份 HTML 页面转换成一份可编辑的 PPTX 演示文稿。
```

```text
使用 deckflow_pptx 检查这个演示文稿，并列出它使用到的字体。
```

```text
使用 deckflow_tools 对这张图片执行 OCR，并返回识别出的文字。
```

## 验证清单

- WorkBuddy 能够识别你添加的 Deckflow Server。
- 完成连接后，界面不再显示需要认证的状态。
- MCP 管理窗口中能够看到每个 Deckflow Server 对应的工具列表。
- 工具列表与 HTML→PPTX、PPTX 文件处理、通用文件工具这 3 组能力一致。
