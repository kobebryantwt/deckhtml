## 从最终结果开始

DeckProbe 与 DeckUse 在本地执行。DeckRender 提供明确的本地、云端和本地优先自动选择；Browser SDK 仅接入云端。DeckOps 默认在本地解析 PDF、PPTX、DOCX 和静态网页源码，同时提供明确的云端路径和仅接入云端的 Browser SDK。DeckHTML 同时支持本地浏览器转换和云端模式。

## 比较执行边界

| 使用目标 | 产品 | 主要接入方式 | 认证 |
| --- | --- | --- | --- |
| 验证格式、数量、元数据、结构或风险信号 | [DeckProbe](/zh/deckprobe/overview) | CLI 和 JavaScript SDK | 不需要；文件留在本地 |
| 生成页面图片、PDF、缩略图或视频 | [DeckRender](/zh/deckrender/overview) | CLI、Node.js SDK 和 Browser SDK | 本地无需认证；云端支持游客或认证 |
| 把内容解析成可复用 DeckIR 和 Markdown | [DeckOps](/zh/deckops/overview) | CLI、Node.js SDK 和 Browser SDK | 本地无需认证；云端路径需要云端访问能力 |
| 检查现有 PPTX 并执行结构化修改 | [DeckUse](/zh/deckuse/overview) | CLI 和 Node.js SDK | 不需要；文件留在本地 |
| 从 HTML 或 SVG 生成 PPTX 或 PNG | [DeckHTML](/zh/deckhtml/overview) | CLI 和 Node.js SDK | 本地不需要；云端支持游客或认证 |

<Note>
  每个产品支持的格式和操作范围不同。某个产品能识别文件，不代表其他产品也能处理。选择路径前，请查看对应产品的支持格式或命令参考页。
</Note>
