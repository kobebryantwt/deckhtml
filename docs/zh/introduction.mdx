Deckflow 为文档工作流的不同阶段提供独立组件。先确定需要得到的结果，再进入相应产品文档。

<CardGroup cols={2}>
  <Card title="DeckProbe" href="/zh/deckprobe/overview">
    在本地或浏览器中嗅探 PDF、Microsoft Office 和现代 Apple iWork 文档。
  </Card>
  <Card title="DeckRender" href="/zh/deckrender/overview">
    将支持的文档格式渲染成页面或幻灯片画面。
  </Card>
  <Card title="DeckOps" href="/zh/deckops/overview">
    将不同格式解析成统一 Document IR，再进行 Extract、Convert 或 Render。
  </Card>
  <Card title="DeckUse" href="/zh/deckuse/overview">
    Manipulate 支持的 Office 源文件，并保持文件可继续编辑。
  </Card>
  <Card title="DeckHTML" href="/zh/deckhtml/overview">
    使用 HTML-native Deck Engine 生成演示文稿产物。
  </Card>
</CardGroup>

## 按任务选择

| 我需要…… | 建议从这里开始 |
| --- | --- |
| 识别文档并获取元数据、结构、安全或资源事实 | [DeckProbe](/zh/deckprobe/overview) |
| 生成缩略图、页面图片或幻灯片预览 | [DeckRender](/zh/deckrender/overview) |
| 将文档解析成统一 IR，或进行语义提取和格式转换 | [DeckOps](/zh/deckops/overview) |
| 修改或删除支持的 Office 源文件元素 | [DeckUse](/zh/deckuse/overview) |
| 从 HTML 生成 Deck | [DeckHTML](/zh/deckhtml/overview) |

需要详细比较时，继续阅读[选择产品](/zh/product-guide)；需要理解组件如何组成一套执行模型时，查看[运行时架构](/zh/runtime-architecture)。
