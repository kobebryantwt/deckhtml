本页重点说明如何在 WorkBuddy 中完成 DeckFlow MCP 的接入。标准流程是创建自定义连接器、粘贴托管 MCP 配置、完成首次信任确认，然后确认 WorkBuddy 已经能看到 DeckFlow 暴露的工具列表。

<Note>
  在 WorkBuddy 里，优先使用托管模式。每个端点都作为独立的 MCP Server 添加，首次连接时先完成信任确认，之后就能在 MCP 管理界面里看到对应工具列表。
</Note>

## 打开 WorkBuddy 的 MCP 配置入口

<Steps>
  <Step title="进入连接器区域">
    在 WorkBuddy 顶部导航中打开 `连接器`，然后点击 `自定义连接器`，创建新的 MCP 条目。
  </Step>
  <Step title="打开 MCP 配置编辑器">
    在 MCP 管理窗口中点击 `配置 MCP`。WorkBuddy 会打开配置文件编辑器，供你粘贴 DeckFlow MCP 的配置内容并保存。
  </Step>
</Steps>

![WorkBuddy MCP config entry](/images/mcp/workbuddy-mcp-entry.png)

## 添加 DeckFlow MCP 配置

将下面这段配置粘贴到 WorkBuddy 的 MCP 配置编辑器中：

```json
{
  "mcpServers": {
    "deckflow-html2pptx": {
      "url": "https://mcp.deckflow.com/v1/html2pptx"
    },
    "deckflow-pptx": {
      "url": "https://mcp.deckflow.com/v1/pptx"
    },
    "deckflow-tools": {
      "url": "https://mcp.deckflow.com/v1/tools"
    }
  }
}
```

粘贴后保存配置文件。

## 完成信任并启用服务

<Steps>
  <Step title="返回 MCP 管理窗口">
    保存完成后，WorkBuddy 会在 `我的 MCP` 区域显示新加的 DeckFlow Server。
  </Step>
  <Step title="信任每个服务">
    首次连接时，WorkBuddy 会要求你对每个 DeckFlow Server 做信任确认。分别点击 `信任`，允许 `deckflow-html2pptx`、`deckflow-pptx`、`deckflow-tools` 接入。
  </Step>
  <Step title="确认 3 个服务都已启用">
    信任完成后，WorkBuddy 会启用这 3 个 MCP Server，并显示各自的工具数量。
  </Step>
</Steps>

![WorkBuddy verification required state](/images/mcp/workbuddy-mcp-verify.png)

## 查看 DeckFlow 工具列表

信任完成并启用后，WorkBuddy 会展开每个 DeckFlow 条目，并在 MCP 管理窗口中显示当前可用的工具列表。

![WorkBuddy DeckFlow tools list](/images/mcp/workbuddy-mcp-tools.png)

## 配置完成后先试这些

- 把一份 HTML 幻灯片页面转换成可编辑的 PPTX 演示文稿。
- 把 HTML 或 Markdown 内容渲染成预览图片。
- 对 PPTX 做拆分、合并、检查或嵌入字体。
- 做 OCR、格式转换、图片处理或压缩文件。

## 示例提示词

```text
使用 deckflow-html2pptx 把这份 HTML 页面转换成一份可编辑的 PPTX 演示文稿。
```

```text
使用 deckflow-pptx 检查这个演示文稿，并列出它使用到的字体。
```

```text
使用 deckflow-tools 对这张图片执行 OCR，并返回识别出的文字。
```

## 验证清单

- WorkBuddy 能够识别你添加的 DeckFlow Server。
- 首次连接时的信任提示不再阻塞这 3 个服务的启用。
- MCP 管理窗口中每个 DeckFlow Server 下都能看到 6 个工具。
- 每组都包含 4 个能力工具，以及共享的 `get_task` 和 `download_task_result` 支撑工具。
