DeckFlow MCP 当前分别提供 3 个托管 Server。每个 Server 暴露 4 个能力工具，并且每个端点都会同时提供同样的 2 个支撑工具：`get_task` 和 `download_task_result`。

<Note>
  文件输入遵循统一约定。在托管 MCP 接入方式下，应使用 `http(s)` URL 或 `fileId:<uploaded-file-id>`，因为远端服务无法直接读取你本机文件系统。
</Note>

## Server 对照表

| Server | 端点 | 工具数量 | 适合的场景 |
| --- | --- | --- | --- |
| `deckflow-html2pptx` | `https://mcp.deckflow.com/v1/html2pptx` | 4 个能力工具 + 2 个支撑工具 | HTML 幻灯片渲染、PPTX 导出、预览图生成、播放器打包 |
| `deckflow-pptx` | `https://mcp.deckflow.com/v1/pptx` | 4 个能力工具 + 2 个支撑工具 | PPTX 拆分、合并、检查、嵌入字体 |
| `deckflow-tools` | `https://mcp.deckflow.com/v1/tools` | 4 个能力工具 + 2 个支撑工具 | 跨格式转换、OCR、图片处理、压缩 |

## 公共支撑工具

这两个工具会出现在 3 组端点里。很多 MCP 客户端会自动带上服务名命名空间，例如 `deckflow-tools_get_task` 或 `deckflow-pptx_download_task_result`。

正常使用时，你通常<strong>不需要把 schema 里所有字段都填满</strong>。建议先只填写必填参数；只有在你需要控制版式、语言、输出形态或等待时长时，再补充可选参数。

### `get_task`

当某个工具调用超时，或者你想主动轮询已有任务时，就使用它。

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `taskId` | `string` | 必填，任务 ID |
| `wait` | `boolean` | 可选；`true` 时阻塞等待到终态或超时 |
| `timeoutSeconds` | `number` | 可选；默认 `120`，最大 `600` |

### `download_task_result`

当任务已经完成，需要重新获取产物地址或刷新下载链接时，使用它。

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `taskId` | `string` | 必填，任务 ID |
| `resultType` | `html \| pptx \| image` | 可选，产物形态提示 |
| `savePath` | `string` | 可选；仅 stdio 模式、且单文件产物时有意义 |

<Tip>
  各个能力工具都支持 `waitSeconds`。小任务通常会默认等待最多 120 秒并直接返回产物；如果超时，不代表失败，而是继续用 `get_task` 查询，完成后再用 `download_task_result` 获取结果。
</Tip>

## `deckflow-html2pptx`

端点：`https://mcp.deckflow.com/v1/html2pptx`

| 工具 | 作用 | 关键参数 |
| --- | --- | --- |
| `html_to_pptx` | 把 HTML 转换成可编辑 PPTX | `html` 或 `file`、`needEmbedFonts`、`platform`、`lang`、`width`、`height`、`waitSeconds` |
| `html_to_image` | 把 HTML 渲染成 PNG 截图 | `html` 或 `file`、`scale`、`fullPage`、`width`、`height`、`waitSeconds` |
| `markdown_to_image` | 把 Markdown 渲染成 PNG 图片 | `markdown` 或 `file`、`theme`、`scale`、`pageWidth`、`waitSeconds` |
| `build_html_player` | 把多页内联 HTML 打包为播放器 | `contents`、`pageWidth`、`pageHeight`、`title`、`description`、`brandMarkPosition`、`waitSeconds` |

### 参数使用方式

| 分类 | 适用工具 | 建议写法 |
| --- | --- | --- |
| 最小必填 | `html_to_pptx` | `html` 和 `file` 二选一 |
| 最小必填 | `html_to_image` | `html` 和 `file` 二选一 |
| 最小必填 | `markdown_to_image` | `markdown` 和 `file` 二选一 |
| 最小必填 | `build_html_player` | 填写 `contents` |
| 输入方式 | `html_to_pptx`、`html_to_image`、`markdown_to_image` | “内联内容”就是把原始 HTML 或 Markdown 文本直接粘贴进参数里，而不是传文件路径或 URL |
| 常用可选 | 渲染类工具 | 只有当你要控制画布尺寸、截图清晰度或页面宽度时，再填写 `width`、`height`、`scale`、`pageWidth` |
| 常用可选 | 本组所有工具 | 只有当你希望工具等待更久再返回时，再填写 `waitSeconds` |
| 按需填写 | `html_to_pptx` | `needEmbedFonts` 适用于导出的 PPTX 需要自带字体的场景 |
| 按需填写 | `html_to_pptx` | `platform` 仅支持 `mac`、`win` |
| 按需填写 | `html_to_pptx` | `lang` 支持 `latin`、`sc`、`tc`、`jp`、`kr`、`ar`、`he` |
| 按需填写 | `build_html_player` | `contents` 只接受内联 HTML 页面内容 |

### 示例提示词

| 工具 | 示例提示词 |
| --- | --- |
| `html_to_pptx` | “请调用 DeckFlow MCP 的 `html2pptx` server，把这个 HTML 页面转换成可编辑的 PPTX，并尽量保留原始版式。” |
| `html_to_image` | “请调用 DeckFlow MCP 的 `html2pptx` server，把这个 HTML 页面渲染成 PNG 预览图，方便我先审阅效果。” |
| `markdown_to_image` | “请调用 DeckFlow MCP 的 `html2pptx` server，把这份 Markdown 发布说明转换成一张干净的 PNG 图片，方便发到群里。” |
| `build_html_player` | “请调用 DeckFlow MCP 的 `html2pptx` server，把这些 HTML 幻灯片片段打包成一个浏览器里可直接打开的播放器。” |

## `deckflow-pptx`

端点：`https://mcp.deckflow.com/v1/pptx`

| 工具 | 作用 | 关键参数 |
| --- | --- | --- |
| `split_pptx` | 按页或按指定范围拆分 PPTX | `file`、`indexes`、`allowSize`、`waitSeconds` |
| `merge_pptx` | 按顺序合并多个 PPTX | `files`、`hiddens`、`autoResize`、`waitSeconds` |
| `embed_pptx_fonts` | 将指定字体嵌入到 PPTX | `file`、`usedFonts`、`waitSeconds` |
| `inspect_pptx` | 提取字体信息或文本形状结构 | `file`、`aspect`、`pickPages`、`includeLayout`、`includeMaster`、`includeNotes`、`ignoreEmptyText`、`onlyBrief`、`imageFilter`、`hasChildren`、`waitSeconds` |

### 参数使用方式

| 分类 | 适用工具 | 建议写法 |
| --- | --- | --- |
| 最小必填 | `split_pptx` | 填写 `file` |
| 最小必填 | `merge_pptx` | 填写 `files`，且至少提供 2 个 PPTX 文件 |
| 最小必填 | `embed_pptx_fonts` | 填写 `file` |
| 最小必填 | `inspect_pptx` | 填写 `file` 和 `aspect` |
| 常用可选 | `split_pptx` | 只有当你想拆指定页时，才填写 `indexes`；页码从 `0` 开始 |
| 常用可选 | `embed_pptx_fonts` | 只有当你要嵌入指定字体集时，才填写 `usedFonts` |
| 常用可选 | 本组所有工具 | 大文件或复杂文件处理时，可以补 `waitSeconds` |
| 按需填写 | `inspect_pptx` | `aspect` 支持 `fonts` 或 `texts` |
| 按需填写 | `inspect_pptx` | 多数检查类可选参数只在 `aspect=texts` 时生效 |

### 示例提示词

| 工具 | 示例提示词 |
| --- | --- |
| `split_pptx` | “请调用 DeckFlow MCP 的 `pptx` server，把这个 PPTX 按页拆开，方便我逐页检查内容。” |
| `merge_pptx` | “请调用 DeckFlow MCP 的 `pptx` server，把这两个 PPTX 按顺序合并成一个文件。” |
| `embed_pptx_fonts` | “请调用 DeckFlow MCP 的 `pptx` server，把这个 PPTX 用到的字体嵌进去，避免换机器后版式跑掉。” |
| `inspect_pptx` | “请调用 DeckFlow MCP 的 `pptx` server，检查这个 PPTX 用了哪些字体，并帮我列出来。” |

## `deckflow-tools`

端点：`https://mcp.deckflow.com/v1/tools`

| 工具 | 作用 | 关键参数 |
| --- | --- | --- |
| `convert_file` | 在 DeckFlow 支持的交付格式之间转换文件 | `file`、`targetFormat`、`resolution`、`imageFormat`、`waitSeconds` |
| `ocr_image` | 识别图片中的文本 | `file`、`language`、`waitSeconds` |
| `transform_image` | 缩放图片或转成 WebP | `file`、`action`、`maxWidth`、`maxHeight`、`waitSeconds` |
| `compress_file` | 压缩普通文件或视频文件 | `file`、`waitSeconds` |

### 参数使用方式

| 分类 | 适用工具 | 建议写法 |
| --- | --- | --- |
| 最小必填 | `convert_file` | 填写 `file` 和 `targetFormat` |
| 最小必填 | `ocr_image` | 填写 `file` 和 `language` |
| 最小必填 | `transform_image` | 填写 `file` 和 `action` |
| 最小必填 | `compress_file` | 填写 `file` |
| 常用可选 | `convert_file` | 只有当你要控制输出分辨率或图片格式时，才填写 `resolution`、`imageFormat` |
| 常用可选 | `transform_image` | 只有当 `action=resize` 时，才填写 `maxWidth` 或 `maxHeight` |
| 常用可选 | 本组所有工具 | 大文件转换时，可以补 `waitSeconds` |
| 按需填写 | `convert_file` | `targetFormat` 支持 `image`、`pdf`、`pptx`、`html`、`video` |
| 按需填写 | `convert_file` | `resolution` 支持 `1080`、`1920`、`2560` |
| 按需填写 | `convert_file` | `imageFormat` 支持 `png`、`jpg` |
| 按需填写 | `ocr_image` | `language` 支持：`ar`、`bg`、`cs`、`da`、`de`、`el`、`en`、`es`、`et`、`fi`、`fr`、`hu`、`id`、`it`、`ja`、`ko`、`lt`、`lv`、`nb`、`nl`、`pl`、`pt`、`ro`、`ru`、`sk`、`sl`、`sv`、`tr`、`uk`、`zh-hans`、`zh-hant` |
| 按需填写 | `transform_image` | `action` 支持 `resize`、`to_webp` |
| 按需填写 | `transform_image` | 当 `action=resize` 时，至少要提供 `maxWidth` 或 `maxHeight` 其中一个 |

### 示例提示词

| 工具 | 示例提示词 |
| --- | --- |
| `convert_file` | “请调用 DeckFlow MCP 的 `tools` server，把这个 PDF 转成图片，我想把每一页单独拿出来使用。” |
| `ocr_image` | “请调用 DeckFlow MCP 的 `tools` server，识别这张截图里的文字，并把提取结果返回给我。” |
| `transform_image` | “请调用 DeckFlow MCP 的 `tools` server，把这张图片缩小到更适合网页使用的宽度。” |
| `compress_file` | “请调用 DeckFlow MCP 的 `tools` server，压缩这个大文件，方便我上传和分享。” |

## 推荐接入组合

- 只需要 HTML 转 PPTX 或预览图时，只接入 `deckflow-html2pptx`
- 如果还需要额外做 PPTX 拆分、合并、检查或嵌入字体，就接入 `deckflow-pptx`
- 如果流程里还涉及 OCR、格式转换、图片处理或压缩，就接入 `deckflow-tools`
