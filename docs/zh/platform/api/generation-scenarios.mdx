文档生成并没有独立的新接口，仍然通过统一的 `POST /tools/tasks` 提交。关键区别在于：`type` 必须固定为 `generation`，同时 `params` 需要传入生成场景的完整参数。

## 场景映射

| 字段 | 值 |
|---|---|
| 接口 | `POST /tools/tasks` |
| `type` | `generation` |
| 文件 | 可选参考文件，例如 PDF、Word、Markdown，支持多个 |
| 查询接口 | `GET /tools/tasks/{id}` |

## Form Data 字段

| 字段 | 类型 | 是否必填 | 说明 |
|---|---|---|---|
| `spaceId` | `String` | 否 | 目标工作空间 Space ID。 |
| `files` | `File` | 否 | 参考源文件，例如 PDF、Word 或 Markdown；支持上传多个文件。 |
| `type` | `String` | 是 | 固定值：`generation`。 |
| `name` | `String` | 否 | 任务显示名称，例如 `"AI 生成文档任务"`。 |
| `params` | `String (JSON)` | 是 | 包含生成参数的 JSON 字符串。 |

## `params` 字段说明

| 字段 | 类型 | 是否必填 | 说明 |
|---|---|---|---|
| `inputText` | `String` | 否 | 用于构建幻灯片结构的主题描述、网页链接 URL 或原始文本。 |
| `enableSearch` | `Boolean` | 否 | 是否启用网页搜索以研究并丰富内容细节。默认值：`false`。 |
| `advancedModel` | `Boolean` | 否 | 是否使用深度推理 AI 模型，以获得更好的逻辑排版和更具创意的幻灯片。默认值：`false`。 |
| `fastMode` | `Boolean` | 否 | 是否开启快速模式，优先输出排版速度而非极致细节优化。默认值：`false`。 |
| `intent` | `String` | 否 | 自定义目标意图或补充指示。 |
| `audience` | `String` | 否 | 目标受众特征，用于指导 AI 选择布局和文案风格。 |
| `pageCount` | `Integer` | 否 | 需要生成的目标页数。 |
| `author` | `String` | 否 | 生成 PPTX 元数据中的作者署名。 |
| `notifyURL` | `String` | 否 | 任务状态变更通知的 Webhook 回调地址。 |

## `params` 示例

```json
{
  "inputText": "生成一份关于可再生能源趋势的演示文稿，重点覆盖太阳能与风能市场。",
  "enableSearch": true,
  "advancedModel": false,
  "fastMode": false,
  "intent": "董事会汇报",
  "audience": "管理层",
  "pageCount": 10,
  "author": "DeckFlow API"
}
```
