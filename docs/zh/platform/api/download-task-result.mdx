任务详情返回 `status: "completed"` 且 `allowGetResult: true` 后，再调用该接口。

虽然路径中包含 `/download`，但实测响应是 JSON 元数据，而不是文件字节流。应用需要从响应中读取结果地址，再单独下载该地址。

## 已验证的 html2pptx 响应

```json
{
  "target": [
    "https://files.example.com/result.pptx",
    10870,
    "dd206bad03fce37c3c753b57ecf32c26"
  ],
  "usedFonts": ["Times New Roman"]
}
```

对于已验证的 `convertor.html2pptx` 路径：

| 值 | 含义 |
| --- | --- |
| `target[0]` | 结果文件地址 |
| `target[1]` | 结果文件字节数 |
| `target[2]` | 服务返回的摘要字符串 |
| `usedFonts` | 转换过程中识别到的字体 |

不同任务类型返回的结果元数据可能不同。应根据所选任务检查需要的字段，不要假设所有任务都会返回 `usedFonts`。

## 下载返回的文件地址

```bash
RESULT_URL=$(curl -sS \
  'https://app.deckflow.com/api/tools/tasks/TASK_ID/download' \
  --header "Authorization: Bearer $DECKFLOW_API_KEY" \
  | jq -r '.target[0]')

curl -fL "$RESULT_URL" -o result.pptx
test -s result.pptx
```

不要把结果地址写入日志。该地址的有效期没有保证，应先检查任务归属和预期输出类型，再及时下载。

## 已验证的响应状态

| 状态码 | 出现场景 | 响应特征 |
| ---: | --- | --- |
| `200` | 任务已完成，且 API Key 属于任务所在 Space | 返回 JSON 结果元数据 |
| `401` | Bearer Token 无效 | `code: "noAuth"` |
| `403` | API Key 属于另一个 Space | `code: "notAllowed"`，并返回 Space 权限信息 |
| `403` | 任务仍为 `pending`、`running`，或已经 `failed` | `code: "notAllowed"`，并包含 `Task is not completed` |
| `404` | Task ID 不存在 | `code: "notFound"` |
| `500` | 未提供 Authorization 请求头 | `code: "unexpectedError"`，并包含 `Profile uuid is required` |

<Note>
  运行中的任务和无额度后失败的任务都会返回 `403` 和 `Task is not completed`；未完成任务目前不会返回 `409`。
</Note>
