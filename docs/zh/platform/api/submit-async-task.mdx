这是 DeckFlow 所有任务的统一提交入口。文档生成、文档翻译、文档焕新和工具 API 都复用这个接口，差异主要体现在 `type` 和 `params` 的组合上。

<Note>
  可以把这个接口理解为统一的任务提交器。不同场景页负责告诉你应该传什么 `type` 和 `params`。
</Note>

## 不同场景如何区分

| 场景 | `type` 示例 | `params` 关注点 |
|---|---|---|
| 文档生成 | `generation` | 提示词、页数、搜索开关、模型和速度选项 |
| 文档翻译 | `translation` | 源语言、目标语言 |
| 文档焕新 | `revamp` | 设计说明、排版风格、视觉刷新要求 |
| 工具 API | `convertor.html2pptx` | 工具特定参数，例如字体嵌入 |

## 共用请求模式

- 使用 `multipart/form-data`
- 把上传文件放到 `files`
- 把业务类型放到 `type`
- 把具体业务参数序列化为 `params` JSON 字符串
- 可选传入 `name`、`notifyURL`、`spaceId`

## 提交之后做什么

接口成功返回后会给你一个任务 ID。接下来使用查询接口持续轮询，直到任务完成。

<Card title="查询任务状态" href="/zh/platform/api/query-task-status">
  使用同一个任务 ID 持续查询执行进度与下载结果。
</Card>
