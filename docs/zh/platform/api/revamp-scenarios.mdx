焕新任务仍然复用统一的异步任务接口。区别在于 `type` 必须固定为 `revamp`，同时 `params` 中需要放入焕新设计所需的指令字段。

## 场景映射

| 字段 | 值 |
|---|---|
| 接口 | `POST /tools/tasks` |
| `type` | `revamp` |
| 文件 | PPTX 演示文稿文件 |
| 查询接口 | `GET /tools/tasks/{id}` |

## Form Data 字段

| 字段 | 类型 | 是否必填 | 说明 |
|---|---|---|---|
| `spaceId` | `String` | 否 | 目标工作空间 Space ID。 |
| `files` | `File` | 是 | 待焕新的 PPTX 文件；支持上传多个文件。 |
| `type` | `String` | 是 | 固定值：`revamp`。 |
| `name` | `String` | 否 | 任务显示名称，例如 `"AI 焕新文档任务"`。 |
| `params` | `String (JSON)` | 是 | 包含焕新参数的 JSON 字符串。 |

## `params` 字段说明

| 字段 | 类型 | 是否必填 | 说明 |
|---|---|---|---|
| `inputText` | `String` | 否 | 排版风格指南、配色规则、品牌 DNA 或其他视觉焕新指令。 |
| `advancedModel` | `Boolean` | 否 | 是否使用高级设计推理 AI。默认值：`false`。 |
| `fastMode` | `Boolean` | 否 | 是否优先开启快速模式。默认值：`false`。 |
| `notifyURL` | `String` | 否 | 任务状态变更通知的 Webhook 回调地址。 |

## `params` 示例

```json
{
  "inputText": "将整套演示文稿刷新为蓝绿色主色调，并使用更简洁的现代版式。",
  "advancedModel": false,
  "fastMode": false,
  "notifyURL": "https://your.domain/callback"
}
```
