> 这一页收集的是围绕当前 DeckHTML CLI 工作流整理的可直接上手示例。

## 无需安装直接运行

```bash
npx -y @deckflow/deckhtml@latest index.html -o deck.pptx
```

## 转换单个文件

```bash
deckhtml index.html
deckhtml index.html -o deck.pptx
```

## 从 stdin 转换

```bash
cat index.html | deckhtml - -o deck.pptx
```

## 转换多个有序文件

```bash
deckhtml title.html agenda.html content.html summary.html -o deck.pptx
```

## 转换托管 URL

```bash
deckhtml https://example.com/deck.html -o deck.pptx
```

## 生成 PNG 输出

```bash
deckhtml index.html -o frames.png
deckhtml index.html --mode cloud -o frames.png
```

## 指定视口宽度或平台映射

```bash
deckhtml index.html --width 1440 -o deck.pptx
deckhtml index.html --platform win -o deck.pptx
```

## 使用 local、auto 或 cloud 模式

```bash
deckhtml index.html --mode local -o deck.pptx
deckhtml index.html --mode auto -o deck.pptx
deckhtml index.html --mode cloud -o deck.pptx
```

## 使用云端增强参数

```bash
deckhtml index.html \
  -o deck.pptx \
  --mode cloud \
  --embed-fonts \
  --report
```

## 生成报告

```bash
deckhtml index.html -o deck.pptx --report
```

## 返回机器可读 JSON

```bash
deckhtml index.html -o deck.pptx --json
```

```json
{
  "ok": true,
  "input": ["index.html"],
  "output": "deck.pptx",
  "format": "pptx",
  "mode": "local"
}
```

## 认证与配置

```bash
deckhtml auth login
deckhtml auth status
deckhtml config set api-key <key>
deckhtml config show
```

在 CI、Docker 和智能体环境中：

```bash
export DECKHTML_API_KEY=your-api-key
deckhtml index.html --mode cloud -o deck.pptx
```
