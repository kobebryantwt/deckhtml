DeckRender 用于把文档生成视觉产物。传入本地文件、URL 或标准输入，并指定图片、PDF 或视频；DeckRender 会选择可用的渲染路径、执行任务并按稳定规则写出文件。

<CardGroup cols={3}>
  <Card title="输入" icon="file-import">
    本地文件、在线 HTML 或 Markdown，以及明确指定源格式的标准输入。
  </Card>
  <Card title="输出" icon="images">
    PNG、JPEG、WebP 页面图片，以及支持格式对应的 PDF 或 MP4 视频。
  </Card>
  <Card title="接入方式" icon="terminal">
    `deckrender` CLI 与 `@deckflow/deckrender` Node.js API 由同一包提供。
  </Card>
</CardGroup>

## DeckRender 负责什么

- 读取并识别输入。
- 选择直连、多步派生、本地或透传渲染路径。
- 按路径能力应用尺寸、图片编码和页面筛选参数。
- 写出单个产物、连续编号的页面图片或 ZIP 压缩包。
- 返回包含执行引擎、路由、页数、文件和耗时的稳定结果。

DeckRender 不会把文档内容解析成中间表示，不负责提取文本或语义结构，也不修改源文件元素。它生成的 Render Plan 只描述执行过程，并不是文档内容模型。

## 执行方式

多数路径通过 Deckflow 云端任务执行。PDF 透传以及 Pages、Numbers 文档中的内嵌预览读取在本地完成。认证并非必需：CLI 可以使用有限额的访客模式，也可以登录或配置 API Key 后使用认证访问。

<Warning>
  Pages 和 Numbers 的输出来自 iWork 写入文档的内嵌预览，仅包含第一页，并沿用文档中保存的预览分辨率。
</Warning>
