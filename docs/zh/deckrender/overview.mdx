DeckRender 是 Deckflow Document Runtime 中专注渲染的组件。开发者通过 SDK 接入，实际渲染在云端执行。

## 适用场景

- 工作流需要页面或幻灯片预览，而不是结构化文档内容。
- 需要在不 Manipulate 源文件的情况下检查视觉保真度。
- 下游流程需要缩略图、评审图片或其他渲染资源。
- 应用只需要 Render，不需要 DeckOps 更完整的 Parse、Extract 和 Convert 能力面。

## 产品边界

无需渲染、只需在本地或浏览器中嗅探文件时，使用 [DeckProbe](/zh/deckprobe/overview)。Render 属于更大的云端流程，并且还需要 Probe、Parse 成 Document IR、Extract 或 Convert 时，使用 [DeckOps](/zh/deckops/overview)。

需要 Manipulate Office 源文件而不是生成画面时，使用 [DeckUse](/zh/deckuse/overview)。
