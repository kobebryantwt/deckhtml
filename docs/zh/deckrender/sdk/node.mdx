CLI 与编程 API 由同一软件包提供，需要 Node.js 18 或更高版本。

```bash
npm install @deckflow/deckrender
```

## 单次渲染

```ts
import { render } from '@deckflow/deckrender';

const result = await render({
  input: './deck.pptx',
  format: 'image',
  imageFormat: 'webp',
  pages: '1-5',
  width: 1920,
  out: './frames/',
  apiKey: process.env.DECKFLOW_API_KEY,
});

console.log(result.route);
console.log(result.outputs);
```

`render()` 会读取输入、构建并执行路由、写出产物，然后返回 `RenderResult`。省略凭证时使用访客模式。

## 复用 Renderer

```ts
import { createRenderer } from '@deckflow/deckrender';

const renderer = createRenderer({
  apiKey: process.env.DECKFLOW_API_KEY,
  onWarning: (message) => console.warn(message),
});

const result = await renderer.render({
  input: './report.pdf',
  format: 'image',
  pages: '1,3,5-7',
  out: './report-pages/',
  onProgress: ({ phase, message, ratio }) => {
    console.log({ phase, message, ratio });
  },
});
```

需要在多次调用中复用凭证、警告处理或自定义执行后端时，使用 `createRenderer()`。

## 渲染选项

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `input` | `string` | 文件路径、HTTP(S) URL 或代表标准输入的 `-` |
| `from` | `SourceFormat` | 显式输入类型；标准输入必须指定 |
| `format` | `'image' \| 'pdf' \| 'video'` | 默认 `image` |
| `imageFormat` | `'png' \| 'jpg' \| 'webp'` | 图片编码 |
| `out` | `string` | 文件、目录、ZIP 或 `-` |
| `pages` | `string` | 从 1 开始的范围，如 `1-5` 或 `1,3,7-9` |
| `width` | `number` | 兼容路径的目标长边 |
| `scale` | `number` | 相对路径默认尺寸的缩放倍数 |
| `quality` | `'low' \| 'medium' \| 'high'` | 图片预设 |
| `embedFonts` | `boolean` | 用于经过 PPTX 的 HTML 路径 |
| `timeout` | `number` | 云端任务等待超时秒数 |
| `onProgress` | `(event) => void` | 读取、规划、上传、任务、等待、下载和写出事件 |

SDK 不会自动应用 CLI profile 或 CLI 的渲染默认配置。请显式传入选项；应用需要复用相同行为时，也可以使用包导出的 `PROFILES` 和 `layerOptions`。

## Renderer 配置

`createRenderer()` 支持 `apiKey`、`token`、`spaceId` 和 `apiBase`，还可以传入：

- `client`：已有的 `@deckops/sdk` 客户端。
- `engine`：实现导出 `RenderEngine` 接口的自定义执行引擎。
- `onWarning`：接收路径限制和非致命参数调整。
- `onUnauthorized`：收到 `401` 后由调用方实现的重新认证回调。
- `onPaymentRequired`：收到 `402` 后由调用方实现的处理回调。

即使提供了自定义云端客户端，本地和透传路径仍会在本地执行。

## 处理类型化错误

```ts
import { DeckRenderError, render } from '@deckflow/deckrender';

try {
  await render({ input: './deck.key', format: 'image', width: 1920 });
} catch (error) {
  if (error instanceof DeckRenderError) {
    console.error(error.code, error.message, error.hint);
  }
}
```

全部返回字段请查看[结果契约](/zh/deckrender/reference/result-contract)。
