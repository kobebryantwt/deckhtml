包根入口提供 Node.js API，需要 Node.js 18 或更高版本。正常安装会包含本地渲染可选依赖；只使用云端的服务可以添加 `--omit=optional`。

```bash
npm install @deckflow/deckrender
```

## 在本地渲染

```ts
import { render } from '@deckflow/deckrender';

const result = await render({
  input: './deck.pptx',
  engine: 'local',
  format: 'image',
  imageFormat: 'png',
  pages: '1-5',
  width: 1920,
  out: './frames/',
});

console.log(result.engine); // local
console.log(result.route);  // local.office2html, local.capture
```

本地 PPTX 和 PDF 路线不会读取凭证、访问 DeckFlow 或上传文档字节。执行机器需要满足[本地与云端引擎](/zh/deckrender/engines)列出的依赖。显式 `local` 执行不会转为云端。

## 通过 DeckFlow 云端渲染

```ts
import { render } from '@deckflow/deckrender';

const result = await render({
  input: './deck.pptx',
  engine: 'cloud',
  format: 'video',
  out: './deck.mp4',
  apiKey: process.env.DECKFLOW_API_KEY,
});
```

省略凭证时使用限频的游客模式。云端路线会上传源文件和中间产物。URL 会先由本地 Node.js 进程获取；DeckRender 不会继承用户浏览器的 Cookie 或当前 DOM。

使用 `engine: 'auto'` 可以本地优先选择。如果当前路线无法在本地执行，DeckRender 会先调用 `onWarning`，再选择云端。

## 复用 Renderer

```ts
import { createRenderer } from '@deckflow/deckrender';

const renderer = createRenderer({
  apiKey: process.env.DECKFLOW_API_KEY,
  onWarning: (message) => console.warn(message),
});

const result = await renderer.render({
  input: './report.pdf',
  engine: 'auto',
  format: 'image',
  pages: '1,3,5-7',
  out: './report-pages/',
  onProgress: ({ phase, message, ratio }) => console.log({ phase, message, ratio }),
});
```

## 渲染参数

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `input` | `string` | 文件路径、HTTP(S) URL，或使用 `-` 表示标准输入 |
| `engine` | `'local' \| 'cloud' \| 'auto'` | 依次使用显式值、`DECKRENDER_ENGINE` 和 `cloud`；SDK 不读取 CLI 渲染默认配置文件 |
| `from` | `SourceFormat` | 显式输入类型；标准输入必须指定 |
| `format` | `'image' \| 'pdf' \| 'video'` | 默认 `image` |
| `imageFormat` | `'png' \| 'jpg' \| 'webp'` | 取决于所选引擎与路线 |
| `out` | `string` | 文件、目录、ZIP 或 `-` |
| `pages` | `string` | 从 1 开始的范围，如 `1-5` 或 `1,3,7-9` |
| `width` / `scale` | `number` | 兼容图片路线的尺寸参数 |
| `quality` | `'low' \| 'medium' \| 'high'` | 图片预设 |
| `embedFonts` | `boolean` | 经过 PPTX 的云端 HTML 路线 |
| `timeout` | `number` | 云端任务等待超时秒数 |
| `onProgress` | `(event) => void` | 解析、计划、上传、任务、等待、下载和写出阶段 |

SDK 不会自动应用 CLI Profile 或已保存的 CLI 渲染默认值。请显式传入参数，或者使用导出的 `PROFILES` 与 `layerOptions`。

应用展示某条路线前，可以使用引擎对应的发现函数：

```ts
import { findLocalRoute, findRoute, localSupportedTargets, supportedTargets } from '@deckflow/deckrender';

console.log(localSupportedTargets('pptx')); // ['image', 'pdf']
console.log(supportedTargets('docx'));      // 云端：['image', 'pdf']
console.log(findLocalRoute('pptx', 'image')?.tasks);
console.log(findRoute('docx', 'image')?.tasks);
```

这些函数只检查当前安装包中的路线表，不访问 DeckFlow。

## 自定义引擎与 Client

`createRenderer()` 还接受：

- `client`：已有的 `@deckops/sdk` 云端 Client。
- `engine`：为兼容旧接口保留的自定义 `RenderEngine`。
- `customEngine`：语义更明确的自定义引擎字段。
- `onUnauthorized` 和 `onPaymentRequired`：内置云端 Client 使用的回调。

同一次调用不能同时由自定义引擎和内置引擎名称控制。注入的 Client 会被视为已经配置完成，需要自行管理认证回调。

前端应用应使用独立的 [Browser SDK](/zh/deckrender/sdk/browser)，不要把 Node.js 包根入口打进浏览器 Bundle。

## 处理类型化错误

```ts
import { DeckRenderError, render } from '@deckflow/deckrender';

try {
  await render({ input: './deck.pptx', engine: 'local', format: 'image' });
} catch (error) {
  if (error instanceof DeckRenderError) {
    console.error(error.code, error.message, error.hint);
  }
}
```

返回字段和错误码参见[结果契约](/zh/deckrender/reference/result-contract)。
