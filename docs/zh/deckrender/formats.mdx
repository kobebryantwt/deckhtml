格式范围取决于选择的引擎。云端支持某种格式，不代表它也能在本地执行，应以当前安装版本返回的矩阵为准。

```bash
deckrender formats --engine local
deckrender formats --engine cloud
deckrender formats --engine auto --json
```

## 本地引擎

| 输入 | 图片 | PDF | 视频 |
| --- | --- | --- | --- |
| PowerPoint `.pptx` | PNG、JPEG | 支持 | — |
| PDF `.pdf` | PNG、JPEG | 原文件透传 | — |
| HTML `.html`、`.htm`、URL | PNG、JPEG | — | — |

本地 PPTX 和 PDF 路线会把文档字节保留在当前机器。HTML 本地渲染不访问 DeckFlow，但页面仍可能加载自身引用的远程资源。依赖与保真边界参见[本地与云端引擎](/zh/deckrender/engines)。

## 云端引擎

| 输入 | 图片 | PDF | 视频 |
| --- | --- | --- | --- |
| PowerPoint `.pptx` | PNG、JPEG、WebP | 支持 | MP4 |
| PDF `.pdf` | PNG、JPEG、WebP | 原文件透传 | — |
| Keynote `.key` | PNG、WebP | 支持 | — |
| Word `.docx` | PNG、JPEG、WebP | 支持 | — |
| HTML `.html`、`.htm`、URL | PNG、WebP | 支持 | MP4 |
| Markdown `.md`、`.markdown` | PNG、WebP | — | — |

所有云端转换都会上传源文件。派生路线还会传输中间产物，例如 Word→图片会先执行 DOCX→PDF，再执行 PDF→图片。PDF→PDF 不需要转换，仍在本地直接透传。

## 图片参数

| 引擎与输入 | `--width` / `--scale` | `--image-format` | `--pages` |
| --- | --- | --- | --- |
| 本地 PPTX | 连续尺寸 | `png`、`jpg` | 支持；只捕获选中幻灯片 |
| 本地 PDF | 连续尺寸 | `png`、`jpg` | 支持；只栅格化选中页面 |
| 本地 HTML/URL | 宽度和缩放 | `png`、`jpg` | 不支持；生成一次通用页面捕获 |
| 云端 PPTX | 吸附到 1080、1920 或 2560 px | `png`、`jpg`、`webp` | 支持 |
| 云端 PDF 或 DOCX 派生图片 | 任意正数长边 | `png`、`jpg`、`webp` | 支持 |
| 云端 Keynote | 不支持调整 | `png`、`webp` | 支持 |
| 云端 HTML/URL | 宽度和缩放 | `png`、`webp` | 不支持；生成一张图片 |
| 云端 Markdown | 页面宽度和缩放 | `png`、`webp` | 不支持；生成一张图片 |

显式传入不兼容参数时会返回 `unsupported_option`，不会静默忽略，也不会切换到其他引擎。WebP 通过额外的逐图云端任务生成；页面筛选会在这个步骤之前完成。

## 路线行为

<AccordionGroup>
  <Accordion title="本地 PPTX 渲染">
    DeckRender 使用 `office2html` 把 PPTX 转为 HTML，再由 Chromium 捕获幻灯片；请求 PDF 时会逐页打印并合并。转换器产生的外部 CDN 请求会被阻止，系统字体、图标和复杂 Office 效果可能与托管云端结果不同。
  </Accordion>
  <Accordion title="本地 PDF 渲染">
    PDF 图片通过 Chromium 中的 PDF.js 栅格化。PDF→PDF 直接复制原文件，不重新渲染，也不上传。
  </Accordion>
  <Accordion title="HTML 转云端 PDF 或视频">
    云端会先把 HTML 重建为 PPTX。PDF 遵循幻灯片布局，而不是浏览器打印布局；视频是重建后 Deck 的幻灯片视频，不是在线页面录制。返回结果会包含 `caveat`。
  </Accordion>
  <Accordion title="Word 转云端图片">
    Word 先转换为 PDF，再把 PDF 渲染为页面图片；返回的 `route` 会包含两项云端任务。
  </Accordion>
  <Accordion title="URL 输入">
    Node.js CLI 和 SDK 会先在本机获取 URL。本地模式直接捕获获取到的 HTML；云端模式会补充相对资源所需的 Base URL 后上传。两种模式都不会继承用户浏览器的 Cookie 或当前 DOM。
  </Accordion>
</AccordionGroup>

PDF 和视频属于单文件输出，不接受图片尺寸、编码、质量或页面筛选参数。可执行示例参见[渲染 PDF 和视频](/zh/deckrender/guides/render-pdf-and-video)。
