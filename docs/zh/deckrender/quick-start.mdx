下面会在本地渲染一个自行创建的 HTML 文件，无需账号，也不会向 DeckFlow 上传源文件。

<Steps>
  <Step title="检查运行条件">
    DeckRender 需要 Node.js 18 或更高版本。本地渲染还要求执行机器已安装 Chrome、Chromium 或 Edge。

    ```bash
    node --version
    ```
  </Step>
  <Step title="安装并验证 CLI">
    正常安装会包含可选 JavaScript 依赖，以及当前平台对应的 `office2html` 包。

    ```bash
    npm install -g @deckflow/deckrender
    deckrender --version
    deckrender formats --engine local
    ```
  </Step>
  <Step title="创建已知输入">
    将以下内容保存为 `hello.html`：

    ```html
    <!doctype html>
    <html>
      <head>
        <meta charset="utf-8" />
        <style>
          body { margin: 0; font: 48px system-ui; }
          main { padding: 64px; background: #f4f7ff; }
        </style>
      </head>
      <body><main>Hello DeckRender</main></body>
    </html>
    ```
  </Step>
  <Step title="在本地渲染一张 PNG">
    ```bash
    deckrender hello.html --engine local -o hello.png --json --quiet
    ```
  </Step>
  <Step title="验证产物与路线">
    命令成功时退出码为 `0`，写出 `hello.png`，并返回类似结果：

    ```json
    {
      "ok": true,
      "input": "hello.html",
      "format": "image",
      "engine": "local",
      "route": ["local.capture"],
      "pages": 1,
      "outputs": [{ "page": 1, "file": "hello.png", "width": 1280, "height": 720, "bytes": 18432 }],
      "durationMs": 1200
    }
    ```

    尺寸、字节数和耗时会随页面和浏览器变化。自动化流程应单独检查文件：

    ```bash
    test -s hello.png
    ```

    ```powershell
    if (!(Test-Path hello.png) -or (Get-Item hello.png).Length -eq 0) { exit 1 }
    ```
  </Step>
</Steps>

如果 DeckRender 找不到浏览器，请安装 Chrome/Chromium/Edge，或设置 `DECKRENDER_CHROMIUM_EXECUTABLE_PATH`。PPTX/PDF 本地路线和依赖查找方式参见[本地与云端引擎](/zh/deckrender/engines)。

## 体验云端路线

云端仍是默认引擎，并提供更完整的格式范围。以下命令会上传 `hello.html`，无需凭证即可使用限频的游客模式执行：

```bash
deckrender hello.html --engine cloud -o hello-cloud.png --json --quiet
```

使用 `--engine auto` 可以本地优先选择；如果需要转到云端，它会提前给出警告，不会静默上传。持续工作负载或私有 Workspace 应配置[认证](/zh/deckrender/authentication)。
