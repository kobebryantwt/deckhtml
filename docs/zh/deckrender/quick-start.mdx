title: 快速开始
sidebarTitle: 快速开始
description: "安装 DeckRender、创建 HTML 输入、使用访客模式渲染 PNG，并验证产物和 JSON 结果。"
---

本示例会创建自己的输入，并通过 Deckflow 云端访客模式完成渲染。HTML 源文件会被上传处理；首次请求不需要账号。

<Steps>
  <Step title="检查 Node.js">
    DeckRender 需要 Node.js 18 或更高版本。

    ```bash
    node --version
    ```
  </Step>
  <Step title="安装并验证 CLI">
    ```bash
    npm install -g @deckflow/deckrender
    deckrender --version
    deckrender formats
    deckrender config list
    ```

    检查 `config list` 显示的凭证来源。DeckRender 可能继承 DeckOps Token；已过期的回退 Token 会返回 `auth_error`，而不是进入游客模式。
  </Step>
  <Step title="创建已知输入">
    保存为 `hello.html`：

    ```html
    <!doctype html>
    <html>
      <head>
        <meta charset="utf-8" />
        <style>
          body { margin: 0; font: 48px system-ui; }
          main { padding: 64px; background: #f4f7ff; }
        </style>
      </head>
      <body><main>Hello DeckRender</main></body>
    </html>
    ```
  </Step>
  <Step title="渲染一张 PNG">
    ```bash
    deckrender hello.html -o hello.png --json --quiet
    ```
  </Step>
  <Step title="验证产物和结果">
    成功命令的退出码为 `0`，会写入 `hello.png`，并输出类似以下结构的结果：

    ```json
    {
      "ok": true,
      "input": "hello.html",
      "format": "image",
      "engine": "cloud",
      "route": ["convertor.html2png"],
      "pages": 1,
      "outputs": [
        {
          "page": 1,
          "file": "hello.png",
          "bytes": 18432
        }
      ],
      "durationMs": 3200
    }
    ```

    `--quiet` 会在命令失败前保持 stderr 为空。字节数和耗时会变化，自动化流程还应单独检查文件：

    ```bash
    test -s hello.png
    ```

    PowerShell 中使用 `if (!(Test-Path hello.png) -or (Get-Item hello.png).Length -eq 0) { exit 1 }`。
  </Step>
</Steps>

访客渲染存在额度限制。如果命令返回 `auth_error`，先运行 `deckrender auth status` 检查实际选中的凭证，再登录或配置 API Key 后重试。已过期的环境变量或 DeckOps 回退凭证可能会覆盖游客模式。详见[认证](/zh/deckrender/authentication)。
