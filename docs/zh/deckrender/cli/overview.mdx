## 输入形式

```bash
deckrender deck.pptx
deckrender https://example.com/page.html -o page.png
cat page.html | deckrender - --from html -o page.png
```

标准输入没有文件名，因此必须使用 `--from`。URL 默认按 HTML 处理，除非通过 `--from` 指定其他格式。DeckRender 会先在本地获取 URL 内容，并在需要时补充基础 URL，使页面中的相对资源能在渲染时正确解析。

URL 直接指向其他受支持文件时，需要指定类型：

```bash
deckrender https://example.com/deck.pptx --from pptx -o frames/
```

URL 请求不会继承浏览器 Cookie、自定义请求 Header 或已经登录的浏览器会话。对于受保护的输入，应先在应用中完成下载，再把本地文件交给 DeckRender。

## 常用渲染选项

| 选项 | 用途 |
| --- | --- |
| `-o, --output <path>` | 文件、目录、`.zip`，或使用 `-` 把原始字节写入 stdout |
| `--engine <engine>` | `local`、`cloud` 或本地优先的 `auto` |
| `--format <format>` | `image`、`pdf` 或 `video`；否则从 `-o` 推断，默认图片 |
| `--image-format <format>` | `png`、`jpg` 或 `webp` |
| `--from <format>` | 覆盖源格式；标准输入必须指定 |
| `--pages <ranges>` | 保留从 1 开始的页面，如 `1-5` 或 `1,3,5-7` |
| `--page <n>` | 保留单页；不能与 `--pages` 同时使用 |
| `--width <px>` | 路径支持时设置图片长边 |
| `--scale <n>` | 将路径默认长边乘以指定倍数 |
| `--quality <level>` | `low`、`medium` 或 `high` 图片质量预设 |
| `--profile <name>` | `web`、`presentation`、`print` 或 `thumbnail` |
| `--embed-fonts` | 路径经过 HTML 转 PPTX 时嵌入字体 |
| `--timeout <seconds>` | 云端任务等待超时；默认 `300` 秒 |
| `--json` | 把机器可解析结果写入 stdout |
| `--quiet` | 隐藏进度与警告 |
| `-v, --verbose` | 把详细诊断写入 stderr |

`--quiet` 与 `--verbose` 不能同时使用。参数支持范围取决于所选路线；多数不兼容的显式参数会返回 `unsupported_option`。路线与参数矩阵请查看[支持格式](/zh/deckrender/formats)。

输出扩展名可以同时推断输出类型和图片编码：

```bash
deckrender deck.pptx -o deck.pdf       # PDF
deckrender deck.pptx -o frame.webp     # WebP 图片
deckrender deck.pptx --format video -o deck.mp4
```

如果 `--format` 与 `-o` 扩展名冲突，DeckRender 会采用 `--format` 并给出警告，但不会修改文件名。因此应避免 `--format pdf -o output.png` 这类让文件内容与扩展名不一致的组合。

## 输出路径规则

| 情况 | 写出结果 |
| --- | --- |
| 未指定 `-o`，多张图片 | `<输入名>/001.png`、`002.png`…… |
| 未指定 `-o`，单个产物 | 写在输入旁，使用目标扩展名 |
| 无扩展名路径或目录 | 在目录中写入连续编号产物 |
| 文件路径且只有一个产物 | 写入该文件 |
| `out.png` 且有多张图片 | `out-001.png`、`out-002.png`…… |
| `.zip` 路径 | 把连续编号产物写入压缩包 |
| `-o -` 且只有一个产物 | 把原始产物字节写入 stdout |

多个产物不能直接写入 stdout，请改用目录、ZIP，或通过 `--pages` 缩小结果。原始 stdout 与 `--json` 也不能组合使用。

页面范围从 1 开始并包含首尾页面。本地 PPTX/PDF 路线只会捕获或栅格化选中的页面；云端路线先渲染完整源文件，因此筛选减少的是下载和写出，而不是基础云端计算。输出 WebP 时，会先筛选页面，再执行逐帧转换。

## Profiles

Profile 是一组命名的参数默认值，并非不同的渲染引擎。显式命令参数优先。

| Profile | 默认值 |
| --- | --- |
| `web` | 图片、WebP、1920 px、中等质量 |
| `presentation` | 图片、PNG、1920 px、高质量 |
| `print` | PDF |
| `thumbnail` | 第一页、JPEG、640 px、低质量 |

```bash
deckrender deck.pptx --profile web -o frames/
deckrender report.pdf --profile thumbnail -o cover.jpg
```

## 辅助命令

| 命令 | 作用 |
| --- | --- |
| `deckrender formats [--engine local\|cloud\|auto] [--json]` | 查看指定引擎选择下的路线矩阵 |
| `deckrender auth login [--port N]` | 打开浏览器登录并保存返回的 Session Token |
| `deckrender auth status` | 验证当前凭证并显示来源 |
| `deckrender auth logout` | 删除 DeckFlow 共享文件中的凭证 |
| `deckrender auth path` | 输出共享凭证路径 |
| `deckrender config set <key> <value>` | 保存 API Key 或渲染默认值 |
| `deckrender config unset <key>` | 删除一项已保存的值 |
| `deckrender config list` | 显示实际生效的设置、凭证和来源 |
| `deckrender config path` | 输出渲染配置与共享配置路径 |

```bash
deckrender formats
deckrender formats --engine local
deckrender auth login
deckrender auth status
deckrender auth logout
deckrender auth path
deckrender config list
deckrender config set profile web
deckrender config set engine local
deckrender config unset profile
deckrender config path
```

显式选择本地引擎后不会上传，也不会在失败时转为云端。安装与数据边界参见[本地与云端引擎](/zh/deckrender/engines)；稳定的 stdout/stderr、JSON 错误和退出码参见[自动化与错误处理](/zh/deckrender/cli/automation)。
