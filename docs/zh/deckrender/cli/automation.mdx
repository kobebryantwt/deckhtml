DeckRender 把结果数据写入 stdout，把进度、警告和错误写入 stderr。调用方无需过滤终端信息即可解析 stdout。

```bash
result=$(deckrender deck.pptx --json --quiet)
first_file=$(printf '%s' "$result" | jq -r '.outputs[0].file')
```

`--json` 会把成功结果保留在 stdout。警告会作为独立 JSON 对象写到 stderr。自动化流程希望 stderr 只包含最终失败结果时，请同时使用 `--quiet`。

## 成功结果

```json
{
  "ok": true,
  "input": "deck.pptx",
  "format": "image",
  "engine": "cloud",
  "route": ["convertor.ppt2image"],
  "pages": 3,
  "outputs": [
    {
      "page": 1,
      "file": "deck/001.png",
      "width": 1920,
      "height": 1080,
      "bytes": 184320
    }
  ],
  "durationMs": 8123
}
```

`pages` 表示执行 `--pages` 筛选前的总页数，`outputs` 只包含本次实际写出的产物。所选路径存在已知保真限制时，结果还会包含 `caveat`。

## 失败结果

启用 `--json` 时，失败信息写入 stderr：

```json
{
  "ok": false,
  "error": {
    "code": "unsupported_option",
    "message": "--width is not supported for .key input.",
    "hint": "The selected route does not expose a resolution parameter."
  }
}
```

云端失败还可能包含 `requestId`，反馈服务问题时请一并提供。

未使用 `--quiet` 时，stderr 可能先输出多条警告 JSON，最后才输出错误对象：

```jsonl
{"warning":"Resolution 2000 snapped to 1920: convertor.ppt2image accepts only 1080/1920/2560."}
{"ok":false,"error":{"code":"render_error","message":"Task convertor.ppt2image failed: ..."}}
```

希望错误解析最简单时，请使用 `--json --quiet`。如果需要保留警告，应把 stderr 按 JSON Lines 读取，并将最后一个包含 `error` 的对象作为失败结果。

## 退出码

| 退出码 | 含义 | 错误码 |
| --- | --- | --- |
| `0` | 成功 | — |
| `1` | 渲染或产物转换失败 | `render_error`、`conversion_error` |
| `2` | 调用、格式组合或选项无法执行 | `usage_error`、`unsupported_format`、`unsupported_option`、`not_implemented` |
| `3` | 需要凭证或凭证被拒绝 | `auth_error` |

已配置凭证被拒绝时，DeckRender 会警告并以游客模式重试一次。如果游客请求也被拒绝，CI 和 JSON 模式会返回 `auth_error`，不会打开交互式登录窗口。`402 Payment Required` 不会以游客模式重试。

```bash
export DECKFLOW_API_KEY='...'
deckrender deck.pptx --json --quiet
```

## 输出原始产物

只有一个产物时，`-o -` 只写出二进制内容：

```bash
deckrender page.html -o - > page.png
```

它不能与 `--json` 组合；路径产生多个页面时也会失败。

## 完整的 CI 模式

```bash
set +e
deckrender deck.pptx --json --quiet -o frames/ > result.json 2> error.json
code=$?
set -e

case "$code" in
  0) jq -r '.outputs[].file' result.json ;;
  2) jq -r '.error.code + ": " + .error.message' error.json >&2 ;;
  3) echo "Configure DeckRender credentials before this job" >&2 ;;
  *) jq -r '.error.message' error.json >&2 ;;
esac

exit "$code"
```

退出码 `2` 可能表示调用参数错误、不支持的格式组合、不支持的选项，或已经规划但尚未实现的路线。应继续读取 `error.code` 区分具体原因。
