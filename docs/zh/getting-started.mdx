先选择应用需要得到的第一个结果。下面每个部分都包含安装、具体调用，以及能够证明示例成功的结果信号。

| 产品 | 第一个结果 | 执行位置 | 凭证 |
| --- | --- | --- | --- |
| DeckProbe | 文档事实的 Schema v2 报告 | 本地 | 无 |
| DeckRender | PNG、PDF 或支持的视频渲染 | 主要在云端 | 游客或认证 |
| DeckOps | Markdown、结构化解析数据或转换产物 | 云端 | 推荐 API Key/Token |
| DeckUse | 更新后的 PPTX | 本地 | 无 |
| DeckHTML | 从 HTML 生成 PPTX 或 PNG | 本地或云端 | 本地无需凭证 |

## DeckProbe：检查一个已知 PDF

<span className="product-kicker">本地 · 无需凭证 · 事实 JSON</span>

```bash
npm install -g @deckflow/deckprobe
deckprobe --version

curl -L https://www.w3.org/WAI/ER/tests/xhtml/testfiles/resources/pdf/dummy.pdf -o sample.pdf
deckprobe -t format,page_count --view values --pretty sample.pdf
```

npm 软件包中的 CLI 会调用对应平台的原生二进制。成功时退出码为 `0`，`schema_version` 为 `2`，驱动为 `pdf`，并解析出 `document.format` 和 `pdf.page_count`：

```json
{
  "schema_version": 2,
  "status": "ok",
  "driver": { "id": "pdf", "profile": "pdf" },
  "values": {
    "document.format": "pdf",
    "pdf.page_count": 1
  }
}
```

不同平台的安装器和完整响应见 [DeckProbe 快速开始](/zh/deckprobe/quick-start)。

## DeckRender：生成 PNG

<span className="product-kicker">云端路径 · 支持访客 · 视觉产物</span>

```bash
npm install -g @deckflow/deckrender
deckrender hello.html -o hello.png --json
test -s hello.png
```

命令会把 HTML 上传到 DeckFlow 云端，写入 `hello.png`，并返回包含 `ok`、路由、页数、输出路径、字节数和耗时的 `RenderResult`。创建输入并了解游客限额见 [DeckRender 快速开始](/zh/deckrender/quick-start)。

## DeckOps：运行一个云端任务

<span className="product-kicker">云端 · 异步任务 · 可下载结果</span>

安装当前已发布的任务 SDK：

```bash
npm install @deckops/sdk
```

把以下输入保存为 `sample.html`：

```html
<!doctype html>
<html><body><h1>Hello DeckOps</h1></body></html>
```

把以下脚本保存为 `run.mjs`。它会创建游客任务、显式启动、等待完成，然后下载结果元数据：

```js
import { createDeck } from '@deckops/sdk';

const deck = createDeck();
const task = await deck.convertHtmlToPng({ files: ['./sample.html'] });

await deck.tasks.start(task.id);
const completed = await deck.tasks.wait(task.id, { timeout: 120 });
const result = await deck.tasks.down(completed.id);

console.log(JSON.stringify({
  taskId: completed.id,
  type: completed.type,
  status: completed.status,
  result,
}, null, 2));
```

执行脚本：

```bash
node run.mjs
```

HTML 会上传到 DeckFlow 云端。成功结果会标识任务，并返回 PNG 下载地址、字节数和哈希：

```json
{
  "taskId": "<task-id>",
  "type": "convertor.html2png",
  "status": "completed",
  "result": ["<download-url>", 8063, "<hash>"]
}
```

进度处理和当前软件包可用性说明见 [DeckOps 快速开始](/zh/deckops/quick-start)。

## DeckUse：更新现有 PPTX

<span className="product-kicker">本地 · 现有 PPTX · 可编辑输出</span>

```bash
npm install -g deckuse
deckuse replace input.pptx '2025' '2026' -o updated.pptx
deckuse get text updated.pptx "text[contains('2026')]"
```

DeckUse 在本地执行，当前支持修改现有 PPTX 内容。它不能新增或删除元素，也不支持其他 Office 格式。请按 [DeckUse 快速开始](/zh/deckuse/quick-start)检查选择器并验证输出。

## DeckHTML：在本地生成 PPTX

<span className="product-kicker">本地 Chromium · HTML 输入 · PPTX 输出</span>

```bash
npm install -g @deckflow/deckhtml
deckhtml deck.html -o deck.pptx --mode local --json --quiet
test -s deck.pptx
```

命令使用本地 Chromium，返回规范化路径、输出格式、执行模式和幻灯片数量。准备浏览器和幻灯片尺寸的 HTML 见 [DeckHTML 快速开始](/zh/deckhtml/quick-start)。
