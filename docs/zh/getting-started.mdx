## DeckProbe

在本地嗅探文档，并得到 Schema v2 JSON 报告。

### 安装

<Tabs>
  <Tab title="macOS 与 Linux">
    ```bash
    curl --proto '=https' --tlsv1.2 -LsSf \
      https://github.com/deckflow/deckprobe/releases/latest/download/deckprobe-installer.sh | sh
    ```
  </Tab>
  <Tab title="Windows">
    ```powershell
    powershell -ExecutionPolicy ByPass -c "irm https://github.com/deckflow/deckprobe/releases/latest/download/deckprobe-installer.ps1 | iex"
    ```
  </Tab>
</Tabs>

### 使用

```bash
deckprobe --pretty -t format,slide_count deck.pptx
```

### 结果

## DeckHTML

从一个 HTML 源文件生成 PPTX。

### 准备

将以下内容保存为 `index.html`：

```html
<!doctype html>
<html>
  <body>
    <section>
      <h1>Hello DeckHTML</h1>
      <p>My first generated slide.</p>
    </section>
  </body>
</html>
```

### 使用

无需全局安装，直接运行 npm 包：

```bash
npx -y @deckflow/deckhtml@latest index.html -o deck.pptx
```

### 结果

命令会写入 `deck.pptx`。调用方需要结构化命令结果时增加 `--json`：

```bash
npx -y @deckflow/deckhtml@latest index.html -o deck.pptx --json
```

可以继续阅读 [DeckHTML 快速开始](/zh/deckhtml/quick-start)、[CLI](/zh/deckhtml/cli/overview)或 [Node.js SDK](/zh/deckhtml/sdk/node)。

## DeckOps

安装 TypeScript SDK，将支持的文档解析为 Markdown：

```bash
npm install @deckops/sdk
```

```ts
import { createDeck } from '@deckops/sdk';

const deck = createDeck({ apiKey: process.env.DECKOPS_API_KEY });
const result = await deck.parseDetailed('./slides.pptx');

console.log(result.markdown);
console.log(result.taskId, result.type);
```

继续阅读 [DeckOps 快速开始](/zh/deckops/quick-start)、[任务模型](/zh/deckops/task-model)或[结构化解析结果](/zh/deckops/structured-results)。
