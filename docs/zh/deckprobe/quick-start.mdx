title: DeckProbe 快速开始
sidebarTitle: 快速开始
description: "安装 DeckProbe、下载示例 PDF、请求两个事实，并验证 Schema v2 结果。"
---

本流程使用原生 CLI，全部操作都在本机完成，不需要账号或 API Key。

<Steps>
  <Step title="安装预编译版本">
    <Tabs>
      <Tab title="macOS 与 Linux">
        ```bash
        curl --proto '=https' --tlsv1.2 -LsSf \
          https://github.com/deckflow/deckprobe/releases/latest/download/deckprobe-installer.sh | sh
        ```
      </Tab>
      <Tab title="Windows PowerShell">
        ```powershell
        powershell -ExecutionPolicy ByPass -c "irm https://github.com/deckflow/deckprobe/releases/latest/download/deckprobe-installer.ps1 | iex"
        ```

        安装程序修改用户 `Path` 后，请重启 Shell。
      </Tab>
    </Tabs>
  </Step>
  <Step title="验证可执行程序">
    ```bash
    deckprobe --version
    deckprobe --help
    ```

    也可以使用 Rust 1.88 或更高版本从源码安装：

    ```bash
    cargo install --git https://github.com/deckflow/deckprobe --locked deckprobe
    ```
  </Step>
  <Step title="下载已知输入">
    ```bash
    curl -L https://www.w3.org/WAI/ER/tests/xhtml/testfiles/resources/pdf/dummy.pdf \
      -o sample.pdf
    ```
  </Step>
  <Step title="请求格式和页数">
    ```bash
    deckprobe \
      --targets format,page_count \
      --view values \
      --pretty \
      sample.pdf
    ```
  </Step>
  <Step title="验证结果">
    成功的 Values Report 退出码为 `0`，包含 `schema_version: 2`、PDF Driver，以及类似以下内容的 `values`：

    ```json
    {
      "schema_version": 2,
      "tool_version": "2.3.0",
      "status": "ok",
      "view": "values",
      "driver": {
        "id": "pdf",
        "profile": "pdf"
      },
      "values": {
        "document.format": "pdf",
        "pdf.page_count": 1
      },
      "unresolved_targets": [],
      "diagnostics": []
    }
    ```

    完整结果还包含 `input`；部分 Target 被顺带解析时，可能出现其他字段。
  </Step>
</Steps>

<Tip>
  固定格式专属 Target 前，先运行 `deckprobe targets pdf --pretty`。请求的 Target 未解析时必须返回非零状态，可以添加 `--strict`。
</Tip>
