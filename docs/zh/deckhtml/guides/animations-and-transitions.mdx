DeckHTML 会区分元素入场动画和幻灯片之间的页面转场。

## 元素动画

PPTX 默认启用动画转换。DeckHTML 可以捕获：

- `data-animation` 以及可选的 Duration、Delay 和 Trigger 属性
- 支持的 CSS `@keyframes`
- 由 Class 触发的 Opacity 或 Transform Transition
- 全局 anime.js 调用

声明式效果当前可映射：`appear`、`fade`/`fade-in`、四个方向的 `fly-in-*`、`zoom`/`zoom-in`、`spin` 变体和四个方向的 `wipe-*`。触发方式支持 `click`、`with`、`after` 及对应的 `*Previous` 别名。超出支持范围的动画会保留最终视觉状态，并产生 `DECKHTML_ANIMATION_UNMAPPED` 诊断。

```html
<h1
  data-element-id="title"
  data-animation="fade"
  data-animation-duration="600"
  data-animation-trigger="after"
>
  Product update
</h1>
```

使用 `--no-animations` 或 `animations: false` 可以关闭入场动画导出。

动画映射仅应用于本地 PPTX 生成。PNG 捕获页面稳定后的可见状态，当前云端 CLI 任务不会接收本地动画选项。

## 页面转场

本地 PPTX 默认开启页面转场，每页会随机选择一个目录效果。可以固定一个效果、按逗号分隔的列表循环，也可以关闭。常用基础效果包括 `fade`、`push`、`wipe`、`cover`、`pull`、`split` 和 `dissolve`；传入未知名称时，CLI 会拒绝执行并在错误中列出可用目录。

```bash
deckhtml deck.html -o deck.pptx --slide-transition fade
deckhtml deck.html -o deck.pptx --slide-transition fade,push,wipe
deckhtml deck.html -o deck.pptx --no-slide-transitions
```

应用代码需要可复现的随机选择时，可以通过 Node API 的转场对象传入 `seed`。
