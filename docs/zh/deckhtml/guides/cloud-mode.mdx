Cloud 模式会上传已经物化的 HTML 输入，创建 HTML 转换任务，等待任务完成，下载结果并写入指定输出路径。

```bash
deckhtml deck.html -o deck.pptx --mode cloud
deckhtml deck.html -o deck.pptx --mode cloud --embed-fonts
```

## 认证行为

Cloud 模式支持稳定的访客 UUID。访客请求会被限频，并可能需要显式启动任务。生产环境建议登录或配置 API Key。

```bash
deckhtml auth login
deckhtml auth status
deckhtml config set api-key <key>
```

CI 环境使用 `DECKHTML_API_KEY`，无需交互式存储凭证。

## 与 Local 模式的区别

- 转换通过 DeckOps 任务远程执行。
- PPTX 输出支持 `--embed-fonts`。
- 异步任务完成后才下载结果文件。
- 当前云端没有返回逐元素报告时，Report 会使用聚合转换统计。

`auto` 只在已经配置凭证时选择 Cloud，否则选择 Local。
