## PPTX 转换

```ts
import { writeFile } from 'node:fs/promises';
import { convertHtmlToPptx } from '@deckflow/deckhtml';

const result = await convertHtmlToPptx({
  input: 'deck.html',
  allowLocalResources: true,
  platform: 'win',
  quiet: true,
});

await writeFile('deck.pptx', result.data);
console.log({
  slideCount: result.slideCount,
  mapping: result.report?.summary,
  diagnostics: result.diagnostics,
});
```

有序多文件输入使用 `inputs: ['01.html', '02.html']`。返回值包括 PPTX `Buffer`、幻灯片数量、使用字体、统计、资源与元素标识诊断，以及可用时的逐元素转换报告。

## PNG 转换

```ts
import { convertHtmlToPng } from '@deckflow/deckhtml';

const result = await convertHtmlToPng({
  input: 'deck.html',
  viewportWidth: 1280,
  viewportHeight: 720,
});
```

PNG 结果会为每个检测到的幻灯片返回一个图片 Buffer。函数不会选择文件名或写入文件：

```ts
await Promise.all(
  result.images.map((image, index) =>
    writeFile(`slide-${index + 1}.png`, image)
  )
);
```

## 多页与有序输入

```ts
const result = await convertHtmlToPptx({
  inputs: ['01-cover.html', '02-metrics.html', '03-summary.svg'],
  slideSelector: '.presentation-page',
  autoDetectSlides: true,
  excludeSelector: '.controls, .progress',
  quiet: true,
});
```

文件可能并行检查，但返回的演示文稿仍保持 `inputs` 顺序。`slideSelector` 会应用到每个输入内部。

直接 URL 会由 Chromium 发起导航：

```ts
const result = await convertHtmlToPptx({
  input: 'https://example.com/deck.html',
  resourcePolicy: { network: 'allow' },
});
```

页面需要受控会话状态时，请传入调用方持有的 `browserContext`。这与 CLI URL 路径不同：CLI 会先把 HTML 响应下载为文本。

## 资源策略

API 默认阻止未显式允许的本地子资源。相比宽松兼容开关 `allowLocalResources: true`，更建议使用限定目录的资源策略：

```ts
const result = await convertHtmlToPptx({
  input: '/work/deck/deck.html',
  resourcePolicy: {
    network: 'deny',
    allowedRoots: ['/work/deck/assets'],
    followSymlinks: false,
  },
});
```

被阻止的资源会出现在 `resourceDiagnostics` 和统一的 `diagnostics` 列表中。

## 严格模式

传入 `strict` 即启用严格门禁。对象中省略的选项默认采用最严格行为，除非显式放宽。

```ts
await convertHtmlToPptx({
  input: 'deck.html',
  strict: {
    requireElementIdentity: true,
    allowRaster: false,
    allowUnsupported: false,
    allowRemoteResources: false,
    failOnMissingFonts: true,
    allowUnmappedAnimations: false,
  },
});
```

严格模式失败会抛出名为 `ConversionError` 的错误，其中包含主诊断和收集到的诊断列表。

## 高级选项

API 还可以控制视口检测、目标字体平台、动画、页面转场、iframe 处理和调用方提供的 Playwright 运行环境。传入的 `browser` 或 `browserContext` 仍归调用方所有，DeckHTML 不会关闭它。
