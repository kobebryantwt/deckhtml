## PPTX 转换

```ts
import { writeFile } from 'node:fs/promises';
import { convertHtmlToPptx } from '@deckflow/deckhtml';

const result = await convertHtmlToPptx({
  input: 'deck.html',
  allowLocalResources: true,
  platform: 'win',
  quiet: true,
});

await writeFile('deck.pptx', result.data);
console.log(result.slideCount, result.report, result.diagnostics);
```

有序多文件输入使用 `inputs: ['01.html', '02.html']`。返回值包括 PPTX `Buffer`、Slide 数、使用字体、统计、资源与元素标识诊断，以及可用时的逐元素转换报告。

## PNG 转换

```ts
import { convertHtmlToPng } from '@deckflow/deckhtml';

const result = await convertHtmlToPng({
  input: 'deck.html',
  viewportWidth: 1280,
  viewportHeight: 720,
});
```

PNG 结果会为每个检测到的 Slide 返回一个图片 Buffer。

## Strict Mode

传入 `strict` 即启用严格门禁。对象中省略的 Flag 默认采用最严格行为，除非显式放宽。

```ts
await convertHtmlToPptx({
  input: 'deck.html',
  strict: {
    requireElementIdentity: true,
    allowRaster: false,
    allowUnsupported: false,
    allowRemoteResources: false,
    failOnMissingFonts: true,
    allowUnmappedAnimations: false,
  },
});
```

Strict 失败会抛出 `ConversionError`，其中包含主诊断和收集到的诊断列表。

## 高级选项

API 还可以控制 Slide Selector、排除 Selector、标识属性、自动检测、Viewport、Resource Policy、目标字体平台、动画、页面转场、iframe 模式与超时，以及调用方提供的 Playwright Browser。
