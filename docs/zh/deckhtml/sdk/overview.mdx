发布的 npm 包除了 CLI，还导出 Node.js API。它会返回 Buffer 和结构化元数据，不会替调用方写入文件。

```bash
npm install @deckflow/deckhtml pptxgenjs
```

主要转换函数：

- `convertHtmlToPptx()`
- `convertHtmlToPng()`
- `inspectHtmlFonts()`

Library 还导出转换报告辅助函数、页面转场目录与 Resolver、字体映射工具及公开转换类型。

应用需要注入浏览器、显式 Resource Policy、Strict Mode、回调，或直接访问结果 Buffer 和 Diagnostics 时，使用 SDK。
