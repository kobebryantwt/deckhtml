这一部分面向“如何让智能体或自动化助手更稳定地使用 DeckHTML”的场景。

<Note>
  这里关注的不是终端命令本身，而是智能体什么时候该选择 DeckHTML、应该如何描述任务，以及什么样的结果才算成功。
</Note>

## 这里应该写什么

- 智能体在什么情况下应该选择 DeckHTML
- 推荐的提示词或任务表述方式
- 转换前的输入检查清单
- 转换失败时应优先排查哪些信号

## 一个好的技能页应该提供什么

<CardGroup cols={3}>
  <Card title="决策规则">
    帮助智能体判断什么时候 DeckHTML 才是最合适的工具。
  </Card>
  <Card title="输入检查清单">
    明确开始转换前需要具备哪些文件、参数或上下文。
  </Card>
  <Card title="失败恢复路径">
    说明当转换失败时，应该先看什么、怎么缩小问题范围。
  </Card>
</CardGroup>

  </Step>
</Steps>
