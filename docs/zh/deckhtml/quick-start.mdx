---

<Steps>
  <Step title="创建一页幻灯片">
    将下面的内容保存为 `deck.html`。声明 Deck 尺寸可以让 DeckHTML 使用预期的 Viewport。

    ```html
    <!doctype html>
    <html>
      <head>
        <meta charset="utf-8" />
        <meta name="deck-size" content="1280x720" />
        <style>
          * { box-sizing: border-box; }
          body { margin: 0; font-family: Arial, sans-serif; }
          .slide-container {
            width: 1280px;
            height: 720px;
            padding: 72px;
            background: #f7fafc;
          }
        </style>
      </head>
      <body>
        <section class="slide-container" data-slide-id="intro">
          <h1 data-element-id="title">Hello DeckHTML</h1>
          <p data-element-id="summary">HTML layout, presentation output.</p>
        </section>
      </body>
    </html>
    ```
  </Step>
  <Step title="在本地转换">
    ```bash
    npx -y @deckflow/deckhtml@latest deck.html \
      -o deck.pptx \
      --mode local \
      --json
    ```
  </Step>
  <Step title="检查结果">
    命令成功时退出码为 `0`，写入 `deck.pptx`，并输出类似下面的 JSON：

    ```json
    {
      "ok": true,
      "input": ["deck.html"],
      "output": "deck.pptx",
      "format": "pptx",
      "mode": "local",
      "slideCount": 1
    }
    ```
  </Step>
  <Step title="生成转换报告">
    ```bash
    npx -y @deckflow/deckhtml@latest deck.html \
      -o deck.pptx \
      --mode local \
      --report \
      --force
    ```

    在 `deck.pptx.report.json` 中检查原生、矢量、栅格、忽略和不支持的映射。
  </Step>
</Steps>
