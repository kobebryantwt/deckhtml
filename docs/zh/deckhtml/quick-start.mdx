description: "安装 DeckHTML、验证浏览器运行时，并在本地生成 PPTX。"
---

这条路径会让源文件留在本机。需要 Node.js 18 或更高版本，以及兼容的 Chromium、Chrome 或 Edge 可执行文件。

<Steps>
  <Step title="安装并验证 DeckHTML">
    ```bash
    npm install -g @deckflow/deckhtml
    deckhtml --version
    ```
  </Step>
  <Step title="准备浏览器">
    DeckHTML 会依次检查 `DECKHTML_CHROMIUM_EXECUTABLE_PATH`、Playwright 管理的浏览器，以及系统中的 Chrome 或 Edge。如果都不可用，可以通过 Playwright 安装 Chromium：

    ```bash
    npx -y playwright install chromium
    ```

    在容器或自定义镜像中，请指定准确的可执行文件：

    ```bash
    export DECKHTML_CHROMIUM_EXECUTABLE_PATH=/path/to/chromium
    ```
  </Step>
  <Step title="创建幻灯片">
    保存为 `deck.html`：

    ```html
    <!doctype html>
    <html>
      <head>
        <meta charset="utf-8" />
        <meta name="deck-size" content="1280x720" />
        <style>
          * { box-sizing: border-box; }
          body { margin: 0; font-family: Arial, sans-serif; }
          .slide-container { width: 1280px; height: 720px; padding: 72px; background: #f7fafc; }
        </style>
      </head>
      <body>
        <section class="slide-container" data-slide-id="intro">
          <h1 data-element-id="title">Hello DeckHTML</h1>
          <p data-element-id="summary">HTML layout, presentation output.</p>
        </section>
      </body>
    </html>
    ```
  </Step>
  <Step title="转换并验证">
    ```bash
    deckhtml deck.html -o deck.pptx --mode local --json --quiet
    test -s deck.pptx && echo "deck.pptx created"
    ```

    PowerShell：

    ```powershell
    if (!(Test-Path deck.pptx) -or (Get-Item deck.pptx).Length -eq 0) {
      exit 1
    }
    ```

    `--quiet` 会让标准输出保持机器可读。JSON 结果使用规范化后的绝对路径，因此具体值取决于当前工作目录：

    ```json
    {
      "ok": true,
      "input": ["/absolute/path/deck.html"],
      "output": "/absolute/path/deck.pptx",
      "format": "pptx",
      "mode": "local",
      "slideCount": 1
    }
    ```
  </Step>
  <Step title="检查转换决策">
    ```bash
    deckhtml deck.html -o deck.pptx --mode local --report --force
    ```

    在 `deck.pptx.report.json` 中检查原生、矢量、栅格、忽略和不支持的元素。
  </Step>
</Steps>
