## 默认输出

默认模式面向人类阅读，可能输出进度、字体提示和产物路径，不应把它当作稳定的 stdout 协议解析。多页 PNG 会输出每个文件路径。

DeckHTML 默认拒绝覆盖已有的本地产物，只有明确需要替换时才传 `--force`。

## JSON 输出

需要机器可读 stdout 时，请同时使用 `--json --quiet`。当前 CLI 只加 `--json` 时，仍可能在最终 Envelope 前把人类可读转换日志写入 stdout。

```bash
deckhtml deck.html -o deck.pptx --mode local --json --quiet
```

```json
{
  "ok": true,
  "input": ["/absolute/path/deck.html"],
  "output": "/absolute/path/deck.pptx",
  "format": "pptx",
  "mode": "local",
  "slideCount": 3
}
```

根据格式和参数，Envelope 还可能包含 `outputs`、`stats`、`simplified` 和 `report`。

## 日志

- `--quiet` 隐藏非必要进度和提示。
- `--verbose` 把更多执行详情写入 stderr。
- `--quiet` 和 `--verbose` 不能同时使用。

## 报告

`--report` 写入 `<output>.report.json`。Local PPTX 提供逐元素映射和诊断；Cloud 转换可能返回聚合报告。详见[报告与诊断](/zh/deckhtml/reference/report-schema)。

## 退出行为

成功转换退出 `0`。用法、输入、浏览器、转换、上传或输出失败会返回非零退出码，并根据输出模式写入文本或结构化错误。以退出码为准，不要仅通过部分生成的文件判断成功。
