## 默认输出

命令成功后，默认把进度写入 stderr，把生成产物路径写入 stdout。多页 PNG 会输出每个文件路径。

DeckHTML 默认拒绝覆盖已有的本地产物，只有明确需要替换时才传 `--force`。

## JSON 输出

`--json` 会让最终成功 Envelope 保持在 stdout，便于脚本解析。

```bash
deckhtml deck.html -o deck.pptx --mode local --json
```

```json
{
  "ok": true,
  "input": ["deck.html"],
  "output": "deck.pptx",
  "format": "pptx",
  "mode": "local",
  "slideCount": 3
}
```

根据格式和参数，Envelope 还可能包含 `outputs`、`stats`、`simplified` 和 `report`。

## 日志

- `--quiet` 隐藏非必要进度和提示。
- `--verbose` 把更多执行详情写入 stderr。
- `--quiet` 和 `--verbose` 不能同时使用。

## 报告

`--report` 写入 `<output>.report.json`。Local PPTX 提供逐元素映射和诊断；Cloud 转换可能返回聚合报告。详见[报告与诊断](/zh/deckhtml/reference/report-schema)。

## 退出行为

成功转换退出 `0`。用法、输入、浏览器、转换、上传或输出失败会返回非零退出码，并根据输出模式写入文本或结构化错误。以退出码为准，不要仅通过部分生成的文件判断成功。
