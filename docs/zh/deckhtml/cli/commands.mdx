## 转换

```text
deckhtml [global options] [inputs...]
```

| 参数 | 行为 |
| --- | --- |
| `-o, --output <path>` | 输出 `.pptx` 或 `.png`；扩展名决定格式 |
| `--mode <mode>` | `auto`、`local` 或 `cloud`，默认 `auto` |
| `--width <pixels>` | 覆盖 Viewport 宽度，CLI 按 16:9 计算高度 |
| `--platform <platform>` | 字体映射目标：`win`、`mac`、`ios`、`android` 或 `linux` |
| `--embed-fonts` | 嵌入字体，仅 Cloud |
| `--report` | 在输出文件旁写入转换报告 |
| `--executable-path <path>` | Local 模式使用指定 Chromium |
| `--exclude <selector>` | 排除匹配的运行时或导航元素 |
| `--identity-attribute <name>` | 自定义稳定元素标识属性 |
| `--force` | 覆盖已有输出 |
| `--no-animations` | 关闭元素入场动画导出 |
| `--slide-transition <effects>` | 选择单个页面转场或逗号分隔循环列表 |
| `--no-slide-transitions` | 关闭页面转场 |
| `--iframes <mode>` | `inspect`、`screenshot` 或 `skip`，仅 Local |
| `--iframe-load-timeout-ms <ms>` | 设置 iframe 加载超时 |
| `--json` | 输出机器可读的最终 Envelope |
| `--quiet` | 隐藏非必要输出 |
| `-v, --verbose` | 把详细日志写入 stderr |
| `-V, --version` | 输出版本 |
| `-h, --help` | 输出帮助 |

## 认证

```bash
deckhtml auth login [--port <port>]
deckhtml auth status
```

## 配置

```bash
deckhtml config set api-key <key>
deckhtml config set space-id <id>
deckhtml config set webhook <url>
deckhtml config set retention-hours <0-99>
deckhtml config show
```
