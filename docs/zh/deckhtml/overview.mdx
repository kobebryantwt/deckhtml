DeckHTML 是 Deckflow 产品体系中的 HTML-native Deck Engine，专项支持以 HTML 作为幻灯片结构和视觉设计源的创作趋势，并通过本地或云端执行路径生成演示文稿产物。

## 产品边界

DeckHTML 从 HTML 生成演示文稿产物。处理已有文档时，嗅探使用 [DeckProbe](/zh/deckprobe/overview)，渲染使用 [DeckRender](/zh/deckrender/overview)，Parse 成 IR、Extract 或 Convert 使用 [DeckOps](/zh/deckops/overview)，Manipulate 支持的 Office 源文件使用 [DeckUse](/zh/deckuse/overview)。
