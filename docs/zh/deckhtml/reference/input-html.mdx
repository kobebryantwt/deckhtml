CLI 接受本地 HTML/SVG 文件、有序文件、标准输入中的 HTML，或一个或多个 HTTP(S) HTML URL；同一次调用不能混用 URL 和本地路径。Node.js API 通过 `input` 或 `inputs` 接收本地路径或直接 HTTP(S) URL，但不会读取标准输入。

## 幻灯片结构

多页 HTML 文档应使用重复且符合幻灯片尺寸的容器。常用选择器包括 `.slide-container`、`.slide-wrap`、`.slide`、`section.slide` 和 `[data-slide]`；当容器可见、尺寸合适且包含有效内容时，也能识别 `.deck-slide`、`.slide-page` 等语义化类名。自动多页检测至少需要两个符合条件的容器。

```html
<main>
  <section class="slide-container" data-slide-id="title">...</section>
  <section class="slide-container" data-slide-id="metrics">...</section>
</main>
```

也可以每页传入一个 HTML 或 SVG 文件。即使多个文件并行检查，DeckHTML 仍会保持参数顺序。

```bash
deckhtml 01-title.html 02-metrics.html 03-summary.html -o deck.pptx
```

Node.js API 可以显式指定非标准幻灯片容器：

```ts
await convertHtmlToPptx({
  input: 'deck.html',
  slideSelector: '.presentation-page',
  autoDetectSlides: false,
});
```

有序文件、批量 URL、并行处理和多页 PNG 命名请参阅[多页与批量输入](/zh/deckhtml/guides/multi-page-and-batch)。

## 尺寸和视口

DeckHTML 可以从 `meta[name="deck-size"]`、支持的 CSS 尺寸变量、数值型视口元数据、固定幻灯片容器、本地关联 CSS、舞台配置或 SVG `viewBox` 检测尺寸；否则回退到 `1280 × 720`。使用 `--width` 覆盖宽度时，CLI 按 16:9 计算高度。

幻灯片容器与浏览器视口应保持相同宽高比。固定尺寸的幻灯片布局比依赖文档滚动的布局更可预测。

## 稳定标识

下游报告或严格检查需要稳定关联源元素时，使用 `data-slide-id` 和 `data-element-id`。

```html
<section class="slide-container" data-slide-id="results">
  <h2 data-element-id="results-title">Results</h2>
</section>
```

Node API 可以自定义标识属性；CLI 对应 `--identity-attribute`。

## 排除运行时界面

导航、进度条和控制器不应进入幻灯片，可通过 `--exclude` 或 `excludeSelector` 排除。

```bash
deckhtml deck.html -o deck.pptx --exclude '.controls, .progress'
```

## 资源和运行时状态

- 本地模式下，把相对资源放在 HTML 附近。
- 转换时确保字体已加载、可见内容已经进入 DOM。
- 不要把关键内容只放在 Hover 状态。
- 在意可编辑性时优先使用 DOM 文本和形状；Canvas 通常会被栅格化。
- URL 输入会先下载响应 HTML，不会保留已有的交互式浏览器会话。

## URL 输入边界

CLI 和 Node.js API 使用不同的 URL 处理路径。

### CLI URL

CLI 通过 Node.js `fetch` 获取响应文本，并在本地或云端转换前将其暂存为 `.html` 文件。

- 不会转发请求头、Cookie 或用户浏览器的登录状态。
- 相对资源会相对于临时本地文件解析，不会自动相对于原始 URL 解析。
- 请使用绝对资源 URL，或在 HTML 响应中加入合适的 `<base href="https://example.com/path/">`。
- 即使 URL 路径使用其他扩展名，响应也会被当作 HTML 文本处理；URL 输入适用于 HTML 页面，不适用于远程 SVG 或任意二进制文件。

### Node.js API URL

Node.js API 会把 HTTP(S) 输入直接交给 Chromium。相对资源以页面 URL 为基准解析；调用方注入的 `browserContext` 也可以携带 Cookie 或其他会话状态。

```ts
import { convertHtmlToPptx } from '@deckflow/deckhtml';

const result = await convertHtmlToPptx({
  input: 'https://example.com/deck.html',
  resourcePolicy: { network: 'allow' },
});
```

需要认证会话时，通过 `browser: { browserContext }` 传入调用方持有的 Playwright `browserContext`。浏览器上下文的建立与保护由调用方负责。公开且自包含的 HTML 响应可以使用 CLI；需要直接浏览器导航或受控会话状态时，使用 Node.js API。

## SVG 输入

本地文件输入可以包含 `.svg`。DeckHTML 会先确认文件包含可用的 SVG 根节点，再映射支持的几何与文字；复杂内容仍可能回退为栅格图。支持 SVG 并不代表每一种 SVG 滤镜、脚本或浏览器效果都有可编辑的 PowerPoint 对应物。
