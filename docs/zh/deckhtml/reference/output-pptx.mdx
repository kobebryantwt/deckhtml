PPTX 输出会同时包含可编辑 Office 元素和视觉降级。DeckHTML 默认不会把整页压成一张图，但不存在稳定原生映射的单个元素可能被栅格化。

## 建议检查

- 幻灯片数量和尺寸
- 文本内容、换行、字体和阅读顺序
- 图片、表格、形状、SVG、公式和媒体
- 元素动画和页面转场
- 报告中的栅格化或不支持元素
- 缺失字体和资源诊断

## 字体

本地转换会根据目标平台映射 CSS 字体栈。云端转换还可以通过 `--embed-fonts` 嵌入匹配的字体文件。

## 输出安全

本地 CLI 转换默认拒绝覆盖已有文件，只有传入 `--force` 才会替换。当前云端下载路径会直接写入结果，因此自动化任务应使用独立输出路径。Node.js API 只返回 Buffer，不会自动写入磁盘。

可编辑性属于交付要求而不是偏好时，使用严格模式和逐元素报告。
