DeckUse 用于对现有 PowerPoint 演示文稿进行聚焦、文件原生的修改。它把 PPTX 打开为临时或持久化 Workspace，根据 Selector 定位幻灯片和 Shape，更新支持的属性，再把 Workspace 打包为另一个可编辑 PPTX。

| 项目 | 当前契约 |
| --- | --- |
| 输入 | 一个 `.pptx` 文件或已初始化的 DeckUse Workspace |
| 输出 | 修改后的 `.pptx`；读取命令会输出结构信息 |
| 执行位置 | 本地 Node.js 进程；不上传文件、不需要认证 |
| 接入方式 | 已验证的 `deckuse` CLI；Node.js API 已有源码，但 `0.2.0` ESM 构建存在运行时导入问题 |
| 运行环境 | Node.js 18 或更高版本；Workspace 打包需要 `zip` 与 `unzip` 命令 |

## DeckUse 适合什么

- 列出幻灯片并查看页面结构。
- 通过页面、Shape、文本或规范 ID Path Selector 读取文本。
- 设置段落文本，或在全局、指定页面中替换文本。
- 使用归一化的 `left`、`top` 坐标移动已有 Shape。
- 在一个 Workspace 中完成多次修改，再统一提交输出文件。

```text
input.pptx → 打开或初始化 Workspace → 选择已有内容 → 修改 → Commit → updated.pptx
```

<Warning>
  当前版本只支持 PPTX。它没有添加或删除幻灯片、元素的命令，也不能编辑 DOCX、XLSX 或 Keynote。请保留原始文件，并使用 PowerPoint 或其他兼容软件检查输出。
</Warning>
