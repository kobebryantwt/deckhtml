DeckUse CLI 通过本地工作区维护现有 PPTX。六个终端命令覆盖文档处理流程；所有内容修改都使用 JSON 表达，再交给 `apply` 执行。

```text
input.pptx → init → inspect / query → apply → validate → commit → updated.pptx
```

## 安装并验证

安装 Node.js 18 或更高版本，再从 npm 安装 CLI：

```bash
node --version
npm install -g @deckflow/deckuse
deckuse --version
deckuse --help
```

DeckUse 完全在本地运行，不需要 DeckFlow 账号或 API Key。

## 命令一览

| 命令 | 作用 | 继续阅读 |
| --- | --- | --- |
| `init <input> <workspace>` | 把一个 PPTX 导入持久工作区 | [检查与查询](/zh/deckuse/cli/inspect-and-query) |
| `inspect <workspace>` | 返回能力信息和完整文档索引 | [检查与查询](/zh/deckuse/cli/inspect-and-query#检查文档) |
| `query <workspace> [selector]` | 查找与选择器匹配的索引元素 | [检查与查询](/zh/deckuse/cli/inspect-and-query#查询候选元素) |
| `apply <workspace>` | 从文件或标准输入执行 JSON 修改命令 | [修改与导出](/zh/deckuse/cli/apply-and-export) |
| `validate <workspace>` | 导出前检查 PPTX 内部关系 | [校验并提交](/zh/deckuse/cli/apply-and-export#校验并提交) |
| `commit <workspace>` | 把工作区导出为另一份 PPTX | [校验并提交](/zh/deckuse/cli/apply-and-export#校验并提交) |

`replaceText`、`setProperties`、`setTransform`、`add`、`remove`、`duplicate` 和 `replacePicture` 等修改能力是 JSON 命令类型，不是独立的终端子命令。具体请求结构请查看 [JSON 命令参考](/zh/deckuse/commands)。

## 最短 CLI 流程

```bash
deckuse init input.pptx ./workspace --json
deckuse query ./workspace 'text=2025' --limit 100 --json
printf '%s\n' '{"type":"replaceText","find":"2025","replace":"2026"}' \
  | deckuse apply ./workspace --json
deckuse validate ./workspace --json
deckuse commit ./workspace -o updated.pptx --json
```

即使 `replaceText` 支持全局查找，也不建议跳过修改前的查询。批量修改前应先检查候选元素；只修改一个确定对象时，应使用查询结果返回的元素引用。
