```bash
npm install deckuse
```

<Warning>
  当前 `deckuse@0.2.0` ESM 入口在 Node.js 22 下会报错：`Dynamic require of "child_process" is not supported`。软件包构建修正前，生产环境请使用已经验证的 CLI。下文描述源码导出，不代表当前已验证的安装包契约。
</Warning>

软件包导出了 CLI 使用的同一组命令函数，以及更底层的 Workspace、Selector、Reader、Writer、错误类和类型 API。

## 执行文件原生命令

```ts
import { replaceTextCommand } from 'deckuse';

await replaceTextCommand(
  './input.pptx',
  '2025',
  '2026',
  { output: './updated.pptx' },
);
```

命令函数会输出与 CLI 相同的进度信息。直接修改 PPTX 时必须提供输出路径。

## 管理 Workspace

```ts
import {
  Workspace,
  SelectorParser,
  SelectorResolver,
} from 'deckuse';

const workspace = await Workspace.load('./working.deck');
const selector = SelectorParser.parse("slide:1/text[contains('Revenue')]");
const paragraphs = await SelectorResolver.resolveParagraphs(
  selector,
  workspace.metadata,
  workspace.workspaceDir,
);

for (const paragraph of paragraphs) {
  console.log(paragraph.idPath, paragraph.paragraphIndex, paragraph.text);
}
```

公开导出包括 `Workspace`、`SelectorParser`、`SelectorResolver`、`PptxReader`、`PptxWriter`、命令函数、DeckUse 错误类，以及 Workspace/Selector 结果类型。

<Warning>
  底层 Reader 与 Writer 暴露的是实现相关的 PPTX 结构，并不提供宽泛兼容性保证。当前已支持的操作优先使用命令函数，同时保留源文件并检查输出演示文稿。
</Warning>
