PPTX 是 DeckUse 当前唯一实现的编辑适配器。本页把“可以索引的内容”和“可以写入的内容”分开说明，避免接入方误以为 `inspect` 返回的每种对象都支持所有修改操作。

## 可索引结构

| 结构 | 索引信息 |
| --- | --- |
| 幻灯片 | 稳定的演示文稿幻灯片 ID 和 Slide Part 路径 |
| 文本框与形状 | 元素引用、名称、文本、几何信息和 OOXML 位置 |
| 连接线与组合 | 元素引用、名称、几何信息和祖先路径 |
| 图片 | 元素引用、几何信息、Media Part、本地媒体路径、文件名、媒体类型和外链状态 |
| 表格 | 表格引用，以及单元格引用、行列位置和单元格文本 |
| 图表 | Chart Part、标题、缓存的系列名称和值，以及是否存在内嵌工作簿 |
| 演讲者备注 | Notes Part、幻灯片 ID 和索引文本 |
| 母版、版式与主题 | Part 引用、文本和发现的 `srgbClr` 值 |

使用 `deckuse inspect` 返回完整索引，或使用 `deckuse query` 进行筛选。返回的引用只属于读取它的工作区和版本。

## 可写入操作

| 范围 | 已实现操作 |
| --- | --- |
| 文本 | 设置一个引用节点；通过可选选择器和数量限制执行字面量或正则替换 |
| 几何信息 | 设置 `x`、`y`、`width`、`height` 和旋转角度 |
| 形状与文字属性 | 名称、填充、描边、文字颜色、字体、字号、粗体、斜体、下划线、隐藏状态，以及直接替换 `srgbClr` |
| 幻灯片 | 添加、复制和删除 |
| 元素 | 添加文本框/形状、连接线、组合、图片和表格；复制或删除引用元素 |
| 图片 | 从文件或 Base64 添加；替换内嵌媒体；清理不再被引用的媒体 |
| 表格 | 添加表格；定位索引单元格并替换文本 |
| 演讲者备注 | 读取索引备注，并替换引用 Notes Part 中的文本 |
| 图表 | 设置标题、缓存的系列名称和缓存数值 |
| 工作流 | 试运行、原子或非原子批处理、校验、版本冲突检测、操作日志和导出 |

准确的 Payload 和单位请查看 [JSON 命令参考](/zh/deckuse/commands)。

## 保留行为

- 尽量保留未知的文件包 Part 和未修改的 XML。
- ZIP 条目会重新压缩，因此保留指解压后的内容，不保证压缩包字节完全相同。
- 复制幻灯片时克隆可变的备注和图表 Part；版式、主题与媒体可能继续共享。
- 删除图片或幻灯片时，只删除已经没有任何关系引用的媒体。
- 文本替换可能把多个文本 Run 合并为一个，并保留第一个 Run 的样式。

## 接入边界

DeckUse 不是渲染或视觉质检引擎。文件包校验会检查无法解析的内部关系，但不会判断外观、重叠、字体替换、每一条 OOXML 规则或设计质量。

图表命令修改 OOXML 图表缓存。存在内嵌工作簿时，DeckUse 返回 `EMBEDDED_WORKBOOK_NOT_SYNCHRONIZED`，因为工作簿本身不会被重写。

DOCX、XLSX、Keynote 和 Numbers 适配器当前返回 `FORMAT_NOT_IMPLEMENTED`。需要视觉产物时使用 [DeckRender](/zh/deckrender/overview)，需要解析或转换时使用 [DeckOps](/zh/deckops/overview)。
