title: DeckUse 快速开始
sidebarTitle: 快速开始
description: "从源码安装 DeckUse，检查并替换已知 PPTX 中的文本，校验工作区并导出结果。"
---

本流程全部在本机执行，不需要 DeckFlow 账号或 API Key。当前公开包的依赖尚未完整发布，因此这里使用源码安装。

<Steps>
  <Step title="检查运行环境">
    请安装 Node.js 24 或更高版本、pnpm 10 和 Git。

    ```bash
    node --version
    pnpm --version
    git --version
    ```
  </Step>
  <Step title="构建并链接 CLI">
    ```bash
    git clone https://github.com/deckflow/deckuse.git
    cd deckuse
    pnpm install
    pnpm install:global
    deckuse --help
    ```

    `pnpm install:global` 会构建全部工作区软件包、部署自包含的生产依赖树，并链接 `deckuse` 可执行程序。当前 `--version` 输出仍是内部占位值，请使用 `deckuse --help` 验证安装，不要根据显示的版本号判断依赖版本。
  </Step>
  <Step title="下载已知 PPTX">
    ```bash
    curl -fL https://docs.deckflow.com/images/deckuse-sample.pptx \
      -o input.pptx
    ```

    示例中包含 `Revenue 2025`，所以下面的查询和替换都有已知匹配。首次跑通后，可以换成自己的 PPTX。
  </Step>
  <Step title="创建工作区">
    ```bash
    deckuse init input.pptx ./workspace --json
    ```

    成功时返回 `{ "ok": true, ... }`，并创建 `workspace/package.pptx`，以及 `.deckuse` 下的清单、索引、媒体缓存和操作日志。
  </Step>
  <Step title="检查匹配元素">
    ```bash
    deckuse query ./workspace 'text=Revenue' --limit 10 --json
    ```

    确认结果中有一个 `text` 为 `Revenue 2025` 的文本框。后续命令需要精确修改单个对象时，请保留查询返回的 `ref`。
  </Step>
  <Step title="执行确认后的替换">
    把下面的命令保存为 `replace.json`：

    ```json
    {
      "type": "replaceText",
      "find": "2025",
      "replace": "2026",
      "selector": "kind=textbox"
    }
    ```

    在工作区中执行：

    ```bash
    deckuse apply ./workspace --input replace.json --json
    ```

    CLI 会为这条顶层命令补充协议版本、工作区 ID 和当前事务版本。请确认 `ok` 为 `true`，并且 `value.matched` 大于零。
  </Step>
  <Step title="校验并导出">
    ```bash
    deckuse validate ./workspace --json
    deckuse commit ./workspace -o updated.pptx --json
    ```

    目标文件已存在时，`commit` 会拒绝覆盖；明确需要覆盖时再添加 `--force`。
  </Step>
  <Step title="验证导出文件">
    ```bash
    deckuse init updated.pptx ./verification --json
    deckuse query ./verification 'text=2026' --limit 10 --json
    test -s updated.pptx
    ```

    PowerShell 中请把最后一行替换为：

    ```powershell
    if (!(Test-Path updated.pptx) -or (Get-Item updated.pptx).Length -eq 0) { exit 1 }
    ```

    文件包校验不检查视觉布局。交付前请打开或渲染 `updated.pptx`。
  </Step>
</Steps>
