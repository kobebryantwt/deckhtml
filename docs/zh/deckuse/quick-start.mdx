---
title: DeckUse 快速开始
sidebarTitle: 快速开始
description: "安装 DeckUse，检查并替换已知 PPTX 中的文本，校验工作区并导出结果。"
---

本流程全部在本机执行，不需要 DeckFlow 账号或 API Key。

<Steps>
  <Step title="安装 CLI">
    请先安装 Node.js 18 或更高版本，再从 npm 安装 DeckUse：

    ```bash
    node --version
    npm install -g @deckflow/deckuse
    deckuse --version
    deckuse --help
    ```
  </Step>
  <Step title="下载公开测试 PPTX">
    ```bash
    curl -fL https://raw.githubusercontent.com/scanny/python-pptx/278b47b1dedd5b46ee84c286e77cdfb0bf4594be/tests/test_files/test.pptx \
      -o input.pptx
    ```

    这份固定版本的测试文件来自公开的 [python-pptx 测试套件](https://github.com/scanny/python-pptx/blob/278b47b1dedd5b46ee84c286e77cdfb0bf4594be/tests/test_files/test.pptx)，其中有且只有一个可编辑文本框包含 `Presentation Title Text`，所以下面的查询和替换都有确定结果。首次跑通后，可以换成自己的 PPTX。
  </Step>
  <Step title="创建工作区">
    ```bash
    deckuse init input.pptx ./workspace --json
    ```

    成功时返回 `{ "ok": true, ... }`，并创建 `workspace/package.pptx`，以及 `.deckuse` 下的清单、索引、媒体缓存和操作日志。
  </Step>
  <Step title="检查匹配元素">
    ```bash
    deckuse query ./workspace 'text=Presentation Title' --limit 10 --json
    ```

    确认结果中只有一个文本框，并且 `text` 为 `Presentation Title Text`。后续命令需要精确修改单个对象时，请保留查询返回的 `ref`。
  </Step>
  <Step title="执行确认后的替换">
    把下面的命令保存为 `replace.json`：

    ```json
    {
      "type": "replaceText",
      "find": "Presentation Title Text",
      "replace": "DeckUse Updated Title",
      "selector": "kind=textbox",
      "limit": 1
    }
    ```

    在工作区中执行：

    ```bash
    deckuse apply ./workspace --input replace.json --json
    ```

    CLI 会为这条顶层命令补充协议版本、工作区 ID 和当前事务版本。请确认 `ok` 为 `true`，并且 `value.matched` 大于零。
  </Step>
  <Step title="校验并导出">
    ```bash
    deckuse validate ./workspace --json
    deckuse commit ./workspace -o updated.pptx --json
    ```

    目标文件已存在时，`commit` 会拒绝覆盖；明确需要覆盖时再添加 `--force`。
  </Step>
  <Step title="验证导出文件">
    ```bash
    deckuse init updated.pptx ./verification --json
    deckuse query ./verification 'text=DeckUse Updated Title' --limit 10 --json
    test -s updated.pptx
    ```

    PowerShell 中请把最后一行替换为：

    ```powershell
    if (!(Test-Path updated.pptx) -or (Get-Item updated.pptx).Length -eq 0) { exit 1 }
    ```

    文件包校验不检查视觉布局。交付前请打开或渲染 `updated.pptx`。
  </Step>
</Steps>
