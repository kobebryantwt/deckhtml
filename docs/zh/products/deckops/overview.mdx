# DeckOps

DeckOps 是深度解析和单向文档操作层。它的解析目标是 **Document Information**：对文件身份、物理与逻辑结构，以及已提取内容智能的结构化描述。

解析完成后，Document Information 可以进一步 Schema 化为 IR，供下游分析、转换或还原使用。DeckOps 实现可用后，再补充具体 IR 契约。

## 适用场景

- 工作流需要实际文本、图片、表格、图表、公式、评论或其他文档对象。
- 需要表达页面、幻灯片、工作表、章节、母版、版式或工作簿结构，而不只是计数。
- 下游处理需要对象位置、样式、关系和格式专属行为。
- 解析结果需要 Schema 化为 IR，或还原成其他支持的格式。

## 产品边界

DeckOps 比 [DeckProbe](/zh/products/deckprobe/overview) 更深入：Probe 返回目标式文档事实及证据，Ops 构建包含实际内容的结构模型。

在产品模型中，DeckOps 仍然是单向操作。需要通过源文件感知模型应用变更并写回支持的源文件时，使用 [DeckUse](/zh/products/deckuse/overview)；结果目标是视觉画面而非结构化内容时，使用 [DeckRender](/zh/products/deckrender/overview)。
