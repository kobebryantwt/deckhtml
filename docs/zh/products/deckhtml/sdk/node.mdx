如果你的转换流程运行在 JavaScript 或 TypeScript 服务、worker 或内部工具里，就更适合使用 Node SDK。

## 安装

```bash
npm install @deckflow/deckhtml playwright pptxgenjs
```

这个包把 `playwright` 和 `pptxgenjs` 声明为 peer runtime dependencies。实际使用时，你的运行环境里需要能解析到这两个依赖，因为转换器栈会直接导入它们。

## 导入程序化接口

包主入口暴露了 `convertHtmlToPptx()`：

```ts
import { convertHtmlToPptx } from '@deckflow/deckhtml';
```

## 基础示例

```ts
import { promises as fs } from 'node:fs';
import { convertHtmlToPptx } from '@deckflow/deckhtml';

const result = await convertHtmlToPptx({
  input: 'index.html'
});

await fs.writeFile('deck.pptx', result.data);
console.log(result.slideCount);
```

## 多文件输入

```ts
import { promises as fs } from 'node:fs';
import { convertHtmlToPptx } from '@deckflow/deckhtml';

const result = await convertHtmlToPptx({
  inputs: ['title.html', 'agenda.html', 'summary.html']
});

await fs.writeFile('deck.pptx', result.data);
```

## 常用 `ConversionOptions`

类型定义里常用的参数包括：

| 参数 | 类型 | 含义 |
| --- | --- | --- |
| `input` | `string` | 单个 HTML 或 SVG 输入文件 |
| `inputs` | `string[]` | 多个 HTML 或 SVG 文件，按顺序组合成一个 PPTX |
| `slideSelector` | `string` | 覆盖默认的分页选择器 |
| `splitByHeight` | `boolean` | 把一个输入按纵向高度切成多页 |
| `autoDetectSlides` | `boolean` | 自动识别一个 HTML 文件中的多页结构 |
| `viewportWidth` | `number` | 浏览器视口宽度（像素） |
| `viewportHeight` | `number` | 浏览器视口高度（像素） |
| `allowLocalResources` | `boolean` | 允许 Playwright 加载 `file://` 子资源 |
| `platform` | `PlatformTarget` | 通用字体映射目标：`win`、`mac`、`ios`、`android`、`linux` |
| `quiet` | `boolean` | 抑制非必要控制台输出 |

## 视口与平台控制示例

```ts
import { promises as fs } from 'node:fs';
import { convertHtmlToPptx } from '@deckflow/deckhtml';

const result = await convertHtmlToPptx({
  input: 'slides.html',
  viewportWidth: 1440,
  viewportHeight: 810,
  platform: 'win',
  quiet: true
});

await fs.writeFile('deck.pptx', result.data);
```

## 返回值

`ConversionResult` 主要包含：

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `data` | `Buffer` | 最终 PPTX 二进制数据 |
| `slideCount` | `number \| undefined` | 有条件时返回的页数 |
| `usedFonts` | `string[] \| undefined` | 转换过程中解析出的字体列表 |
| `stats` | `ConversionStats \| undefined` | 元素和字体统计信息 |

## 实用说明

Node SDK 当前主要围绕 `convertHtmlToPptx()` 提供 PPTX 生成能力。更广义的终端工作流、认证流程和云端参数仍然更适合通过 CLI 理解和使用。
