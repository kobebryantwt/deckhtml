本地模式会在调用 DeckHTML 的当前机器上直接执行转换流程。

## 什么时候用

如果你的场景符合下面这些特征，就更适合本地模式：

- 你希望先跑通一个简单直接的本地开发流程
- 输入文件已经都在本地磁盘上
- 当前不需要云端专属的 `--embed-fonts` 参数
- 你更偏好本地文件访问和本地产物输出

## 典型路径

```bash
deckhtml index.html -o deck.pptx --mode local
```

在很多场景下，本地模式也是最容易预测、最适合作为第一步验证的起点。

## 最佳实践

- 保证输入文件和引用资源都能在本地访问
- 在脚本和 CI 里优先使用 JSON 输出
- 需要排查问题时，再附加报告输出

```bash
deckhtml index.html -o deck.pptx --mode local --report --json
```
