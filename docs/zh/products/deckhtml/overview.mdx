# DeckHTML

DeckHTML 基于 HTML 生成 PPTX，是 Deckflow 产品体系中以 HTML 作为幻灯片结构和视觉设计源的创作产品。

## 产品边界

DeckHTML 从 HTML 生成 PPTX。处理已有文档时，嗅探使用 [DeckProbe](/zh/products/deckprobe/overview)，渲染使用 [DeckRender](/zh/products/deckrender/overview)，单向文档操作使用 [DeckOps](/zh/products/deckops/overview)，编辑源文件使用 [DeckUse](/zh/products/deckuse/overview)。
