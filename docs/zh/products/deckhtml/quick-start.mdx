这是从一个 HTML 文件到生成演示文稿产物的最短路径。

<Note>
  这个页面刻意以 CLI 为起点。只要你先跑通一次本地转换，后续就可以把同样的输入迁移到 SDK 或 MCP 使用。
</Note>

## 五步开始

<Steps>
  <Step title="准备一个 HTML 幻灯片页面">
    创建一个 HTML 文件，例如 `index.html`。DeckHTML 最适合处理“一个页面对应一页幻灯片”或“一个文件内包含清晰多页结构”的输入。

    ```html
    <!doctype html>
    <html>
      <head>
        <meta charset="utf-8" />
        <title>Hello DeckHTML</title>
      </head>
      <body>
        <section>
          <h1>Hello DeckHTML</h1>
          <p>Convert this page into presentation output.</p>
        </section>
      </body>
    </html>
    ```
  </Step>
  <Step title="无需全局安装，直接运行">
    直接通过 `npx` 使用最新版本：

    ```bash
    npx -y @deckflow/deckhtml@latest index.html -o deck.pptx
    ```
  </Step>
  <Step title="或者安装一次后重复使用">
    如果你希望保留本地命令：

    ```bash
    npm install -g @deckflow/deckhtml
    deckhtml index.html -o deck.pptx
    ```
  </Step>
  <Step title="检查生成结果">
    本地转换成功后，会输出目标 PPTX，并打印输出路径或 JSON 结果。

    ```bash
    deckhtml index.html -o deck.pptx
    deckhtml index.html -o deck.pptx --json
    ```
  </Step>
  <Step title="根据场景选择执行模式">
    如果希望在当前机器上直接转换，使用 [CLI 概览](/zh/products/deckhtml/cli/overview) 里的本地路径；如果需要托管执行、认证能力或接入智能体工作流，可以继续看 [MCP 概览](/zh/platform/mcp/overview) 和 [API 概览](/zh/platform/api/overview)。
  </Step>
</Steps>
