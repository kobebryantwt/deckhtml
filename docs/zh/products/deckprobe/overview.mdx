# DeckProbe

DeckProbe 是 Deckflow 产品体系中的发现与嗅探层。它无需先构建完整的页面和元素模型，也无需渲染文件，就能回答针对文档的目标问题。

调用方只需指定所需事实，例如已验证格式、幻灯片数量、工作表名称、加密状态或资源数量；DeckProbe 会在置信度和预算约束下，选择能够满足目标的最低成本有效探测路径。

## DeckProbe 回答什么

- **文件身份**：已验证格式、MIME 类型、扩展名匹配、文件大小、作者、声明时间和生成应用。
- **主要结构**：由格式驱动实现的数量、名称、尺寸，以及幻灯片、工作表、页面、母版或版式等事实。
- **安全与质量**：在格式支持范围内探测加密、密码保护、宏、签名、外部关系、嵌入文件、活动内容风险和结构质量。
- **资源摘要**：在格式支持范围内统计图片、媒体、预览图、字体、评论、附件和嵌入对象。

## DeckProbe 不负责什么

DeckProbe 不会返回用于复现文档的完整文本块、形状、表格单元格、样式、坐标和关系。这类深度解析属于 [DeckOps](/zh/products/deckops/overview)。

DeckProbe 也不生成视觉预览或修改源文件。渲染使用 [DeckRender](/zh/products/deckrender/overview)，源文件感知编辑使用 [DeckUse](/zh/products/deckuse/overview)。

<Info>
  DeckProbe 可通过原生 Rust CLI 在本地运行，也可通过 JavaScript SDK 在浏览器内运行。实际实现、实时 Target 注册表和完整参考文档位于 [deckflow/deckprobe](https://github.com/deckflow/deckprobe)。
</Info>
