## 产品接入面

- CLI：从 HTML 输入到产物输出的最快路径
- SDK：面向服务端或内部工具的程序化封装
- MCP：面向智能体环境的工具化接入

## 转换流水线模型

从高层看，DeckHTML 的工作流通常都遵循类似的阶段：

1. 从文件、`stdin` 或 URL 读取输入
2. 归一化处理输出格式、执行模式等选项
3. 在本地或云端执行转换流程
4. 写出最终产物，以及可选的报告文件
5. 返回适合人读或机器处理的结果

## 文档结构

当前帮助中心主要分成三层：

- 面向首次接入的开始使用指南
- 面向不同产品接入面的专题说明，例如 CLI、SDK、MCP
- 面向接口契约、参数和返回结构的参考文档
