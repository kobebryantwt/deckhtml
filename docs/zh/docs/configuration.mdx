## 凭证

云端模式的凭证常见有两种提供方式：

- 通过 `deckhtml config set api-key <key>` 写入本地
- 通过 `DECKHTML_API_KEY` 在运行时传入

在 CI 和其他非交互环境里，通常更推荐环境变量方式。

## 输出行为

常见输出相关设置一般通过命令参数传入：

- `-o` 或 `--output`：指定输出路径
- `--json`：输出机器可读 JSON
- `--report`：额外生成转换报告

当前已发布 CLI 会通过 `-o` 的扩展名推断输出类型：

- 使用 `.pptx` 生成 PowerPoint 演示文稿
- 使用 `.png` 生成 PNG 帧输出

## 模式选择

如果你希望执行行为更可预测，可以显式指定模式：

```bash
deckhtml index.html --mode local
deckhtml index.html --mode cloud
```
