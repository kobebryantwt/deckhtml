## DeckHTML 支持哪些输入？

当前文档主要覆盖三类输入：

- 本地 HTML 文件
- 标准输入 `stdin`
- 托管 URL

## 可以生成哪些输出？

DeckHTML 当前主要围绕 `pptx`、`pdf` 和 `png` 三类输出组织能力。

## 什么时候需要认证？

只有在云端执行，以及使用云端专属增强参数时，才需要认证。

## 可以在 CI 里自动化使用吗？

可以。建议优先使用 `--json` 获取结构化结果，通过环境变量传递凭证，并在需要排障时附加 `--report`。

## 我应该用 CLI、SDK 还是 MCP？

- 直接在终端操作时，用 CLI
- 集成到应用代码里时，用 SDK
- 暴露给智能体或编辑器工具时，用 MCP
