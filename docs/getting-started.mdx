Choose the first result your application needs. Each section provides installation, a concrete invocation, and the signal that proves the example succeeded.

<Note>
  All DeckFlow JavaScript packages and CLIs below are installed from npm. If the default registry is unavailable in your region, add `--registry=https://registry.npmmirror.com` to that install command. Keep this override per command so other projects and registries are not changed globally; mirrors can occasionally lag the official npm release.
</Note>

## DeckProbe: inspect a known PDF

<span className="product-kicker">Local · no credentials · factual JSON</span>

```bash
npm install -g @deckflow/deckprobe
deckprobe --version

curl -fL https://mozilla.github.io/pdf.js/web/compressed.tracemonkey-pldi-09.pdf -o sample.pdf
deckprobe -t format,page_count --view values --pretty sample.pdf
```

The npm package's CLI uses the platform-specific native binary. Success means exit code `0`, `schema_version: 2`, driver `pdf`, and resolved values for `document.format` and `pdf.page_count`:

```json
{
  "schema_version": 2,
  "status": "ok",
  "driver": { "id": "pdf", "profile": "pdf" },
  "values": {
    "document.format": "pdf",
    "pdf.page_count": 14
  }
}
```

See the [DeckProbe Quickstart](/deckprobe/quick-start) for a complete response and additional inputs.

## DeckRender: create a PNG

<span className="product-kicker">Local or cloud · visual artifact · structured result</span>

```bash
npm install -g @deckflow/deckrender
deckrender hello.html --engine local -o hello.png --json --quiet
test -s hello.png
```

The command uses an installed Chrome/Chromium/Edge browser, keeps the HTML on the machine, writes `hello.png`, and returns a `RenderResult` containing `engine`, route, page count, output path, bytes, and duration. Create the input, check local prerequisites, and try the guest cloud path in the [DeckRender Quickstart](/deckrender/quick-start).

## DeckOps: parse once, derive Markdown

<span className="product-kicker">Local by default · durable DeckIR · reusable views</span>

```bash
npm install -g @deckflow/deckops
deckops --version

curl -fL https://docs.deckflow.com/images/deckuse-sample.pptx -o sample.pptx
deckops parse sample.pptx --json
deckops convert sample/ --json
test -s sample/views/markdown/index.md
```

The first command creates `sample/` with `ir.json`, `manifest.json`, an optional `probe.json`, and extracted assets. The second reads that IR rather than parsing the PPTX again; a successful result reports `"reusedParse": true` and writes the Markdown view.

DeckOps keeps PDF, PPTX, DOCX, and static web source local by default. Continue with the [DeckOps Quickstart](/deckops/quick-start) for a complete verified workflow and explicit cloud-engine selection.

## DeckUse: update an existing PPTX

<span className="product-kicker">Local · existing PPTX · editable output</span>

```bash
npm install -g @deckflow/deckuse
deckuse --version
curl -fL https://docs.deckflow.com/images/deckuse-sample.pptx -o input.pptx
deckuse init input.pptx ./workspace --json
printf '%s\n' '{"type":"replaceText","find":"Presentation Title Text","replace":"DeckUse Updated Title","selector":"kind=textbox","limit":1}' \
  | deckuse apply ./workspace --json
deckuse validate ./workspace --json
deckuse commit ./workspace -o updated.pptx --json
```

DeckUse works locally through a versioned workspace. Its CLI can inspect and query PPTX structure, update text, properties and geometry, add/duplicate/remove supported slides and elements, work with pictures, tables and chart caches, then export another PPTX. Follow the [DeckUse Quickstart](/deckuse/quick-start) for prerequisites, expected query output, and final verification.

## DeckHTML: generate a PPTX locally

<span className="product-kicker">Local Chromium · HTML source · PPTX output</span>

```bash
npm install -g @deckflow/deckhtml
deckhtml deck.html -o deck.pptx --mode local --json --quiet
test -s deck.pptx
```

The command uses local Chromium and returns normalized paths, output format, execution mode, and slide count. Prepare the browser and a slide-sized HTML source in the [DeckHTML Quickstart](/deckhtml/quick-start).
