Each product solves a different document task. Start with the result you need, then follow the linked quickstart for prerequisites, a known input, expected output, and failure guidance.

| Product | First result | Runs | Credentials |
| --- | --- | --- | --- |
| DeckProbe | Schema v2 facts about a document | Local | None |
| DeckRender | PNG, PDF, or supported video render | Mostly cloud | Guest or authenticated |
| DeckOps | Markdown, structured parse data, or converted artifact | Cloud | API key/token recommended |
| DeckUse | Updated PPTX | Local | None |
| DeckHTML | PPTX or PNG from HTML | Local or cloud | None locally |

## DeckProbe: inspect a known PDF

```bash
curl -L https://www.w3.org/WAI/ER/tests/xhtml/testfiles/resources/pdf/dummy.pdf -o sample.pdf
deckprobe -t format,page_count --view values --pretty sample.pdf
```

Success means exit code `0`, `schema_version: 2`, driver `pdf`, and resolved values for `document.format` and `pdf.page_count`. Install the native CLI and see the exact response in the [DeckProbe Quickstart](/deckprobe/quick-start).

## DeckRender: create a PNG

```bash
npm install -g @deckflow/deckrender
deckrender hello.html -o hello.png --json
test -s hello.png
```

The command uploads the HTML to Deckflow cloud, writes `hello.png`, and returns a `RenderResult` containing `ok`, route, page count, output path, bytes, and duration. Create the HTML input and review guest limits in the [DeckRender Quickstart](/deckrender/quick-start).

## DeckOps: run a cloud task

```bash
npm install @deckops/sdk
node run.mjs
```

The script in the [DeckOps Quickstart](/deckops/quick-start) creates a known HTML file, uploads it, starts a guest `convertor.html2png` task, and prints the completed task and PNG download metadata. The current npm artifact does not yet expose the repository's newer Parse facade.

## DeckUse: update an existing PPTX

```bash
npm install -g deckuse
deckuse replace input.pptx '2025' '2026' -o updated.pptx
deckuse get text updated.pptx "text[contains('2026')]"
```

DeckUse works locally and currently supports modifying existing PPTX content. It does not add or delete elements and does not support other Office formats. Follow the [DeckUse Quickstart](/deckuse/quick-start) to inspect selectors and verify the output.

## DeckHTML: generate a PPTX locally

```bash
npm install -g @deckflow/deckhtml
deckhtml deck.html -o deck.pptx --mode local --json --quiet
test -s deck.pptx
```

The command uses local Chromium and returns normalized paths, output format, execution mode, and slide count. Prepare the browser and a slide-sized HTML source in the [DeckHTML Quickstart](/deckhtml/quick-start).
