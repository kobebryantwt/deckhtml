## DeckProbe

Inspect a document locally and receive a Schema v2 JSON report.

### Install

<Tabs>
  <Tab title="macOS and Linux">
    ```bash
    curl --proto '=https' --tlsv1.2 -LsSf \
      https://github.com/deckflow/deckprobe/releases/latest/download/deckprobe-installer.sh | sh
    ```
  </Tab>
  <Tab title="Windows">
    ```powershell
    powershell -ExecutionPolicy ByPass -c "irm https://github.com/deckflow/deckprobe/releases/latest/download/deckprobe-installer.ps1 | iex"
    ```
  </Tab>
</Tabs>

### Use

```bash
deckprobe --pretty -t format,slide_count deck.pptx
```

### Result

```json
{
  "schema_version": 2,
  "tool_version": "2.2.0",
  "status": "ok",
  "input": {
    "display_name": "deck.pptx",
    "source_kind": "local_file",
    "file_size": 245760
  },
  "driver": {
    "id": "powerpoint",
    "profile": "pptx"
  },
  "results": {
    "powerpoint.slide_count": {
      "target": "powerpoint.slide_count",
      "status": "resolved",
      "value": 31,
      "confidence": "exact",
      "confidence_score": 1,
      "path": "powerpoint.presentation_xml",
      "source": "ppt/presentation.xml"
    }
  },
  "execution": {
    "probe_level": "metadata",
    "paths": ["powerpoint.presentation_xml"],
    "estimated_cost": 12,
    "actual_cost": {
      "physical_bytes_read": 4096,

```

Values and costs in this example are illustrative; the field names follow the Schema v2 contract. Continue with the [DeckProbe Quickstart](/deckprobe/quick-start) or [Output Model](/deckprobe/output-model).

## DeckHTML

Generate a PPTX file from an HTML source file.

### Prepare

Save the following as `index.html`:

```html
<!doctype html>
<html>
  <body>
    <section>
      <h1>Hello DeckHTML</h1>
      <p>My first generated slide.</p>
    </section>
  </body>
</html>
```

### Use

Run the package directly without a global installation:

```bash
npx -y @deckflow/deckhtml@latest index.html -o deck.pptx
```

### Result

The command writes `deck.pptx`. Add `--json` when the calling process needs structured command output:

```bash
npx -y @deckflow/deckhtml@latest index.html -o deck.pptx --json
```

Continue with the [DeckHTML Quickstart](/deckhtml/quick-start), [CLI](/deckhtml/cli/overview), or [Node.js SDK](/deckhtml/sdk/node).
