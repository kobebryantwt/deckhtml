Deckflow is organized by document task. Start from the result your application needs, then use the product-specific guide for installation, configuration, and integration details.

## Choose your first result

| Use case | Product | First step |
| --- | --- | --- |
| Inspect format, metadata, structure, security, or asset facts | DeckProbe | [Run your first probe](/deckprobe/quick-start) |
| Produce page images, thumbnails, or slide previews | DeckRender | [Understand DeckRender](/deckrender/overview) |
| Parse into Document IR, extract semantic structure, or convert formats | DeckOps | [Understand DeckOps](/deckops/overview) |
| Modify elements in a supported Office source file | DeckUse | [Understand DeckUse](/deckuse/overview) |
| Generate presentation artifacts from HTML | DeckHTML | [Run your first generation](/deckhtml/quick-start) |

If more than one product appears to fit, compare their boundaries in [Choose a product](/product-guide).

## Follow the product guide

Each product area is organized around the following documentation pattern:
