This path keeps the source on your machine. You need Node.js 18 or later and a compatible Chromium, Chrome, or Edge executable.

<Steps>
  <Step title="Install and verify HTML2Deck">
    ```bash
    npm install -g @deckflow/html2deck
    html2deck --version
    ```
  </Step>
  <Step title="Make a browser available">
    HTML2Deck first checks `HTML2DECK_CHROMIUM_EXECUTABLE_PATH`, then a Playwright-managed browser, then supported system Chrome or Edge installations. If none is available, install Chromium with Playwright:

    ```bash
    npx -y playwright install chromium
    ```

    In a container or custom image, point HTML2Deck to the exact executable:

    ```bash
    export HTML2DECK_CHROMIUM_EXECUTABLE_PATH=/path/to/chromium
    ```
  </Step>
  <Step title="Create a slide">
    Save this as `deck.html`:

    ```html
    <!doctype html>
    <html>
      <head>
        <meta charset="utf-8" />
        <meta name="deck-size" content="1280x720" />
        <style>
          * { box-sizing: border-box; }
          body { margin: 0; font-family: Arial, sans-serif; }
          .slide-container { width: 1280px; height: 720px; padding: 72px; background: #f7fafc; }
        </style>
      </head>
      <body>
        <section class="slide-container" data-slide-id="intro">
          <h1 data-element-id="title">Hello HTML2Deck</h1>
          <p data-element-id="summary">HTML layout, presentation output.</p>
        </section>
      </body>
    </html>
    ```
  </Step>
  <Step title="Convert and verify">
    ```bash
    html2deck deck.html -o deck.pptx --mode local --json --quiet
    test -s deck.pptx && echo "deck.pptx created"
    ```

    In PowerShell:

    ```powershell
    if (!(Test-Path deck.pptx) -or (Get-Item deck.pptx).Length -eq 0) {
      exit 1
    }
    ```

    `--quiet` keeps stdout machine-readable. The JSON result contains normalized absolute paths, so the exact values depend on your working directory:

    ```json
    {
      "ok": true,
      "input": ["/absolute/path/deck.html"],
      "output": "/absolute/path/deck.pptx",
      "format": "pptx",
      "mode": "local",
      "slideCount": 1
    }
    ```
  </Step>
  <Step title="Inspect conversion decisions">
    ```bash
    html2deck deck.html -o deck.pptx --mode local --report --force
    ```

    Review `deck.pptx.report.json` for native, vector, raster, ignored, and unsupported elements.
  </Step>
</Steps>
