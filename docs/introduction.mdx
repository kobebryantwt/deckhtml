DeckProbe and DeckUse execute locally. DeckRender uses local, passthrough, and DeckFlow cloud routes. DeckOps executes document tasks in the cloud. DeckHTML supports local browser-based conversion and a cloud mode.

## Compare the execution boundary

| Goal | Product | Primary interface | Authentication |
| --- | --- | --- | --- |
| Verify format, counts, metadata, structure, or risk signals | [DeckProbe](/deckprobe/overview) | CLI and JavaScript SDK | Not required; processing stays local |
| Produce page images, PDF, thumbnails, or video | [DeckRender](/deckrender/overview) | CLI and Node.js SDK | Optional for cloud routes; guest mode is available |
| Parse, extract, convert, generate, or orchestrate cloud tasks | [DeckOps](/deckops/overview) | CLI and SDK | Credentials for high-level Parse; limited guest low-level tasks |
| Inspect and apply structured changes to an existing PPTX | [DeckUse](/deckuse/overview) | CLI and Node.js SDK | Not required; processing stays local |
| Generate PPTX or PNG from HTML or SVG | [DeckHTML](/deckhtml/overview) | CLI and Node.js SDK | Not required locally; guest or authenticated cloud mode |

<Note>
  Supported formats and operations differ by product. A file being recognized by one product does not mean every other product can process it. Check the relevant supported-format or command reference before choosing a path.
</Note>
