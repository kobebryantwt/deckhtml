Deckflow provides focused components for different stages of a document workflow. Start with the outcome you need, then open the corresponding product documentation.

<CardGroup cols={2}>
  <Card title="DeckProbe" href="/deckprobe/overview">
    Inspect PDF, Microsoft Office, and modern Apple iWork documents locally or in the browser.
  </Card>
  <Card title="DeckRender" href="/deckrender/overview">
    Render supported document formats into page or slide visuals.
  </Card>
  <Card title="DeckOps" href="/deckops/overview">
    Parse formats into one Document IR, then Extract, Convert, or Render.
  </Card>
  <Card title="DeckUse" href="/deckuse/overview">
    Manipulate supported Office source files while keeping them editable.
  </Card>
  <Card title="DeckHTML" href="/deckhtml/overview">
    Build presentation artifacts with an HTML-native deck engine.
  </Card>
</CardGroup>

## Choose by task

| Use case | Start with |
| --- | --- |
| Identify a document and inspect metadata, structure, security, or asset facts | [DeckProbe](/deckprobe/overview) |
| Produce thumbnails, page images, or slide previews | [DeckRender](/deckrender/overview) |
| Parse a document into a unified IR or perform semantic extraction and conversion | [DeckOps](/deckops/overview) |
| Modify or delete elements in a supported Office source file | [DeckUse](/deckuse/overview) |
| Generate a deck from HTML | [DeckHTML](/deckhtml/overview) |

Ready to build? Follow [Getting started](/getting-started). For a detailed comparison, continue with [Choose a product](/product-guide); for the vocabulary used across the product family, see [Document operations](/document-operations).
