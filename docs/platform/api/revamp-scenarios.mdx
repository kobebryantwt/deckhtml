Revamp jobs still use the unified async task API. The difference is that the `type` field must be fixed to `revamp`, and `params` must contain the revamp-specific design guidance fields shown below.

## Core mapping

| Field | Value |
|---|---|
| Endpoint | `POST /tools/tasks` |
| `type` | `revamp` |
| Files | PPTX presentation files |
| Query endpoint | `GET /tools/tasks/{id}` |

## Form-data fields

| Field | Type | Required | Meaning |
|---|---|---|---|
| `spaceId` | `String` | No | Target workspace Space ID. |
| `files` | `File` | Yes | PPTX files to restyle. Multiple files are supported. |
| `type` | `String` | Yes | Fixed value: `revamp`. |
| `name` | `String` | No | Human-readable task name, such as `"AI revamp task"`. |
| `params` | `String (JSON)` | Yes | JSON string containing the revamp parameters below. |

## `params` fields

| Field | Type | Required | Meaning |
|---|---|---|---|
| `inputText` | `String` | No | Layout style guidance, color rules, branding DNA, or other design-refresh instructions. |
| `advancedModel` | `Boolean` | No | Whether to use the advanced design reasoning model. Default: `false`. |
| `fastMode` | `Boolean` | No | Whether to prioritize faster output. Default: `false`. |
| `notifyURL` | `String` | No | Webhook callback URL for task status changes. |

## Example `params`

```json
{
  "inputText": "Refresh the deck with a blue-green palette and cleaner modern layouts.",
  "advancedModel": false,
  "fastMode": false,
  "notifyURL": "https://your.domain/callback"
}
```
