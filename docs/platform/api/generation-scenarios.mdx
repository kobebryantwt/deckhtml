Generation jobs still use the unified `POST /tools/tasks` endpoint. The only difference is that the `type` field must be fixed to `generation`, and `params` must contain the generation-specific fields shown below.

## Core mapping

| Field | Value |
|---|---|
| Endpoint | `POST /tools/tasks` |
| `type` | `generation` |
| Files | The current task endpoint requires uploaded `files` or existing `fileIds` |
| Query endpoint | `GET /tools/tasks/{id}` |

## Form-data fields

| Field | Type | Required | Meaning |
|---|---|---|---|
| `spaceId` | `String` | No | Target workspace Space ID. |
| `files` | `File` | One of `files` or `fileIds` | Reference files such as PDF, Word, or Markdown. Repeat the field for multiple files. |
| `fileIds` | `String[]` | One of `files` or `fileIds` | IDs of reference files already stored in DeckFlow. |
| `type` | `String` | Yes | Fixed value: `generation`. |
| `name` | `String` | No | Human-readable task name, such as `"AI generation task"`. |
| `params` | `String (JSON)` | Yes | JSON string containing the generation parameters below. |

## `params` fields

| Field | Type | Required | Meaning |
|---|---|---|---|
| `inputText` | `String` | No | Topic description, URL, or raw source text used to build the slide structure. |
| `enableSearch` | `Boolean` | No | Whether to enable web search to enrich the generated content. Default: `false`. |
| `advancedModel` | `Boolean` | No | Whether to use a deeper reasoning model for better layout logic and creativity. Default: `false`. |
| `fastMode` | `Boolean` | No | Whether to prioritize speed over maximum detail optimization. Default: `false`. |
| `intent` | `String` | No | Custom goal, task intent, or instruction. |
| `audience` | `String` | No | Target audience characteristics that guide layout and copy tone. |
| `pageCount` | `Integer` | No | Desired slide count. |
| `author` | `String` | No | Author metadata written into the generated PPTX file. |
| `notifyURL` | `String` | No | Webhook callback URL for task status changes. |

## Example `params`

```json
{
  "inputText": "Create a renewable energy trend deck with emphasis on solar and wind market share.",
  "enableSearch": true,
  "advancedModel": false,
  "fastMode": false,
  "intent": "Board presentation",
  "audience": "Executive leadership team",
  "pageCount": 10,
  "author": "DeckFlow API"
}
```
