Call this endpoint after the task detail reports `status: "completed"` and `allowGetResult: true`.

Despite the `/download` path, the verified response is JSON metadata rather than the file bytes. Your application reads the result URL from the response, then downloads that URL separately.

## Verified html2pptx response

```json
{
  "target": [
    "https://files.example.com/result.pptx",
    10870,
    "dd206bad03fce37c3c753b57ecf32c26"
  ],
  "usedFonts": ["Times New Roman"]
}
```

For the verified `convertor.html2pptx` route:

| Value | Meaning |
| --- | --- |
| `target[0]` | Result file URL |
| `target[1]` | Result byte length |
| `target[2]` | Digest string returned by the service |
| `usedFonts` | Fonts observed during conversion |

Result metadata can differ by task type. Check for the fields required by the selected route instead of assuming every task returns `usedFonts`.

## Download the returned URL

```bash
RESULT_URL=$(curl -sS \
  'https://app.deckflow.com/api/tools/tasks/TASK_ID/download' \
  --header "Authorization: Bearer $DECKFLOW_API_KEY" \
  | jq -r '.target[0]')

curl -fL "$RESULT_URL" -o result.pptx
test -s result.pptx
```

Do not log the result URL. Its lifetime is not guaranteed, so verify the task owner and expected output type, then download it promptly.

## Verified response statuses

| Status | When it occurs | Response signal |
| ---: | --- | --- |
| `200` | Task is completed and the API key owns its Space | JSON result metadata |
| `401` | Bearer token is invalid | `code: "noAuth"` |
| `403` | API key belongs to another Space | `code: "notAllowed"` and a Space access message |
| `403` | Task is pending, running, or failed | `code: "notAllowed"` and `Task is not completed` |
| `404` | Task ID does not exist | `code: "notFound"` |
| `500` | Authorization header is omitted | `code: "unexpectedError"` and `Profile uuid is required` |

<Note>
  A running task and a failed zero-credit task both return `403` with `Task is not completed`; non-completed tasks do not currently return `409`.
</Note>
