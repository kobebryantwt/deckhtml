Use this page to add DeckFlow MCP in WorkBuddy. The normal path is to create a custom connector, paste the hosted MCP config, confirm trust for each server, and then verify that WorkBuddy can see the DeckFlow tools.

<Note>
  Hosted HTTP is the recommended WorkBuddy setup path. Add one MCP server per endpoint, trust each server the first time it appears, then verify the tool lists directly in the MCP manager.
</Note>

## Open the WorkBuddy MCP configuration entry

<Steps>
  <Step title="Open the Connectors area">
    In WorkBuddy, open the `Connectors` area from the top navigation. Then click `Custom Connector` to create a new MCP entry.
  </Step>
  <Step title="Open the MCP config editor">
    In the MCP manager, click `Configure MCP`. WorkBuddy opens the config file editor where you can paste the DeckFlow MCP definitions and save them.
  </Step>
</Steps>

![WorkBuddy MCP config entry](/images/mcp/workbuddy-mcp-entry.png)

## Add the DeckFlow MCP config

Paste this config into WorkBuddy's MCP config editor:

```json
{
  "mcpServers": {
    "deckflow-html2pptx": {
      "url": "https://mcp.deckflow.com/v1/html2pptx"
    },
    "deckflow-pptx": {
      "url": "https://mcp.deckflow.com/v1/pptx"
    },
    "deckflow-tools": {
      "url": "https://mcp.deckflow.com/v1/tools"
    }
  }
}
```

Save the file after the new server entries are added.

## Trust and enable the servers

<Steps>
  <Step title="Return to the MCP manager">
    After the config is saved, WorkBuddy lists the new DeckFlow servers under `My MCP`.
  </Step>
  <Step title="Trust each server">
    On first connection, WorkBuddy asks for trust confirmation for each DeckFlow server. Click `Trust` for `deckflow-html2pptx`, `deckflow-pptx`, and `deckflow-tools`.
  </Step>
  <Step title="Confirm that all three servers are enabled">
    After trust is granted, WorkBuddy enables the three MCP servers and shows their tool counts in the manager.
  </Step>
</Steps>

![WorkBuddy verification required state](/images/mcp/workbuddy-mcp-verify.png)

## Verify the DeckFlow tools

After the servers are trusted and enabled, WorkBuddy expands each DeckFlow entry and shows the available MCP tools directly in the MCP manager.

![WorkBuddy DeckFlow tools list](/images/mcp/workbuddy-mcp-tools.png)

## What to try after setup

- Convert an HTML slide page into an editable PPTX deck.
- Render HTML or Markdown into preview images.
- Split, merge, inspect, or embed fonts in PPTX files.
- Convert files, run OCR, resize images, or compress large outputs.

## Example prompts

```text
Use deckflow-html2pptx to convert this HTML page into an editable PPTX deck.
```

```text
Use deckflow-pptx to inspect this presentation and list the fonts it uses.
```

```text
Use deckflow-tools to run OCR on this image and return the extracted text.
```

## Validation checklist

- WorkBuddy recognizes the DeckFlow servers you added as available MCP servers.
- The first-connection trust prompt no longer blocks the three server entries.
- Tool discovery shows 6 tools under each DeckFlow server entry.
- Each group contains 4 capability tools plus the shared `get_task` and `download_task_result` support tools.
