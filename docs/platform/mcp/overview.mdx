DeckFlow MCP currently provides three hosted MCP servers. You can register only the server that matches your workflow, or add all three when you want the full DeckFlow toolset inside an MCP-compatible client.

<Note>
  If your main job is turning HTML into PPTX or preview images, use the `html2pptx` server. If you also need PPTX post-processing or general file utilities, register the `pptx` and `tools` servers as well.
</Note>

## Available DeckFlow MCP servers

| Endpoint | Scope | Tools |
| --- | --- | --- |
| `https://mcp.deckflow.com/v1/html2pptx` | HTML-to-PPTX pipeline | `html_to_pptx`, `html_to_image`, `markdown_to_image`, `build_html_player` |
| `https://mcp.deckflow.com/v1/pptx` | PPTX file utilities | `split_pptx`, `merge_pptx`, `embed_pptx_fonts`, `inspect_pptx` |
| `https://mcp.deckflow.com/v1/tools` | General file tools | `convert_file`, `ocr_image`, `transform_image`, `compress_file` |

## Add DeckFlow to Your Agent

<Steps>
  <Step title="Open your agent's MCP settings">
    In your agent, open the MCP, connectors, or tools settings area and choose the option for adding a custom server.
  </Step>
  <Step title="Choose the server or servers you need">
    Decide whether you need the `html2pptx`, `pptx`, or `tools` server, based on the capabilities you want to expose in your client.
  </Step>
  <Step title="Add each hosted endpoint as its own MCP server">
    Register one custom MCP server per endpoint. Recommended names are `deckflow-html2pptx`, `deckflow-pptx`, and `deckflow-tools`.
  </Step>
  <Step title="Authenticate if your client requires it">
    Some clients open a browser-based authorization flow after the server is added. Others let you store the connection and then complete auth from the MCP manager.
  </Step>
  <Step title="Verify the servers and start using tools">
    After setup, confirm the DeckFlow servers are connected, then try a small task such as converting HTML to PPTX or splitting a PPTX file.
  </Step>
</Steps>

<Tip>
  Menu names vary by client. Use the product guides below for the exact setup path supported by each agent.
</Tip>

## Supported Products

DeckFlow MCP currently has setup guides for:

- [Codex](/platform/mcp/codex): add one or more DeckFlow servers from Codex settings or by editing `~/.codex/config.toml`.
- [Cursor](/platform/mcp/cursor): add one or more DeckFlow servers from Cursor MCP settings or by editing Cursor's MCP config file.
- [Claude Code](/platform/mcp/claude-code): add one or more DeckFlow servers with `claude mcp add`, or by editing `~/.claude.json` / `.mcp.json`.
- [TRAE](/platform/mcp/trae): add the hosted DeckFlow server configs from the MCP settings panel and complete browser authorization.
- [WorkBuddy](/platform/mcp/workbuddy): paste the hosted DeckFlow server configs into the Connectors UI and confirm the tool lists.

If your client supports custom MCP servers, these hosted endpoints usually work there as well.

## What You Can Do

Once connected, your agent can use DeckFlow for:

- [Turn HTML into editable PPTX or preview images](/platform/mcp/tools#html-to-pptx-pipeline): use the `html2pptx` server for HTML rendering and publishing workflows.
- [Process PPTX files after generation](/platform/mcp/tools#pptx-file-utilities): split, merge, inspect, and embed fonts through the `pptx` server.
- [Run general file utilities](/platform/mcp/tools#general-file-tools): convert files, run OCR, resize images, and compress outputs through the `tools` server.

## Authentication and Transport

DeckFlow MCP documentation now focuses on these hosted endpoints:

```text
https://mcp.deckflow.com/v1/html2pptx
https://mcp.deckflow.com/v1/pptx
https://mcp.deckflow.com/v1/tools
```

Depending on the client, DeckFlow MCP can be connected in one of three ways:

- <strong>Client UI</strong>: add a custom MCP server from a settings screen and finish browser-based auth if prompted.
- <strong>Config file</strong>: write the server entry directly into a local MCP config file such as `config.toml`, `mcp.json`, or `.mcp.json`.
- <strong>CLI command</strong>: register the server with a helper command such as `claude mcp add`.

Use one MCP server entry per endpoint. If you want the full DeckFlow setup, register all three.
