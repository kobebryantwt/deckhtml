# Python SDK

Use the Python SDK when your integration layer is Python-based.

## Typical use cases

- Automation jobs in Python
- Notebook or scripting workflows
- Service wrappers in Python backends

## Expected shape

A typical Python integration should:

1. Import DeckHTML client helpers
2. Provide input and output options
3. Execute a conversion request
4. Read the returned result and artifact locations
