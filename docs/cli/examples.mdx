> Browse ready-to-run CLI examples based on the currently published `@deckflow/deckhtml` package.

## Run without installing

```bash
npx -y @deckflow/deckhtml@latest index.html -o deck.pptx
```

## Convert a single file

```bash
deckhtml index.html
deckhtml index.html -o deck.pptx
```

## Convert stdin

```bash
cat index.html | deckhtml - -o deck.pptx
```

## Convert multiple ordered files

```bash
deckhtml title.html agenda.html content.html summary.html -o deck.pptx
```

## Convert a URL

```bash
deckhtml https://example.com/deck.html -o deck.pptx
deckhtml https://example.com/deck.html -o deck.pptx --render-wait 9
```

## Generate cloud outputs

```bash
deckhtml index.html --mode cloud --format png -o frames
```

In the published `0.1.0` package, `pdf` is not yet completed even though it appears in the CLI surface.

## Set viewport width or platform mapping

```bash
deckhtml index.html --width 1440 -o deck.pptx
deckhtml index.html --platform win -o deck.pptx
```

## Use local, auto, or cloud mode

```bash
deckhtml index.html --mode local -o deck.pptx
deckhtml index.html --mode auto -o deck.pptx
deckhtml index.html --mode cloud -o deck.pptx
```

## Use cloud-only enhancements

```bash
deckhtml index.html \
  -o deck.pptx \
  --mode cloud \
  --rebuild-svg \
  --rebuild-chart \
  --embed-fonts \
  --map-motion
```

## Generate a report

```bash
deckhtml index.html -o deck.pptx --report
```

## Return machine-readable JSON

```bash
deckhtml index.html -o deck.pptx --json
```

```json
{
  "ok": true,
  "input": ["index.html"],
  "output": "deck.pptx",
  "format": "pptx",
  "mode": "local"
}
```

## Authentication and config

```bash
deckhtml auth login
deckhtml auth status
deckhtml config set api-key <key>
deckhtml config show
```

For CI, Docker, and agent environments:

```bash
export DECKHTML_API_KEY=your-api-key
deckhtml index.html --mode cloud -o deck.pptx
```
