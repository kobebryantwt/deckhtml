> Convert HTML files, stdin, or URLs into PPTX, PDF, or PNG artifacts from your terminal.

The published `@deckflow/deckhtml` package gives you a command-line interface for HTML-to-presentation conversion. It accepts local files, multiple ordered HTML files, stdin, and hosted URLs. It supports local and cloud execution, human-readable output by default, and machine-readable JSON output for scripts and CI.

<Note>
  Use the CLI when you want the fastest path from HTML input to a generated artifact. It is the best starting point for local testing, shell automation, and CI pipelines.
</Note>

## Quick Start

Run without installing:

```bash
npx -y @deckflow/deckhtml@latest index.html -o deck.pptx
```

Install globally:

```bash
npm install -g @deckflow/deckhtml
deckhtml --version
```

## First run

Convert a single local HTML file:

```bash
deckhtml index.html
```

By default, DeckHTML writes a PPTX next to the input file using the same base name:

```text
index.pptx
```

Write to a specific output path:

```bash
deckhtml index.html -o deck.pptx
```

Convert stdin:

```bash
cat index.html | deckhtml - -o deck.pptx
```

Convert a hosted page:

```bash
deckhtml https://example.com/deck.html -o deck.pptx
```

## Authentication

Authentication is only required for cloud execution and cloud-only enhancement flags.

```bash
deckhtml auth login
deckhtml auth status
deckhtml config set api-key <key>
```

For CI, Docker, and agent environments, the environment variable takes precedence over stored credentials:

```bash
export DECKHTML_API_KEY=your-api-key
```
