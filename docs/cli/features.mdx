> Understand what the published CLI actually supports today: inputs, formats, rendering controls, cloud enhancements, and persistent config.

## Input sources

DeckHTML accepts the same core input shapes through one command surface:

```bash
deckhtml [inputs...]
```

Supported inputs:

- one local HTML file
- multiple ordered local HTML files
- stdin through `-`
- a hosted URL

Examples:

```bash
deckhtml index.html
deckhtml title.html agenda.html body.html -o deck.pptx
cat index.html | deckhtml - -o deck.pptx
deckhtml https://example.com/deck.html -o deck.pptx
```

## Output formats

The published package supports:

| Format | Description |
| --- | --- |
| `pptx` | PowerPoint deck output. Default. |
| `pdf` | PDF export. |
| `png` | PNG frame output. |

## Execution modes

| Mode | Behavior |
| --- | --- |
| `auto` | Use cloud when an API key exists; otherwise run locally. |
| `local` | Force local conversion. |
| `cloud` | Force cloud conversion and require an API key. |

Local conversion works without authentication. Cloud conversion and cloud-only enhancement flags require a configured API key.

## Cloud-only enhancements

These flags are only available in cloud mode:

| Flag | Description |
| --- | --- |
| `--rebuild-svg` | Rebuild SVG objects. |
| `--rebuild-chart` | Rebuild chart objects. |
| `--embed-fonts` | Embed fonts into the output. |
| `--map-motion` | Map animations into the output. |

## Rendering controls

The published CLI also exposes:

| Flag | What it controls |
| --- | --- |
| `--width <pixels>` | Playwright viewport width. Height scales at `16:9`. |
| `--platform <platform>` | Target platform for generic font mapping: `win`, `mac`, `ios`, `android`, `linux`. |
| `--render-wait <seconds>` | Per-page wait before capture in cloud mode. |

These are useful when the page depends on client-side rendering, platform-specific font fallback, or a controlled viewport width.

## Logging and machine-readable output

| Flag | Purpose |
| --- | --- |
| `--json` | Write machine-readable JSON to stdout. |
| `--quiet` | Reduce output to errors and final result. |
| `--verbose` | Write detailed logs to stderr. |
| `--report` | Generate a conversion report next to the output. |

`--quiet` and `--verbose` conflict.

## Authentication and config

Authentication-related commands:

```bash
deckhtml auth login
deckhtml auth status
```

Persistent config:

```bash
deckhtml config set api-key <key>
deckhtml config set size 1920x1080
deckhtml config set webhook https://example.com/webhooks/deckhtml
deckhtml config set retention-hours 3
deckhtml config show
```

For CI, Docker, and agent environments, `DECKHTML_API_KEY` takes precedence over stored credentials.
