This path uses the native CLI. It runs entirely on your machine and requires no account or API key.

<Steps>
  <Step title="Install a prebuilt release">
    <Tabs>
      <Tab title="macOS and Linux">
        ```bash
        curl --proto '=https' --tlsv1.2 -LsSf \
          https://github.com/deckflow/deckprobe/releases/latest/download/deckprobe-installer.sh | sh
        ```
      </Tab>
      <Tab title="Windows PowerShell">
        ```powershell
        powershell -ExecutionPolicy ByPass -c "irm https://github.com/deckflow/deckprobe/releases/latest/download/deckprobe-installer.ps1 | iex"
        ```

        Restart the shell if the installer changes the user `Path`.
      </Tab>
    </Tabs>
  </Step>
  <Step title="Verify the executable">
    ```bash
    deckprobe --version
    deckprobe --help
    ```

    Source installation is also available with Rust 1.88 or later:

    ```bash
    cargo install --git https://github.com/deckflow/deckprobe --locked deckprobe
    ```
  </Step>
  <Step title="Download a multi-page PDF">
    ```bash
    curl -fL https://mozilla.github.io/pdf.js/web/compressed.tracemonkey-pldi-09.pdf \
      -o sample.pdf
    ```

    This 14-page paper provides enough structure and metadata to make the result useful for verification.
  </Step>
  <Step title="Request format and page count">
    ```bash
    deckprobe \
      --targets format,page_count \
      --view values \
      --pretty \
      sample.pdf
    ```
  </Step>
  <Step title="Verify the result">
    A successful values report has exit status `0`, `schema_version: 2`, a PDF driver, and a `values` map similar to:

    ```json
    {
      "schema_version": 2,
      "tool_version": "2.4.0",
      "status": "ok",
      "view": "values",
      "driver": {
        "id": "pdf",
        "profile": "pdf"
      },
      "values": {
        "document.format": "pdf",
        "pdf.page_count": 14
      },
      "unresolved_targets": [],
      "diagnostics": []
    }
    ```

    The full result also includes `input`; additional fields can appear when targets are satisfied opportunistically.
  </Step>
</Steps>

## Before automating the command

- Run `deckprobe targets pdf --pretty` before storing format-specific Target IDs in code. It reports each Target's minimum Probe Level and applicability.
- Add `--strict` when every requested Target must resolve. DeckProbe still writes the complete JSON report, then exits with status `5` if any requested Target is unresolved.
