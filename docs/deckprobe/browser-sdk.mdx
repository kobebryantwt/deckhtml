The `@deckflow/deckprobe` package runs the same target-driven Rust engine in WebAssembly. It accepts `File`, `Blob`, `ArrayBuffer`, and `Uint8Array`; document bytes remain in the browser.

## Install

```bash
npm install @deckflow/deckprobe
```

The package includes the JavaScript entry points, TypeScript definitions, and WebAssembly runtime used below.

## Probe on the main thread

`probe()` initializes WebAssembly lazily. Call `initDeckProbe()` during startup or idle time to prepare the first interaction:

```ts
import { initDeckProbe, probe } from "@deckflow/deckprobe";

await initDeckProbe();

const report = await probe(file, {
  targets: ["@summary", "@security"],
  level: "metadata",
});
```

A browser `File` supplies its own name. For `Blob`, `ArrayBuffer`, or `Uint8Array`, pass a logical filename so the extension can select the format:

```ts
const bytes = await fetch("/documents/quarterly-deck").then((response) =>
  response.arrayBuffer(),
);

const report = await probe(bytes, {
  name: "quarterly-deck.pptx",
  targets: ["powerpoint.slide_count"],
});
```

`initDeckProbe()` configuration is applied only on the first initialization. Configure a custom runtime before the first call to `probe()`.

## Probe in a Worker

Use the Worker entry for user-provided files, large inputs, or deep probes that should not occupy the UI thread:

```ts
import { createDeckProbeWorker } from "@deckflow/deckprobe/worker";

const worker = createDeckProbeWorker();
try {
  const report = await worker.probe(file, {
    targets: ["@summary"],
    level: "deep",
  });
} finally {
  worker.terminate();
}
```

Reuse one Worker for a batch, then terminate it when the owning screen or job ends. `terminate()` cancels pending probes.

## Discover capabilities

The main SDK entry exports `formats()`, `targets(format)`, `schema()`, and `version()`:

```ts
import { formats, schema, targets, version } from "@deckflow/deckprobe";

const engineVersion = await version();
const supportedFormats = await formats();
const pdfTargets = await targets("pdf");
const reportSchema = await schema();
```

All discovery functions are asynchronous. Use them to populate format and target selectors, validate responses against the bundled contract, and display the active engine version.

## Vite development configuration

Exclude DeckProbe from Vite dependency pre-bundling. Without this setting the WebAssembly wrapper can be moved away from its `.wasm` file during development, causing a 404 or an HTML response where WebAssembly bytes are expected.

```ts
// vite.config.ts
import { defineConfig } from 'vite';

export default defineConfig({
  optimizeDeps: {
    exclude: ['@deckflow/deckprobe'],
  },
});
```

This applies to both the main-thread and Worker entries.

<Tip>
  Both `probe()` and the Worker API load the complete input into memory. A Worker keeps conversion and parsing off the UI thread, but does not reduce memory use. Prefer the native CLI for very large files or large batches.
</Tip>
