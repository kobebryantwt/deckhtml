DeckProbe CLI runs the target-driven Rust engine locally. It fits shell commands, CI, services, and batch workflows without requiring Python, a JVM, Microsoft Office, or an external PDF library.

## Install

<Tabs>
  <Tab title="macOS and Linux">
    ```bash
    curl --proto '=https' --tlsv1.2 -LsSf \
      https://github.com/deckflow/deckprobe/releases/latest/download/deckprobe-installer.sh | sh
    ```
  </Tab>
  <Tab title="Windows">
    ```powershell
    powershell -ExecutionPolicy ByPass -c "irm https://github.com/deckflow/deckprobe/releases/latest/download/deckprobe-installer.ps1 | iex"
    ```

    Restart the shell if the installer updates the user `Path`.
  </Tab>
  <Tab title="From source">
    Requires Rust 1.88 or newer and Git.

    ```bash
    cargo install --git https://github.com/deckflow/deckprobe --locked deckprobe
    ```
  </Tab>
</Tabs>

Verify the executable and inspect the built-in help:

```bash
deckprobe --version
deckprobe --help
```

## Run a first probe

Inspect a local document with the default Metadata-level profile:

```bash
deckprobe report.pdf
```

Request only the targets your application needs and format the JSON for reading:

```bash
deckprobe -t format,slide_count --pretty deck.pptx
```

DeckProbe writes one Schema v2 JSON report to standard output. A successful target contains its value, confidence, selected path, and evidence source; the report also records actual execution cost and diagnostics.

## Common tasks

```bash
# Inspect identity, common metadata, and primary structure
deckprobe -t @summary report.pdf

# Inspect security-related signals
deckprobe -t @security upload.docm

# Return compact values instead of full evidence records
deckprobe -t @summary --view values report.pdf

# Preview selected paths without executing non-header probe paths
deckprobe --plan --pretty report.pdf

# Treat unresolved requested targets as a non-zero exit status
deckprobe --strict -t format,page_count report.pdf
```
