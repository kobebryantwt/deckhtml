DeckProbe is a target-driven document inspection engine available as a native Rust CLI and a Browser JavaScript SDK. It inspects untrusted documents without rendering them and without starting Microsoft Office, Apple iWork, or another desktop office suite.

<CardGroup cols={2}>
  <Card title="Supported document formats" icon="file-check">
    - PDF
    - Modern and legacy Microsoft Word, Excel, and PowerPoint
    - Modern Apple Keynote, Numbers, and Pages
  </Card>
  <Card title="Local execution" icon="laptop">
    - The native CLI does not depend on Python, the JVM, Microsoft Office, or an external PDF library
    - The Browser SDK runs the same engine locally through WebAssembly and does not upload document bytes
  </Card>
</CardGroup>

Instead of unpacking everything, DeckProbe executes only the probe paths needed for the requested targets and confidence level. Results are deterministic Schema v2 JSON with target-level evidence and measured I/O cost.

## Why DeckProbe

| Requirement | DeckProbe behavior |
| --- | --- |
| Focused inspection | Runs only the paths needed for targets such as format, page count, or slide count |
| Predictable resource use | Enforces physical-read, decompression, archive-entry, and wall-clock budgets |
| Automation-ready output | Returns stable JSON for successful, partial, and failed probes |
| Verifiable results | Records status, value, confidence, selected path, and evidence source per target |
| Safer format routing | Selects by filename extension, then verifies the container and required internal document type |

## Supported formats

| Family | Profiles | Current inspection coverage |
| --- | --- | --- |
| PDF | `.pdf` | Header and Info metadata, page/object counts, xref type, signatures, links, attachments, JavaScript, forms, annotations, and XMP presence |
| Word | `.docx`, `.docm`, `.dotx`, `.dotm` | OOXML metadata, saved statistics, paragraph/table structure, security signals, comments, and image assets |
| Excel | `.xlsx`, `.xlsm`, `.xltx`, `.xltm`, `.xlsb` | Worksheets, names, visibility, shared strings, tables, charts, pivots, security signals, and image assets; `.xlsb` is identity-only |
| PowerPoint | `.pptx`, `.pptm`, `.ppsx`, `.ppsm`, `.potx`, `.potm` | Slides, hidden slides, masters, layouts, notes, slide size, charts, comments, images, media, and security signals |
| Legacy Office | `.doc`, `.dot`, `.xls`, `.xlt`, `.ppt`, `.pps`, `.pot` | Validated CFB streams, SummaryInformation metadata, macros, embedded-object signals, and core statistics |
| Keynote | `.key` | Modern IWA identity and integrity, slide canvas, orientation, hidden/notes/build/transition counts, and referenced table models |
| Numbers | `.numbers` | Modern IWA identity and integrity, ordered sheets, table dimensions, hidden/filtered dimensions, and persisted formulas |
| Pages | `.pages` | Modern IWA identity and integrity, sections, page geometry, change tracking, body-text structure, cached pagination, and table models |

<Note>
  Apple iWork support covers modern ZIP/IWA documents. Legacy XML iWork packages are recognized but return a structured `UNSUPPORTED_FORMAT` error.
</Note>

## Scope

DeckProbe returns document facts, not rendered output or a complete editable object model. It does not run OCR, execute macros, follow external links, or send files to a remote service.

- For page- and element-level Document IR, semantic extraction, or format conversion, use [DeckOps](/deckops/overview).
- To render documents, use [DeckRender](/deckrender/overview).
- To modify supported Office source files, use [DeckUse](/deckuse/overview).
