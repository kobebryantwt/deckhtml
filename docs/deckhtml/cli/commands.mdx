## Convert

```text
deckhtml [global options] [inputs...]
```

| Flag | Behavior |
| --- | --- |
| `-o, --output <path>` | Output `.pptx` or `.png` path; extension selects format |
| `--mode <mode>` | `auto`, `local`, or `cloud`; default `auto` |
| `--width <pixels>` | Override viewport width; CLI derives 16:9 height |
| `--platform <platform>` | `win`, `mac`, `ios`, `android`, or `linux` font mapping target |
| `--embed-fonts` | Embed fonts; cloud only |
| `--report` | Write a conversion report next to the output |
| `--executable-path <path>` | Use a specific Chromium executable locally |
| `--exclude <selector>` | Exclude matching runtime or navigation elements |
| `--identity-attribute <name>` | Use a custom stable element identity attribute |
| `--force` | Overwrite existing output |
| `--no-animations` | Disable element entrance-animation export |
| `--slide-transition <effects>` | Select one transition or a comma-separated cycle |
| `--no-slide-transitions` | Disable slide transitions |
| `--iframes <mode>` | `inspect`, `screenshot`, or `skip`; local only |
| `--iframe-load-timeout-ms <ms>` | Set iframe load timeout |
| `--json` | Print a machine-readable final envelope |
| `--quiet` | Suppress nonessential output |
| `-v, --verbose` | Print detailed logs to stderr |
| `-V, --version` | Print version |
| `-h, --help` | Print help |

## Authentication

```bash
deckhtml auth login [--port <port>]
deckhtml auth status
```

## Configuration

```bash
deckhtml config set api-key <key>
deckhtml config set space-id <id>
deckhtml config set webhook <url>
deckhtml config set retention-hours <0-99>
deckhtml config show
```
