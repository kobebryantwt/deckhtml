## Install and verify

```bash
npm install -g @deckflow/deckhtml
deckhtml --version
deckhtml --help
```

Or run a pinned or latest package without installing globally:

```bash
npx -y @deckflow/deckhtml@latest deck.html -o deck.pptx
```

## Input forms

```bash
deckhtml deck.html -o deck.pptx
deckhtml 01.html 02.html 03.html -o deck.pptx
cat deck.html | deckhtml - -o deck.pptx
deckhtml https://example.com/deck.html -o deck.pptx
```

Stdin requires `--output`. A single command can use local files or URLs, but cannot mix both.

## Output format

DeckHTML infers format from `-o`:

```bash
deckhtml deck.html -o deck.pptx
deckhtml deck.html -o frames.png
```

PPTX is the default when `-o` is omitted.

## Reliable automation defaults

```bash
deckhtml deck.html \
  -o deck.pptx \
  --mode local \
  --json \
  --report \
  --force
```

Use [Output and Automation](/deckhtml/cli/output-modes) for stdout, stderr, JSON, file overwrite, and report behavior.
