## Install and verify

```bash
npm install -g @deckflow/deckhtml
deckhtml --version
deckhtml --help
```

Or run a pinned or latest package without installing globally:

```bash
npx -y @deckflow/deckhtml@latest deck.html -o deck.pptx
```

## Input forms

```bash
deckhtml deck.html -o deck.pptx
deckhtml 01.html 02.html 03.html -o deck.pptx
cat deck.html | deckhtml - -o deck.pptx
deckhtml https://example.com/deck.html -o deck.pptx
```

Stdin requires `--output`. A single command can use local files or one or more URLs, but cannot mix both. URL input is downloaded as HTML text; it does not inherit cookies or browser state, and relative assets require an explicit `<base>` or absolute URLs.

## Output format

DeckHTML infers format from `-o`:

```bash
deckhtml deck.html -o deck.pptx
deckhtml deck.html -o frames.png
```

PPTX is the default when `-o` is omitted.

For more than one detected slide, PNG output uses numbered paths and returns all of them in the JSON `outputs` array. See [Multi-page and Batch Input](/deckhtml/guides/multi-page-and-batch).

## Reliable automation defaults

```bash
deckhtml deck.html \
  -o deck.pptx \
  --mode local \
  --json \
  --report \
  --force \
  --quiet
```

Use `--json --quiet` together when stdout must contain only the final JSON envelope. Use [Output and Automation](/deckhtml/cli/output-modes) for stdout, stderr, exit status, overwrite, and report behavior.
