PPTX output combines editable Office elements with visual fallbacks. DeckHTML does not flatten an entire slide by default, but individual elements can be rasterized when no stable native mapping exists.

## What to verify

- slide count and slide size
- text content, wrapping, font selection, and reading order
- images, tables, shapes, SVG, formulas, and media
- element animations and slide transitions
- rasterized or unsupported elements in the report
- missing font and resource diagnostics

## Fonts

Local conversion maps CSS font stacks for the selected target platform. Cloud conversion can additionally embed matching font binaries with `--embed-fonts`.

## Output safety

Local CLI conversion refuses to replace an existing file unless `--force` is passed. The current cloud download path writes its result directly, so automation should use an isolated output path. The Node API returns a buffer and never writes to disk automatically.

Use strict mode and per-element reports when editability is a delivery requirement rather than a preference.
