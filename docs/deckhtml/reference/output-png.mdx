title: PNG Output
sidebarTitle: PNG Output
description: "Render each detected DeckHTML slide to a PNG image."
---

Select PNG output through the `-o` extension:

```bash
deckhtml deck.html -o frames.png --mode local
```

A one-slide input writes the requested path. A multi-slide input writes numbered PNG files and reports all output paths.

PNG is useful for previews, thumbnails, visual review, and downstream image workflows. It preserves rendered appearance but does not retain editable slide objects.

PNG conversion does not use PPTX-specific animation, transition, or font-embedding behavior. It renders the visible state of each detected slide at the selected viewport.

Use the Node `convertHtmlToPng()` API when image buffers should remain in memory.
