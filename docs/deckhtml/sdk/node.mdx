Use the Node SDK when your conversion workflow lives in JavaScript or TypeScript services, workers, or internal tools.

## Install

```bash
npm install @deckflow/deckhtml playwright pptxgenjs
```

The package declares `playwright` and `pptxgenjs` as peer runtime dependencies. In practice, your application environment needs both available at runtime because the converter stack imports them directly.

## Import the published API

The package exports `convertHtmlToPptx()` from its main entry:

```ts
import { convertHtmlToPptx } from '@deckflow/deckhtml';
```

## Basic example

```ts
import { promises as fs } from 'node:fs';
import { convertHtmlToPptx } from '@deckflow/deckhtml';

const result = await convertHtmlToPptx({
  input: 'index.html'
});

await fs.writeFile('deck.pptx', result.data);
console.log(result.slideCount);
```

## Multiple input files

```ts
import { promises as fs } from 'node:fs';
import { convertHtmlToPptx } from '@deckflow/deckhtml';

const result = await convertHtmlToPptx({
  inputs: ['title.html', 'agenda.html', 'summary.html']
});

await fs.writeFile('deck.pptx', result.data);
```

## Useful `ConversionOptions`

The type definitions expose these commonly useful options:

| Option | Type | Meaning |
| --- | --- | --- |
| `input` | `string` | Single HTML or SVG input file. |
| `inputs` | `string[]` | Multiple HTML or SVG files, processed in order into one PPTX. |
| `slideSelector` | `string` | Override the selector used to split slides inside one document. |
| `splitByHeight` | `boolean` | Split one input vertically into multiple slides. |
| `autoDetectSlides` | `boolean` | Auto-detect multi-slide containers in one HTML file. |
| `viewportWidth` | `number` | Browser viewport width in pixels. |
| `viewportHeight` | `number` | Browser viewport height in pixels. |
| `allowLocalResources` | `boolean` | Allow loading `file://` subresources in Playwright. |
| `platform` | `PlatformTarget` | Generic font mapping target: `win`, `mac`, `ios`, `android`, `linux`. |
| `quiet` | `boolean` | Suppress non-essential console output. |

## Example with viewport and platform control

```ts
import { promises as fs } from 'node:fs';
import { convertHtmlToPptx } from '@deckflow/deckhtml';

const result = await convertHtmlToPptx({
  input: 'slides.html',
  viewportWidth: 1440,
  viewportHeight: 810,
  platform: 'win',
  quiet: true
});

await fs.writeFile('deck.pptx', result.data);
```

## Return type

The `ConversionResult` includes:

| Field | Type | Meaning |
| --- | --- | --- |
| `data` | `Buffer` | Final PPTX binary data. |
| `slideCount` | `number \| undefined` | Slide count when available. |
| `usedFonts` | `string[] \| undefined` | Resolved fonts used during conversion. |
| `stats` | `ConversionStats \| undefined` | Element and font statistics collected during conversion. |

## Practical note

The Node SDK is currently focused on PPTX generation through `convertHtmlToPptx()`. The CLI remains the documented surface for broader shell-oriented workflows, authentication flows, and cloud flags.
