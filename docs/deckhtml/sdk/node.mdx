## PPTX conversion

```ts
import { writeFile } from 'node:fs/promises';
import { convertHtmlToPptx } from '@deckflow/deckhtml';

const result = await convertHtmlToPptx({
  input: 'deck.html',
  allowLocalResources: true,
  platform: 'win',
  quiet: true,
});

await writeFile('deck.pptx', result.data);
console.log({
  slideCount: result.slideCount,
  mapping: result.report?.summary,
  diagnostics: result.diagnostics,
});
```

Pass `inputs: ['01.html', '02.html']` for ordered files. The function returns a PPTX `Buffer`, slide count, used fonts, statistics, resource and identity diagnostics, and a per-element conversion report when available.

## PNG conversion

```ts
import { convertHtmlToPng } from '@deckflow/deckhtml';

const result = await convertHtmlToPng({
  input: 'deck.html',
  viewportWidth: 1280,
  viewportHeight: 720,
});
```

The PNG result contains one image buffer per detected slide. The function does not choose filenames or write them:

```ts
await Promise.all(
  result.images.map((image, index) =>
    writeFile(`slide-${index + 1}.png`, image)
  )
);
```

## Multi-page and ordered inputs

```ts
const result = await convertHtmlToPptx({
  inputs: ['01-cover.html', '02-metrics.html', '03-summary.svg'],
  slideSelector: '.presentation-page',
  autoDetectSlides: true,
  excludeSelector: '.controls, .progress',
  quiet: true,
});
```

Files may be inspected concurrently, but the returned presentation preserves `inputs` order. `slideSelector` applies within each input.

For a direct URL, Chromium performs the navigation:

```ts
const result = await convertHtmlToPptx({
  input: 'https://example.com/deck.html',
  resourcePolicy: { network: 'allow' },
});
```

Pass a caller-owned `browserContext` when the page requires controlled session state. This differs from the CLI URL path, which downloads the HTML response as text first.

## Resource policy

The API blocks local subresources by default unless they are explicitly allowed. Prefer a scoped resource policy over the broad `allowLocalResources: true` compatibility switch:

```ts
const result = await convertHtmlToPptx({
  input: '/work/deck/deck.html',
  resourcePolicy: {
    network: 'deny',
    allowedRoots: ['/work/deck/assets'],
    followSymlinks: false,
  },
});
```

Blocked resources appear in `resourceDiagnostics` and the unified `diagnostics` list.

## Strict conversion

Adding `strict` opts into strict gates. Omitted flags inside the object use their strictest behavior unless explicitly relaxed.

```ts
await convertHtmlToPptx({
  input: 'deck.html',
  strict: {
    requireElementIdentity: true,
    allowRaster: false,
    allowUnsupported: false,
    allowRemoteResources: false,
    failOnMissingFonts: true,
    allowUnmappedAnimations: false,
  },
});
```

Strict failures throw a `ConversionError` containing a primary diagnostic and the collected diagnostic list.

## Advanced options

The API also controls viewport detection, target font platform, animations, slide transitions, iframe handling, and caller-provided Playwright execution. A supplied `browser` or `browserContext` remains owned by the caller; DeckHTML does not close it.
