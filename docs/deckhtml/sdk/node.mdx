## PPTX conversion

```ts
import { writeFile } from 'node:fs/promises';
import { convertHtmlToPptx } from '@deckflow/deckhtml';

const result = await convertHtmlToPptx({
  input: 'deck.html',
  allowLocalResources: true,
  platform: 'win',
  quiet: true,
});

await writeFile('deck.pptx', result.data);
console.log(result.slideCount, result.report, result.diagnostics);
```

Pass `inputs: ['01.html', '02.html']` for ordered files. The function returns a PPTX `Buffer`, slide count, used fonts, statistics, resource and identity diagnostics, and a per-element conversion report when available.

## PNG conversion

```ts
import { convertHtmlToPng } from '@deckflow/deckhtml';

const result = await convertHtmlToPng({
  input: 'deck.html',
  viewportWidth: 1280,
  viewportHeight: 720,
});
```

The PNG result contains one image buffer per detected slide.

## Strict conversion

Adding `strict` opts into strict gates. Omitted flags inside the object use their strictest behavior unless explicitly relaxed.

```ts
await convertHtmlToPptx({
  input: 'deck.html',
  strict: {
    requireElementIdentity: true,
    allowRaster: false,
    allowUnsupported: false,
    allowRemoteResources: false,
    failOnMissingFonts: true,
    allowUnmappedAnimations: false,
  },
});
```

Strict failures throw a `ConversionError` containing a primary diagnostic and the collected diagnostic list.

## Advanced options

The API also controls slide selectors, excluded selectors, identity attributes, auto-detection, viewport, resource policy, target font platform, animations, slide transitions, iframe mode, iframe timeout, and caller-provided Playwright browser execution.
