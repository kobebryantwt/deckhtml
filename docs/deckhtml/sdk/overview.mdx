The published package exports a Node.js API in addition to the CLI. It returns buffers and structured metadata without writing output files on your behalf.

```bash
npm install @deckflow/deckhtml pptxgenjs
```

Main conversion functions:

- `convertHtmlToPptx()`
- `convertHtmlToPng()`
- `inspectHtmlFonts()`

The library also exports conversion report helpers, transition catalogs and resolvers, font mapping utilities, and public conversion types.

Use the SDK when your application needs browser injection, explicit resource policy, strict conversion gates, callbacks, or direct access to result buffers and diagnostics.
