description: "Create a slide-sized HTML file and convert it to PPTX with DeckHTML."
---

<Steps>
  <Step title="Create a slide">
    Save the following as `deck.html`. Declaring the deck size lets DeckHTML use the intended viewport.

    ```html
    <!doctype html>
    <html>
      <head>
        <meta charset="utf-8" />
        <meta name="deck-size" content="1280x720" />
        <style>
          * { box-sizing: border-box; }
          body { margin: 0; font-family: Arial, sans-serif; }
          .slide-container {
            width: 1280px;
            height: 720px;
            padding: 72px;
            background: #f7fafc;
          }
        </style>
      </head>
      <body>
        <section class="slide-container" data-slide-id="intro">
          <h1 data-element-id="title">Hello DeckHTML</h1>
          <p data-element-id="summary">HTML layout, presentation output.</p>
        </section>
      </body>
    </html>
    ```
  </Step>
  <Step title="Convert locally">
    ```bash
    npx -y @deckflow/deckhtml@latest deck.html \
      -o deck.pptx \
      --mode local \
      --json
    ```
  </Step>
  <Step title="Check the result">
    A successful command exits with code `0`, writes `deck.pptx`, and prints a JSON envelope similar to:

    ```json
    {
      "ok": true,
      "input": ["deck.html"],
      "output": "deck.pptx",
      "format": "pptx",
      "mode": "local",
      "slideCount": 1
    }
    ```
  </Step>
  <Step title="Generate a conversion report">
    ```bash
    npx -y @deckflow/deckhtml@latest deck.html \
      -o deck.pptx \
      --mode local \
      --report \
      --force
    ```

    Review `deck.pptx.report.json` for native, vector, raster, ignored, and unsupported mappings.
  </Step>
</Steps>
