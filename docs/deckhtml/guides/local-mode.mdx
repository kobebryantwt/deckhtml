Local mode loads the input with Playwright, inspects the browser layout, and generates PPTX or PNG on the current machine.

```bash
deckhtml deck.html -o deck.pptx --mode local
deckhtml deck.html -o frames.png --mode local
```

Use local mode for fast iteration, controlled data handling, CI jobs with Chromium, and application workflows that need the Node conversion API.

## Local capabilities

- HTML or SVG to PPTX
- HTML or SVG to one or more PNG images
- multi-file and multi-slide inputs
- editable element mapping and raster fallbacks
- animations and slide transitions for PPTX
- iframe inspection, screenshot, or omission
- per-element report and structured diagnostics

## Requirements

Local execution needs a usable Chromium installation. Set `--executable-path` or `DECKHTML_CHROMIUM_EXECUTABLE_PATH` when automatic discovery cannot find it.

Browser resolution order is: an explicit `--executable-path`, `DECKHTML_CHROMIUM_EXECUTABLE_PATH`, a Playwright-managed Chromium, then a supported system Chrome or Edge installation. The Node.js API can additionally provide a persistent profile, a caller-owned browser, or a browser context.

Local mode does not support `--embed-fonts`. It can map CSS font stacks to the selected target platform, but embedding the font binaries is a cloud operation.
