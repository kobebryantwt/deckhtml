## Only one slide was detected

Use at least two repeated `.slide-container`, `.slide`, `[data-slide]`, or other semantic slide hosts; make each visible host close to the viewport size and give it meaningful text or media content. Otherwise pass one file per slide or set `slideSelector` in the Node.js API. Generate a report to confirm `slideCount`.

## Content is clipped or positioned incorrectly

Match the declared deck size, slide host size, and browser viewport. Add `meta[name="deck-size"]` or pass `--width` when auto-detection does not reflect the authored canvas.

## Fonts differ from the browser

Ensure font files load before conversion, use an explicit CSS font stack, select the target `--platform`, and inspect missing-font diagnostics. Use cloud `--embed-fonts` when the output must carry supported font binaries.

## An element is an image instead of editable

Check its `mapping_mode` and raster reason in the report. Canvas charts, complex SVG, some gradients, URL backgrounds, and formula fallbacks are expected raster candidates.

## Chromium cannot start

Install a compatible Chromium or pass `--executable-path`. In containers, make sure the process has the libraries and permissions Chromium requires.

## Remote or iframe content is missing

Review resource and iframe diagnostics. Confirm network access, choose the intended iframe mode, and increase `--iframe-load-timeout-ms` when the child document is slow.

For CLI URL input, remember that DeckHTML downloads HTML text before conversion. Relative assets do not automatically resolve against the original URL; use absolute URLs or a `<base>` element. Authenticated pages requiring browser cookies cannot be fetched through this input path.

## Cloud PPTX still reports a browser error

The current CLI performs a local HTML inspection after the cloud PPTX task to collect slide and font statistics. Install Chromium or set `DECKHTML_CHROMIUM_EXECUTABLE_PATH`. Cloud PNG does not use this post-conversion inspection.

## CI produced an ambiguous result

Use `--json --report`, check the process exit code, verify every reported artifact path, and fail the job on disallowed report mappings or diagnostic rule IDs.
